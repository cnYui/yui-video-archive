## 一句话

**每句话都交一个新信息：第一句就是最反常识的事实，中间短分句 + 数字 + 自问自答换挡，最后一句能单独截图转发。** 不寒暄，不铺垫，不留白。

## 节奏指标（照着量）

| 指标 | AI大圆镜实测（10 条中位） | 我们写稿的目标 |
|---|---|---|
| 分句（一个逗号段 ≈ 一口气） | 9 字，P90 14 字 | 8–12 字，超过 15 字就拆 |
| 句子（到句号 / 问号） | 22 字，2–3 个分句 | ≤ 28 字（双语字幕一行的上限）；一句一个意思 |
| 数字 | 每分钟 10 个，约 6 秒一个 | 每分钟 8 个以上；每个数配一个能想象的参照 |
| 自问自答 | 每 15–25 秒一次换挡 | 每一拍开头可以用一个短问句，问完立刻答 |
| 停顿 | 每分钟约 5 次 ≥ 0.25 s，几乎一口气 | 不写“……”留白，不写“那么，接下来我们来看” |
| 语速 | 5.2 字/s（含停顿） | 估时照各技能的配音实测（曼波约 6.6、悠一克隆约 7.6 字/s），不改配音速度 |
| 时长 | 一条只讲一件事，短条 30–120 s | 各合集原来的时长不变；长片按下面的“长片骨架”分幕 |

## 骨架

### 短条 / 一条新闻（60–120 s；日报每条新闻也照这个缩写）

1. **钩子（前 5 秒）**：一句话说出最反常识的事实，带一个具体数字或具体对象。不寒暄、不先讲概念（《原LAI如此》的开场白暂时保留，见“和原有规则的关系”）。可以紧跟一个防不信的短句：“这是正经论文”“真的做出来了”。
2. **背书（5–15 秒）**：日期 + 机构 + 期刊 / 公司 / 官方页面，一口气说完。日期写到“几月几号”（日报、OpenAI 相关的日期规矩照各自技能）。
3. **拆机制**：“先说清楚”或“怎么做到的？”开头，3–4 个短分句讲完做法，最多一个极短的比喻（一句话以内，比如“像插了面小旗”这种长度）。
4. **加码 / 对照**：前情、上一个纪录、现实代价，全用数字。和我们之前讲过的同题视频可以回扣一句（“上一期讲过……”），不重复讲。
5. **泼冷水**：主动说边界，口气平：还没测过的、官方没写的、只活了几天的、成本多少的。
6. **收尾金句（最后 3–8 秒）**：一到两句，对仗或反转，能单独转发。短条不喊关注、不预告。

30 秒以内的超短条只要 1、2、3、6 四拍。

### 长片（3 分钟以上：原LAI如此、日报整期、教程）

冷开场（一个具体的人 / 场景 / 数字）→ 一句话说今天讲完什么 → 按时间或步骤分幕，每幕仍是“时间 + 事件 + 数字 + 一句口语评价” → 中段一句定性（“X 只是麦克风，Y 才是灵魂”这种）→ “但另一面是……”（风险、代价、争议）→ 收尾金句。原LAI如此的“先抛 2–3 个疑问”保留，但问题要一句一个、每个后面马上接答案，别攒在开头一起念。

## 句子手法

- **短分句链**：主语能省就省，逗号串 2–4 个短分句。
- **数字落地**：配参照物（“比家猫还小一圈”“十个里有六个半”“跟人的体温差不多”）；百分比和小数照念，不取整。
- **自问自答**：“怎么做到的？”“那它超过人了吗？”“那这东西拿来干嘛？”——问完马上答，下一拍就开始了。
- **替观众说质疑**：“你可能会说：……”，然后用判据或数据回答。
- **对“你”说**：把新闻拉到观众身上（你的照片、你的电费、你的代码）。
- **原话引用**：“官方原话：……”“作者自己都说……”。比转述更有分量，也方便事实核对。
- **列举不编号**：“能写代码、能订机票、还能替你测游戏”；只有真的分层时才用“一共三层”。
- **口语动词**：下手更狠、干净得很、拎出来、往前拱、整活、出幺蛾子、愣是……一条一两个就够；不用网络烂梗，少用“呢 / 啦 / 哦”。
- **一句话定性**：拆完机制后最多一两句，帮观众记住。

## 和原有规则的关系

- **照旧**：不要 AI 腔；短句口语；直接给干货；不用“不是……而是……”（AI大圆镜用过“这不是科幻片，是真事”，我们不用，改成“2024 年就发生了，真事”）；事实核对在写稿之前，每个数字有出处；日报不用“炸裂”“王炸”、报道 DeepSeek 中立；Claude Code 相关“官方没写的明说官方没写”；OpenAI 相关网友说法挂名；双语字幕的字数上限。
- **改掉**：Way to AGI 观点类“文风参考叶小十同学”→ 改照本规范（小剧场、贯穿全片的类比不再用）。
- **保留不动**（用户 2026-10-04：“先不动”）：《原LAI如此》的开场白“大家好，我是……”和“S02 先抛 2–3 个疑问 → 疑问卡飞成本期目录”（连着引擎：`build_script.py` 查开场白、开场挥手动作、目录动画）。疑问要写成本规范的样子（一句一个、带数字、短），开场白之后的第一句正文就是钩子。
- 其余开场写法（Claude Code / OpenAI 的“演示前十几秒当钩子”、日报的条目开头）本来就是钩子开场，按本规范写第一句。

## 改写示例（Claude Code相关第 3 期开头，示意）

原稿（5 句，约 120 字，第 4 句才说出产品）：

> 你让 Claude 改完代码，最后它会给你一份总结。这份总结写得很顺，每一条看着都是好消息。可有一条，被它一笔带过了。Claude Code 新加了一个内置插件，叫 You should know……官方推文说：它会扫描 Claude 的输出，把你可能漏掉的重要信息挑出来。

照本规范（钩子 → 背书 → 拆机制）：

> Claude 改完代码交的总结里，藏着一句会让顾客被扣两次钱的话。它自己一笔带过了。Claude Code 2.1.287 版加了个内置插件，叫 You should know。官方推文说：它扫 Claude 的输出，把你可能漏看的挑出来。怎么挑的？派一个旁路智能体，在旁边盯着。

收尾原稿“总结写得再漂亮，也有没说出口的。多一双眼睛盯着，挺省心。”已经接近这个风格；改成反转句会更像：“总结写得越顺，越要有人盯着没说出口的那句。”

## 交稿前自检

- [ ] 第一句正文是不是最反常识的事实？有没有具体数字或对象？前面有没有寒暄、概念铺垫？
- [ ] 15 秒内有没有日期 + 来源？
- [ ] 每个分句 ≤ 15 字？每句 ≤ 28 字？
- [ ] 每分钟有没有 8 个以上数字？每个数有没有参照、有没有出处？
- [ ] 每一拍之间是不是靠短问句 / “但”换挡，而不是“接下来我们来看”？
- [ ] 有没有主动泼冷水（边界、官方没写的）？
- [ ] 最后一句能不能单独截图转发？短条有没有多余的“关注 / 下期见”？
- [ ] 没有“不是……而是……”，没有夸张词，没有把两项研究接成一条线讲。

## 不要学的

- **事实拼接**：它把 2021 年“人细胞打进猴胚胎”和 2023 年“猴干细胞嵌合猴”接成一条线讲，听起来像同一项研究推进了一步。我们按研究分开讲，各自写出处。
- **选题上限**：它的爆款（10 万+）都碰到“死 / 脑 / 疼 / 你的孩子”这类身体直觉，同样写法的冷门条只有几百播放。写法是底线，选题和第一句决定上限；但我们不为了钩子夸大事实。
