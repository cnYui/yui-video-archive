## 做法（可复用，和技能里的 HTML 引擎是两条路）

1. 转写：Design 用宽松设置（不开 VAD、不丢低置信段）逐词转写 `asr_design.py`；Slides 沿用第 2 期（ClaudeSlides 独立视频）校对过的逐词稿。按逐词时间 + 原声响度（`check_cuts.py`、`snap_cuts.py`）找每段入 / 出点；每个人脸段 / 操作段用 gridframes（抽帧叠 120 px 坐标网格）量裁切框。
2. 台本 `台本/plan.py`（唯一来源）：每段 `cut` + 同传句子（zh / en 一一对应拆成字幕条，带原片 t0）+ 上 / 下框子镜头（`O` 原片同步、`B` 别处素材、`F` 定格 + 缓推）+ 小标签；`build_script.py` 量真实字宽、出 34 行 `say`；Fish 一次键入 34 行、核对 34 块、一次生成、一次导出（`import_segments.py` 逐句核对文字），`build_voice.py` 去首尾静音 / 拉齐音量 / 量真实时长 / 给多条字幕的句子找切点。
3. 时间线 `build_timeline.py`：同传开口 = 英文 t0 − 段入点 + 0.4 s（前一句没说完就顺延）；段长 = max(原片段长, 同传说完 + 0.3 s)，帧数取整；`render_scenes.py` 先把每个子镜头从原片裁切成 846×476 小片（有缓存，freeze 用 OpenCV 逐帧裁切缩放），再和该段底图（背景印花 + 每个小标签一张）、圆角蒙版、贴纸合成整帧小片；`render.py` 拼接 + 烧 ASS 字幕 + 混音；`qa_mix.py` 出片前自查。

- **字幕字号（ASS Fontsize ≠ CSS em）**：技能规定的中文 52 px / 英文 30 px 是 HTML 引擎的 CSS font-size；这条走 ffmpeg + libass，ASS 的 `Fontsize` 是**行高**（Noto Sans SC 静态字重 winAscent + winDescent = 1.448 em），写 52 只画出 52 / 1.458 ≈ 36 px 的字。实测同一串字：CSS 52 px 宽 1077 px，ASS Fontsize 52 画出来 739 px（比值 0.686），Fontsize 76 才是 1079 px。第一版成片写 52 / 30，实际只有标准的 68.6 %。改成 ASS 76 / 44（`make_subs.py` 的 `LIBASS_EM = 0.686`，`ZH_ASS, EN_ASS = round(52 / 0.686), round(30 / 0.686)`）；新增 `check_subs_render.py` 对成片 mp4 抽每条字幕中点一帧、量烧进去的墨迹：中文墨迹高中位数 51 px、最宽一行 878 px、离左右边缘最近 85 px（≥ 70）；SRT 不变。**这是所有走 ASS 的成片共有的问题**（第 1 条、之前的 ClaudeSlides / OpenAI 几条走 ASS 的都偏小），没动，已告诉维护技能的会话。
- **系列 BGM**：`mix_audio.py` 重写——`AI科普/素材/音频/bgm.wav`（lo-fi 轻爵士，F 大调 80 BPM，原件 −20 LUFS）从头垫到尾，−16 dB（约 −36 LUFS，比配音低约 20 dB，文件自带建议 18–22 dB），同传空档（≥ 0.3 s）回升 +5 dB（0.5 s 以上平滑），Slides 一章再降 6 dB（原声里自带 BGM 分不开，让它领头），头 1 s 淡入、尾 2.5 s 淡出；技能引擎的规则“有原声的素材段 BGM ×0.05”这条每段都有原声，照搬等于听不见，所以改成整条垫底。成片 137.77 s、21.4 MB、−16.0 LUFS、真峰值 −2.0 dBFS，成片音轨和混音原件互相关错位 0.0 ms，BGM 单独 −35.9 LUFS。成片 / 无字幕版 / 手机预览已重出。
- **封面**：`制作/04_封面/make_cover_short.py`（不是技能的 `make_cover.py`——那个对竖屏成片的整帧裁切放不下两个框，所以自己用 PIL 排）出 `cover_3x4.png` / `cover_16x9.png` / `cover_4x3.png`：钩子“不只写代码 / 还能做设计”（不和平台标题同一句）、画面 = 台本 D04 段同一时刻的原片 4K 帧（上框 Nate 闭口微笑、下框 Claude Design 新手引导三张卡）缩进“边框 6”+ 黄贴纸 + 本条橙色印花；16:9 版内容收在 B 站首页 16:10 切图的安全区 x 110–1810 里。没有箭头（并排的两个框没有“指谁”的位置）。备选脚本 `make_cover_face.py`（Nate 的脸铺满、不带边框）做出来脸太近、张着嘴，没用——Tavus 那条在抖音遇到“封面不佳：请勿使用截屏当封面”（疑似视频通话截屏样的小窗画面），如果这条也被拦再回来改。
