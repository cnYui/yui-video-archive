# JoJo 落水角色半头重画结果

用户要求重新绘制第一幕坠机落海后的像素形象，海面只露半个头。方案见 `20261009-200046-jojo-half-submerged-head-plan_CN.md`。

## 最终效果

- 承太郎、乔瑟夫、阿布德尔、花京院、波鲁纳雷夫的 `float` 动作各重画两帧，共十帧。第一幕使用前四人的正式资源。
- 海面只露帽子、发型和上半张脸；下半张脸、身体和四肢隐藏。水线固定，两帧有一像素沉浮和水纹变化。
- 承太郎沿用另一会话已重画的成年头部；其余角色沿用各自原有头部特征。
- 已安装五人的正式图集，并更新游戏的 `chars`、`data` 资源包；重新打开或刷新 `游戏素材/JoJo/游戏/index.html` 即可加载。

## 绘制与资源更新

以下路径均相对 `游戏素材/JoJo/游戏/`：

| 文件 | 修改用途 |
|---|---|
| `tools/art/art_common.py` | 公共 `half_submerged_head()`：40×24 帧，源图水线锚点 `(20,21)`，先裁掉水线以下人物像素，再画水纹 |
| `tools/art/art_later_existing.py` | 五人落水取各自头部，使用公共水线函数，落水动画设为 3 fps |
| `tools/art/art_jotaro_redraw.py` | 承太郎落水使用成年重画后的帽脸比例，复用公共水线函数 |
| `tools/dev/sea_half_head_20261009/build_preview.py` | 定向构建候选图集，回读与引擎比对，通过后安装；包含非落水动作和并发修改检查 |
| `tools/dev/sea_half_head_20261009/capture_sea.py` | 从正式入口加载正式资源，摆出第一幕原海面背景、四人位置及对白，捕获两帧和五人翻转场景 |

第一章仍使用原 `float` 动作、原人物位置和上方对白。原角色素材库未改。
