## 做了什么

- **BGM**：成片里原本就有系列 BGM，但压得太低（说话时比人声低约 20 dB、停顿 −36…−44 dB，手机外放听不到）。程序合成 3 首（`制作\05_BGM\make_bgm.py`：A 科技脉冲 104 BPM A 小调 / B 柔光环境 88 BPM D 小调 / C 轻快电子 112 BPM C 大调），各混一版手机预览给用户听，用户选 A；终混 `mix_audio.py --bgm … --bed -11 --swell 3 --duck 0.25`（约比人声低 15 dB）：成片 12.3 MB、−16.0 LUFS、真峰值 −2.7 dBFS。
