# 手写字动画样片

## 起因

用户发来参考视频 `Downloads/28630518511-1-192.mp4`（讲 Token 的科普，白底马克笔手写字、火柴人），问「这样手写文字动画你能做吗」。

参考视频的特点：
- 文字一笔一笔写出来，画面里没有手。
- 中文和英文（Token、DeepSeek）都是手写感。
- 黄色的波浪下划线、圈、黑色箭头也是一笔笔画出来的。

用户同意下载两份数据。

## 数据（`AI日报/素材/手写/`，npm 原始包 `.tgz` 也留在这里）

- `hanzi-writer-data@2.0.1`：9575 个字。每个字有 `strokes`（轮廓）和 `medians`（按笔顺排列的中线点）。坐标在 1024 的方格里、y 轴朝上，SVG 里要套 `translate(0,900) scale(1,-1)`。
  - 许可是 Arphic Public License（`ARPHICPL.TXT`）。成片视频可以用；如果公开分发含改动数据的 HTML，要一起附上许可文本。
  - 没有中文标点、数字和字母。
- `hersheytext@2.0.0`：Hershey 和 EMS 单线字体（SVG font）。代码是 MIT，字体许可看各 SVG 的说明。

## 样片（`AI日报/_测试_手写动画_20260928/`，子代理制作，我逐帧检查过）

- `handwriting_sample.mp4`：5 秒，2340×1080，30 fps，150 帧。
- `handwriting_sample_sheet.png`：总览图。
- `index.html`：由 `build.py` 和 `template.html` 生成。
- `README.md`：重建方法、参数、许可。
- `_检查/`：逐帧条、字体对比图。
- 做法：
  - 中文沿笔画中线画圆头黑线，笔宽约为字格的 7%，看起来像马克笔。
  - 每个字随机偏一点：旋转 ±3°、缩放 ±6%、基线 ±6 px。随机种子固定。
  - `renderAt(t)` 按时间设置 `stroke-dashoffset`，所以每一帧只取决于 t。
  - 用 `render_wide.py` 出片。
- 时间线：
  - 0.03–2.22 s：写「今天天气不错」（33 笔）
  - 2.27–2.63 s：黄色波浪下划线
  - 2.70–3.39 s：写 token
  - 3.44–3.90 s：黄圈，从底部顺时针画，收尾稍微出头
  - 3.95–4.58 s：三个箭头，先画杆再画头
  - 之后停在最后一帧
- 英文字体选的是 EMS Tech，它是手写体 Architects Daughter 的单线版，许可 OFL。原字体为绘图仪设计，笔画会来回走，`build.py` 已经把字母拆成自然的书写顺序。
- 已知的局限：
  - 笔画数据来自楷体，所以写出来比参考视频工整。
  - 33 笔要在 2.2 秒里写完，笔画之间的停顿压到 20 ms、字与字之间 70 ms，笔速约 1950 px/s。
  - 英文字母只核对过 t、o、k、e、n 的笔顺，大写字母没查。
- 可以再改进的地方：
  - 短笔画写慢一点，长笔画写快一点；提笔的时间按移动距离算。
  - 长笔画加轻微抖动，整行的斜度和基线慢慢漂移。
  - 黄色标记放到黑字下面，用荧光笔的混合效果。
  - 想要更潦草的字，就换成真人手写轨迹数据，前提是许可允许。
