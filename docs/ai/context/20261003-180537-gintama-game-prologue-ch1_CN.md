## 技术方案

- 纯 HTML5 Canvas + 原生 JS，没有依赖；画布 384×216（和原片内部画布一样），整数倍最近邻放大。`file://` 直接打开能跑：所有元数据内嵌在 `data.js`，图片用 `<img>`、音频用 `HTMLAudio`、开场动画用 `<video>`（不用 fetch）。
- 资源全从原工程导出（`tools/build_assets.py`）：
  - 角色：`银魂/角色图集`（48 个图集 + 头像）直接用；
  - 背景：**按原工程 bg 模块的图层和公式在 JS 里重拼**，保留视差：歌舞伎町大街（天空、云、Terminal 塔、远景楼 0.3、中景 0.55、店面 1.0、透视石板路分行滚动、水沟、摇摆灯笼、飘动的旗子、半透明前景电线杆）、事务所（8 帧环境动画 + 7 帧拉门 + 桌子前景）、序章的战场（黄昏天空 + 原 s00 的大太阳、云、远处战舰、两层山、浓烟柱、插满刀的原野、透视土地、三种战旗）；营帐是自己画的；
  - UI：原 s00 的「银魂」logo 和缎带、原引擎 `name_card` / `chapter_card` 画的名牌和篇章卡、`sfx_text` 画的拟声字；
  - 字：宋体 12 / 16 px 点阵（原片字幕同款），只收脚本里出现的字（789 个）；
  - 音频：9 首配乐 + 47 个音效（wav → mp3）；
  - 开场动画：原 s00 拆两段（0–8.2 s 天人降临到攘夷战争；8.2–17.9 s 雨中废刀令到「银魂」标题），引擎逐帧渲染 ×2 最近邻，mp4（H.264，给 Safari）+ webm（VP9，Chrome / Edge / Firefox 优先用）。
- 引擎（`engine/`）：固定 60 Hz 逻辑；横版 + 前后纵深走位；角色按脚点 y 排序；打字机对话（22 字/秒，按角色音高放打字音）+ 2 倍头像 + 名牌；选项；旁白；镜头跟随 / 锁场；命中顿帧、白闪、火花、拟声字；被打飞的天人飞上天变成星星（银魂梗）。
- 战斗：J 三连击（下劈 / 上撩 / 突刺击退）、K 跳（空中 J 跳斩）、按住 L 防御（挡正面）；敌人 AI 走位对齐纵深、出手前头顶“!”预警、同时最多两个出手；Boss 有重击和冲锋（闪红光 + “!!”）。输了弹“××倒下了…… / 再来一次 / 回到标题”，从这场战斗开头重来，血量回满。
- 剧情脚本（`engine/script.js`）一句句 `await`：`S.say / narrate / choice / walk / arc / pose / act / emote / fight / video / setStage / camera / letterbox …`。

## 内容

- **序章**：开场动画 → 篇章卡 → 志士营地自由走动（桂、坂本、两个志士，篝火 / 两顶营帐 / 战旗可调查）→ 出营地第一战（两波）→ 第二战（一波 + 天人部队长）→ 桂和坂本赶到 → 旁白 → 开场动画后半。
- **第一章**：事务所睡觉 → 登势催房租 → **解谜**（沙发缝字条“重要的钱藏在你最重视的东西后面”→「糖分」字画背后 5000 日元；电视结野主播、Jump、日历、挂钟、盆栽等都能调查）→ 门口交钱三选一 → 被踢飞（窗外 → 大街摔落）→ 歌舞伎町自由闲逛（8 个 NPC、10 个调查点）→ 登势提到收保护费 → 甘味处触发：天人混混三人 + 猪头大哥 → 团子店大婶、登势收尾 → 挖鼻孔“……今天的歌舞伎町，也很和平呢。”→ 章末“第一章 完 / 下一章：新八登场（制作中）”。
- 台词按原作人物和梗新写（甜党、天然卷、Jump、洞爷湖、“不是假发，是桂”、坂本叫“金时”、登势在丈夫坟前遇到偷吃供品的银时、结野主播、高天原……），不是原作原句。用到的设定只取有把握的；高杉在序章只被提到（避免战时眼睛的设定问题）。

## 测试

- `tools/playtest.py`：Playwright 无头 Chromium 从标题一路自动玩（推进对话、走到调查点、贴近敌人连按 J），`--lose` 让第一场战斗先输一次测“再来一次”。最终一轮：序章 + 第一章 **78 句对话、控制台 0 报错**，截图在 `tools/_playtest/`。
- 中途发现并修掉的问题：
  - 标题和菜单的字没进字库（字库原来只扫 `story/`、`engine/`，漏了 `main.js`）；全角空格被 `isprintable()` 过滤掉了；
  - 提示条在顶部和血条、名牌打架、太长出屏 → 改到底部、自动换行；
  - 对话头像太小 → 2 倍（原片做法），裁到框里；
  - 白夜叉名牌标题和小字都是“白夜叉”→ 标题改“坂田银时”；
  - 前景电线杆挡住打架的人 → 半透明；
  - 章节切换（标题卡）时玩家控制没锁上（真人碰不到，自动测试撞上了）→ 切章节时先锁、剧情脚本结束时只有在有地图时才交还操作。
- 没测到的：真浏览器里的声音和 mp4（无头 Chromium 不带 H.264，所以加了 webm 并验证了 webm 能放）；手机 / 触屏（目前只有键盘）。
