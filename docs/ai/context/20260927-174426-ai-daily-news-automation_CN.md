## 三、要你决定的 3 件事

### 1. 发布前要不要你审

- **A. 审核后定时（推荐先用一周）**：05:00 左右通知你，你回“发”才投稿。北京 06:55（东京 07:55）前回复就定时 07:00；之后回复就立即发；当天没回复就不发。
- **B. 全自动定时**：自动检查全部通过就直接定时 07:00，再推送 BV 号给你。07:00 前你还能在创作中心改或删这条稿件（按钮位置第一次跑时确认）。有一项没通过就改走 A。
- 自动检查：
  - 台本检查无错误。
  - 事实核对 0 处提示（句子里的数字、英文名都能在原文找到）。
  - 每批配音识别分 ≥ 0.85。
  - 正片 3–4 分钟，上传版 ≤ 9 MB。
  - 题材不在不收的范围（时政、军方、出口管制、传闻等）。
- 不管选哪种，B 站自己的审核都不保证 07:00 前做完。

### 2. 配音怎么做

网页版免费额度每月 8,000 积分，1 积分 = 1 字节。3–4 分钟一期要 3,000–4,000 积分，一个账号每月只够 2 期左右。
- 天天发要十几个账号。
- 半夜额度用完没人切，这期就赶不上 07:00。
- 多开免费账号轮换，还可能违反 Fish Audio 的服务条款。

| 方案 | 费用 | 声音 |
|---|---|---|
| a. 网页版 + 插件（现在） | 0 | 苏晓晓 S1，和首期一样；额度不够就停下等你切账号 |
| b. Fish Audio API，模型 s1（推荐） | 每期约 $0.05–0.12，每月 $2–4 | 苏晓晓 S1，和首期一样 |
| c. API 免费模型 s2.1-pro-free | 0 | 苏晓晓，但模型换成 S2.1，要先试听；有公平使用限制、不保证速度，请求可能被拿去训练 |

- 2026-09-27 查过官方定价页（docs.fish.audio「Pricing & Rate Limits」）：s1、s2-pro、s2.1-pro 都是每百万 UTF-8 字节 $15，s2.1-pro-free 免费；按量付费，没有月费和最低消费；预充值不到 $100 可以同时发 5 个请求，够用。
- 费用估算：首期配音文本 2,219 字节（927 字，配音 2:10）；3–4 分钟一期约 2,950–3,900 字节。
  - 每批只生成 1 个版本：每期 $0.044–0.058，每月 $1.3–1.7。
  - 1 个版本 + 约三成批次重配：每期 $0.06–0.08，每月 $1.7–2.3。
  - 每批 2 个版本挑一个（和网页版一样）：每期 $0.09–0.12，每月 $2.7–3.5。
  - 选版本用的语音识别是本机 faster-whisper，不花钱；除了配音，流水线没有别的按次收费。
- b、c 都要你在 Fish Audio 后台建一个 API key，自己设成 Windows 用户环境变量 `FISH_API_KEY`（我不经手 key）；b 还要充一点余额。
- 走 API 不用浏览器，配音从约 10 分钟缩到 2 分钟左右。
