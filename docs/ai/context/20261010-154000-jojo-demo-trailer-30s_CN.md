## 做法

- **录制**：照银魂 `tools/recorder.js`。本机 http 服务打开游戏（file:// 下片头视频画进画布算跨域）；测试器真实键盘通关；页面里从 WebAudio 总线（`G.audio.master / musicOut / sfxOut`）各接一路，片头 `<video>` 原声接进 BGM 轨；`captureStream()` 不传帧率；保活直流（1e-5）让没声音的轨也从 0 秒开始写（序章那次没加，音效轨仍对齐、只是尾巴少 3 秒）；画面上藏掉对话框 / 旁白 / 提示 / 互动提示 / 目标箭头 / QTE / 菜单（只换绘制函数，测试器照常读快照——所以序章那次测试器报了 goal_arrow_missing / fly_not_investigated，是录制模式造成的，不是游戏问题）。录的时候帧率 60 / 59。
- **配乐**：用户要“开头封面那个 bgm” = 完整版标题曲《STAND PROUD》（体验版包里不带）。librosa 和这台机器的 numpy 冲突，自己写的节拍分析：165.1 BPM、一拍 0.3634 秒；截 44.033–74.033 秒，副歌第一拍在宣传片 7.995 秒，30 秒落在歌里的静音上。
- **剪辑**：照银魂宣传片 v2 的逐帧合成框架；录像按最近邻取成 640×360（游戏界面原生）再整数倍放大；片头 / 序幕直接用 `op.mp4`、`coffin.mp4`。手法：冷开场黑边慢推、慢放、急停黑场砸「ゴ」+「替身 STAND」、副歌闪白震屏 RGB 错位每拍轻推、斜切三竖条（隐者之紫 / 红色魔术师 / 法皇之绿同屏）、左右分屏（火焰 / 残像）、调色、JoJo 式褐色定格 + To Be Continued + Logo。不剧透（不放入队、雪莉回忆、念写的 DIO）。
- 每轮先出 `sheet`（每 0.25 秒一帧）看构图，调了两轮入点（片头红眼、标题慢放不混进点名卡、漩涡 pose、必杀反色、Boss 切入、滚石阶、香港镜头去掉眼睛特写、十字火焰风暴切入）和三联屏（横条把人切成一截截 → 改竖条）。

## 注意 / 没做

- 《STAND PROUD》是商业歌曲，公开发布平台可能识别版权；要稳妥可换原工程标题曲重新卡点。
- 只做了横版 16:9；竖屏版（抖音 / 小红书）没做（银魂有竖屏版脚本可参照）。
- 没有人耳朵听过成片（只量了响度和两轨比例：音效比配乐低约 8.5 dB）。
