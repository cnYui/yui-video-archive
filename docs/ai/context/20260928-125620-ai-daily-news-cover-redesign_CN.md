# 《AI每日日报》封面改版：白底两行大字 + 鲸鱼娘右下 + 其余新闻小字（鲸鱼娘蓝）

日期：2026-09-28（东京 12:56）｜会话：DeepSeek AI 每日新闻速报

## 用户的要求（按时间）

1. 「当前视频的封面需要更换一下，日期去掉，因为和标题重复了，而且封面最重要的应该是在用户浏览的时候，把一条新闻大字呈现出来……准备三个版本，用鲸鱼娘的素材，封面中的角色素材也可以用不同的姿势，多一些变化。」
2. 参考 UP 主「通俗解释」（space.bilibili.com/1532444879）的封面，「风格很统一」：纯白底，两行大字（灰色铺垫 + 橙色钩子），一个火柴人站在底部。
3. 「角色形象可以放在左下角或者右下角，然后空白的部分可以放其他的新闻标题，用小字来呈现。」
4. 选定 **D 版**（角色右下、左边小字清单），再出三种配色（橙、鲸鱼娘蓝、另一种），选定 **鲸鱼娘蓝**。
5. 「当前分集中，还有一个昨天的视频，你也把封面换一下」：9/27 那期一起换。

## 结果

- 新脚本 `AI日报/skill/ai-daily-news/scripts/make_cover_white.py` 和模板 `assets/cover-template/cover.white.html`。
  - 1920×1080，4:3 是居中裁切 x 240..1680，所有内容都在裁切范围内。
  - 两行大字：第 1 行铺垫，第 2 行钩子，都按宽度自动缩小。
  - 鲸鱼娘：64×64 帧按整数倍放大（×9），不镜像。
  - 其余新闻：小字清单，标题是「今天还有 N 条」，最多列 5 条，多了加「……共 N 条」。
- 鲸鱼娘的姿势是拼出来的：动作帧 + 另一帧的眼睛矩形（素材包保证手不进眼睛区域 `patch_rects.eyes`，所以任何姿势都能换表情）+ 特效帧（`fx_emph` 感叹号、`fx_glint`、`fx_listen`）+ 可选的像素问号（颜色跟配色走）。
- 配色 `THEMES`：
  - `orange`：橙 #F5A21D
  - `blue`：鲸鱼娘调色板亮蓝 B #4A88DA，铺垫行用偏蓝的灰 #8A93AD。**这是默认配色，用户选定。**
  - `night`：视频底色藏青 #1B2340 + 金色 #FFC94D，角色背后加一圈浅蓝柔光。
- 情绪 → 姿势组 `POSES`，同一情绪按一年中的第几天轮换：

  | 情绪 | 姿势 |
  |---|---|
  | 吃惊 | 举手指 + 「!」、摊手、贴纸「?」 |
  | 开心 | 竖拇指 + 闪光、叉腰、挥手、拉炮 |
  | 疑问 | 托下巴 + 看右上 + 问号、侧耳、贴纸「?」 |
  | 认真 | 举手指 + 「!」、抱臂、手放胸前 |

  角色在右下角，所以不用 reach / point（会指到画面外）。13 个姿势都在 D 版里渲染检查过，见 `AI日报/_测试_封面_20260928/全部姿势_D蓝.png`。
- 接进流程：
  - `台本.json` 新增 `cover` 块：`{"item": 1, "line1": "铺垫 ≤10 字宽", "line2": "钩子 ≤8 字宽", "mood": "吃惊|开心|疑问|认真"}`。
  - `make_episode.py` 的 `validate`：没有 cover 块、item 越界、文案太长、mood 不对、写了日期，都会报错；超过建议长度只提示。
  - `daily.py render` 改为调用 `make_cover_white.py --from-script`。旧的 `make_cover.py`（日期大字版）留着不用。
  - 封面渲染失败会自动重试一次（无头浏览器偶尔起不来，这次出过一次）。
- SKILL.md 已更新：
  - 规则区加了封面规则。
  - 台本示例加了 cover 块，第 3 步写了 cover 的写法。
  - 第 6 步写明封面怎么生成。
  - AI 复核提示词加了「封面两行大字要和原文一致、不夸大」。
  - 第 8 步加了「换已发布稿件的封面」的实测步骤。
