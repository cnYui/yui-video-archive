## 写法

- 按技能 `way-to-agi-episode` 第 1 步（台本，用户要才写：口播体、披露式展开、事实查官方来源并记日期）和 `AGENTS.md` 的台本风格。
- 格式沿用研究生系列第 1 期台本 v1（`20260929-193326-ep1-script-v1-timeline-evidence_CN.md`）：句子后标 `[n]` 证据编号，文末列出处；【画面】【录屏】【待确认】【可删】；小标题带时长。这种写法是用户在那一期要求的，这一期要“论证”，正好合适。
- 结构（取代大纲 v1 的口播要点）：
  0. 开场一句 + 三个困惑（用 AI 写作业算不算学生思维 / 还要练判断力吗 / 摆脱之后做什么）+ 24.42% vs 24.94%；
  1. 学生思维的三个表现（找标准答案、单因素、不换位）+ 别当骂人话；
  2. 怎么来的（训练、制度、自己习惯了）；
  3. AI 会把它放大：标准答案太好拿（Bastani + 学生说法，回答困惑一）/ 没人教什么时候用 + AI 会讨好你 / 判断力更值钱、要靠经验练（斯坦福 + 一种解释，回答困惑二）；
  4. 三个动作（提好问题、练判断力、敢担责，对应复旦学生的回答），用“考研还是直接工作”贯穿录屏演示，5 段提示词；
  5. 摆脱之后做什么（创造价值、组织资源、练表达，回答困惑三）；
  6. 收尾一句。
- 只用一个例子贯穿演示；别人视频的观点用自己的话转述，口播里只说“有位 UP 主”，画面角落标出处。

## 这次重新核对的事实（一手来源，2026-10-01）

- **Bastani 等 PNAS 2025**：用 PMC 全文（PMC12232635）核对。近一千名土耳其 9–11 年级学生；练习时 +48% / +127%；撤掉 AI 后 GPT Base −17%，GPT Tutor 和对照组无统计差异；GPT Tutor 的提示词要求“给提示、不直接给答案”，并附老师给的解法和常见错误；**聊天记录显示 GPT Base 组多数时候直接要答案**。SSRN 页面 403，打不开。
- **斯坦福 Canaries**：2026-08-12 修订页。19%（一年前 15%）；调整主要通过少招年轻人，而非增加离职；作者称是早期描述性指标，不是因果估计。原文页面上**没有**“成文知识 vs 默会知识”这类解释，所以稿子里用宋一博士的解释，并写明“有一种解释”。
- **Anthropic 讨好（sycophancy）研究**：Anthropic 研究页 2023-10-23；arXiv 2310.13548（2025-05 修订）。五个主流 AI 助手都有讨好倾向，讨好是 RLHF 模型的普遍行为。
- 光明日报调查、光明网复旦那篇：沿用 2026-09-30 抓原文核对的结果。
