# 银魂游戏：手机 / 平板（触屏）版，加屏幕按键

- 时间：2026-10-06 18:50–19:50（UTC+9）。
- 用户原话：“你这个 fork 是来做将银魂这个游戏修改为手机端也能玩的横屏游戏的，请你添加按键，修改原始的 html 代码”。
  - 这个会话是从做长视频《欢迎来到 人人皆可做游戏的 时代》的会话分出来的（长视频那边的进度不在这里，见 `20261006-190000-gintama-full-recording-and-long-video-silent_CN.md` 和长视频目录的 README）。

## 结果

在手机 / 平板上横屏玩，屏幕上有按键；**不改剧情、不改战斗**，只把手指翻成键盘输入。电脑上双击 index.html 的玩法没变。

| 位置 | 按键 | 对应键盘 |
|---|---|---|
| 左下 | 方向盘（手指放上去、滑到哪儿朝哪儿走，8 方向） | ← → ↑ ↓ |
| 右下 | J 攻击（也是确认）、K 跳跃、L 防御（按住）、E 调查 / 确认（附近有人 / 东西时跳动） | J K L E |
| 右上 | ⏸ 暂停、⛶ 全屏 | Esc |
| 画面任意处 | 点一下 = 推进对话 / 跳过开场动画 | Enter |

- 按场景自动显示：对话 / 过场时按钮全收起（点屏幕继续）；连按 / 看准时机只留 J；菜单 / 选项留方向盘 + J / E，**也可以直接点选项**；自由走动 J、L 暗着；战斗全亮；手离开屏幕 2.5 秒淡下去。
- 暂停菜单多一项“按键大小”（小 / 中 / 大），记在这台手机里。
- 竖着拿出“请把手机横过来玩”，游戏停住。
- 操作说明页、几条提示文字在触屏下换成触屏的说法；按键名字（J K L E）和游戏里“按 J 停下转轮”“按住 L 防御”一致，所以没改词。
- 怎么在手机上玩：电脑双击 `游戏\手机试玩.bat`（局域网小服务器，支持 Range，iPhone 放视频 / 音频要用）→ 手机和电脑同一个 Wi-Fi → 手机浏览器打开窗口里印出来的网址（`http://192.168.x.x:8000/`）→ 横着拿，点右上 ⛶ 全屏（iPhone：分享 → 添加到主屏幕）。
- 电脑上想看按键：网址后面加 `?touch=1`（`?touch=0` 强制不显示）。

## 没做 / 没法测 / 要注意

- **真机没测过**：我只有 Chromium 的触屏模拟。手感（按钮大小、位置、方向盘死区）要用户上手后再调；三处最常调：`index.html` 里 `.tc-j / .tc-k / .tc-l / .tc-e` 的 `--x / --y / --s`、`touch.js` 里 `layout()` 的大小公式、`padMove` 里的死区（0.3）和角度（60°）。
- **iPhone 的声音是按 iOS 的规则写的，没真机验证**（`primeAudio`：第一次抬手时给音效各建一个元素静音点播、音乐用两个点过的元素轮流放）；iOS 的音乐音量调不了。iPhone 没有网页全屏，只能“添加到主屏幕”。安卓 Chrome 没这些问题。
- 16:9 的手机上方向盘会压住画面左下角的角色（战斗开场角色就在最左边）；已经做了：底色调浅、2.5 秒不碰就淡下去、可选“小”档。想彻底不挡，要么把画面缩一档给按键让位（会小 20%），要么做“浮动方向盘”（手指落在哪儿盘出现在哪儿）——用户用过再决定。
- 没做手柄（Gamepad API）、左手模式、按键位置自定义。
- 公开发布前：标题曲是商业歌曲翻弹、角色是同人形象；`手机试玩.bat` 只在局域网里用，没有把游戏放到公网。
- 坑（已写进 `流程复盘.md` 第十五节）：触屏的“用户激活”是手指抬起才算（音乐补放、全屏都要用 pointerup / click）；序章点开始后场景名是 `video` 不是 `world`；改了中文字符串要重跑 `build_assets.py font data`；Python 自带 http.server 不支持 Range（iPhone 放媒体要）；后台 `( … ) &` 会被工具杀掉；dcg 钩子会拦 `rm -rf`（临时目录不需要先删）。

## 最终复测（19:31）

- `touchtest.py` 在五个尺寸各跑一遍（844×390、640×360 = 16:9 小手机、1024×768 = 平板、667×375、915×412）：每个都是 58 项全部通过、0 页面报错。
  - 16:9 手机上按键压到画面的范围（`G.touch.safe`）：方向盘盖到 x≈86（画面宽 384），右下按钮从 x≈289 起，右上暂停 / 全屏钮从 x≈327 起；20:9 手机（844×390）只压 41 / 332 / 378，黑边够放大部分按键。
- 桌面键盘回归 `python tools\playtest.py prologue`（file://）：0 报错、32 句对话、走到第一章；桌面没有触屏时 `#tc` 整块 `display: none`，行为跟以前一样。
- 桌面行为有一处变化：鼠标点菜单 / 选项现在是“点中哪项选哪项”，点在空处不再算确认；点暂停菜单外面 = 继续游戏（原来点哪里都算确认当前项）。
- 手机试玩服务器（`serve_phone.py`）：本机回环上测过 Range（206 / 416、`bytes=-N`、`bytes=N-`）和启动提示；没有绑 0.0.0.0（会弹防火墙）。
