## 做了什么

1. **素材**（`素材/X平台视频/`，直接从 X 的视频 CDN `video.twimg.com` 下，链接取自 X 嵌入接口的 `variants`，和 TwitterSaver 解出来的同一个源；没走 TwitterSaver 页面）：Griffin 发布视频（2105704169009246248，1080p，108.6 s）、Elevare 客户案例（2104998304279048334，**取 1080p**，原片有 4K，演示区 1474 宽用不上，181.8 s）、Memories 介绍（2100277005841469469，是第 4 条推文引用的那条，91.6 s）、第 2 条推文是**图片**（盲测条形图，`…_benchmark.png`）。全部 ffprobe 核对过。官网页面区块用 Playwright 按 2 倍像素截图（`制作/capture_pages.py`，14 张 + 每张里要高亮的文字位置 `boxes.json`），在 `素材/官网截图/`。整个 `素材/` 不进 git。
2. **事实核对**（后台调研子代理，约 29 分钟，`台本/事实核对.md`）。**对台本影响最大的**：
   - 只有 **Griffin-Lite 研究预览版**，仅少数受信任测试者能用，不对客户开放、没上 Tavus 平台、无价格无日期（官方说解决安全问题后“很快”发布）。不能写“已上线 / 现在能用”。
   - “第一个人类交互模型”“第一个通过实时视频图灵测试”都是 Tavus 自称（官网只有一处带“据我们所知”）。**48% = 26/54，Tavus 自己设计和执行，参与者事先被告知对方是“另一位参与者”，页面没提真人对照组，不是经典（三方）图灵测试**；上一代 2.4% = 1/41（正文另一处写 “max 2%”、推文写 “<3%”，三处口径不一致，台本只写“41 个里 1 个”）。
   - NVIDIA VideoFDB 榜单页上确有 “Tavus Griffin Lite”，数字和 Tavus 页面吻合（生成 3.83 / 真人 3.92 / 次高 2.80；感知 3.73 / 真人 4.20），但**评审是语言模型**；Griffin 是榜上唯一端到端模型，生成赛道只有两个 NVIDIA 拼的对手；“15 个模型”其实是 8 个系统；榜单里 Griffin 响应延迟中位数仍比真人慢（生成 1.9 s 对 0.9 s）；官网的 0.43 秒只是画面生成器“音频→画面”延迟，不是回复延迟。**台本没用 0.43 秒、没用“37% ahead”（全页无解释）、没写“15 个模型”。**
   - 9 月 29 日 Phoenix-4.5 盲测（309 人，Prolific 招人，只比“哪个更自然”）、Memories 的 LongMemEval 93.4%（467/500，答题用了 gpt-5.6-sol 等第三方模型，低于 Mem0 自报的 94.4%）、Elevare 案例（案例页明写 Raven-1 和 Sparrow-2，无 Elevare 自己的成效数字，CDC 数字年份对不齐）**都不是 Griffin**，画面标签里写了“不是 Griffin”。
   - 外界反应以诈骗 / 伦理担忧为主（科技记者 Kevin Roose、参议员 Schatz 等），媒体多指出“样本小、自家实验、说法偏强”；没找到别家在先宣称视频图灵测试通过，但“全世界第一”不能写。
3. **台本**（`台本/录制稿.json`，zh / say / en 三栏；`台本/plan.json`，17 个场景）：开场（先看 3.4 秒 Vanessa 的脸再出标题）→ 先看演示（发布视频里的对白：Hassaan 和 Vanessa〔Griffin 驱动的 AI，新闻稿说法〕的“如果足够好，他们根本不用去想”“比个大拇指”“穿丑毛衣的是谁”“放慢呼吸”）+ 官网首屏 + 全双工示意图 → 再看成绩（面对面实验、VideoFDB 两条赛道、Phoenix 盲测，每处标“Tavus 自己做的 / AI 评审”）→ 现在能用（研究预览版的安全说明、Elevare、Memories，都标“不是 Griffin”）→ 以发布视频结尾（“maybe that’s the most real thing we could show them”）+ 链接卡。左栏目录 3 条（先看演示 / 再看成绩 / 现在能用）。画外音约 70 s（约 39%），其余是官方视频和官网页面。**这是第一条同时有“画外音”和“原片对白字幕”的片子**。
4. **引擎改造**（`制作/00_整片/`，复制自 openai-episode 模板，**改的是本期的副本，没动技能模板**）：
   - 配色 / 版式取自官网 CSS 变量（`--themes--background #f7f4ef` 奶油底、`terminal-black #140206`、`bubbletech-4 #ff6183` 亮粉、`floppy-fog-3 #b0a8d1`、`neon-field` 绿点；官网图表里实测绿条 `#00D22E`）：直角方框 + 墨黑边 + **硬投影**、编号小标签带绿点、衬线大标题；官网字体（Suisse / Perfectly Nineties）是商用字体，换成 OFL 的 Noto Sans SC / Space Grotesk / JetBrains Mono / Instrument Serif / Noto Serif SC（后两个渲染时在线加载并等加载完，加载不到会报 `字体没加载`）。字幕仍是项目的统一标准（中文 52 + 英文 30，y 922），只把颜色换成墨黑 / 暖灰、描边换成奶油色。
   - `build_timeline.py` 新增：①`dlg` = 对白字幕（按**原片时间码**写，自动换算成成片时间，进字幕带，前面带粉 / 黑说话人标签）；②`type: shot` = 官网页面镜头（截图 + 相机推拉 + 高亮框，时间可锚在某句配音的某个词上 `["N11b","41",-0.5]`，也可以写 `"end"`）；③默认对所有素材套 `SRC_CROP`（裁掉原片底部自带的英文烧录字幕，y 985 以下；裁成 16:9）。字幕重叠检查（画外音和对白不能叠）。
   - 说话人是按音高（男 / 女）+ 画面核对的（`制作/speakers.py`）；对白时间用能量包络 + 词级转写抠（识别器给“停顿后第一个词”的起点常常偏早）；成片混音里逐条对白用英文识别核对（`qa_dlg.py`，24 条里 23 条 ≥ 0.75）。

## 踩坑

- **封面三个“设计过”的版式全被否**：用户要的是最直白的做法——**成片里的真实画面截图 + 箭头指主角 + 一句短钩子大字**（“这是AI！”）。以后遇到“第三方模型发布 / 画面里有一个明显的主角”这类视频，第一个候选就做这种，再配 1–2 个别的；不要先交“48% 大数字卡片”“官网底图 + 大标题”这种设计稿。用户贴的截图是 1248×703 的屏幕截图、太糊，**回原片抽同一帧、按封面尺寸重渲**（见上面第 6 条）。

- **第二次去 Fish 重生成 v2 配音，没做成**：我的标签和用户的 B 站窗口共用 Chrome，用户当时在**全屏看视频**（时光代理人第 3→4 集），我的标签一直是 `visibilityState: hidden`、视口一度缩成 270×88、截图超时。试过在隐藏标签里硬做：CDP 鼠标点击不被页面接收，但页面脚本的 `button.click()` 有效（换声音、选 S2 Pro 都成了）；**可是 `computer type` 在隐藏标签里会丢掉全部 ASCII 字符（AI、Phoenix…）和换行（整稿变成一个区块），合成的 `paste` 事件也不被编辑器接收**——拿去生成会是错稿，所以停了，没生成、没花积分；项目里留了一个被弄乱内容的“未命名项目”（用户可删）。**没有抢用户的前台**，把 Chrome 还给了另一个会话。要做 v2 得等用户的视频窗口让出来（或用户说可以盖）。

- **Chrome 窗口和别的会话共用，最后 navigate 的标签才可见**：第二次去 Fish 时，我的标签 `visibilityState = hidden`、视口缩成 270×88、截图超时（用户自己的 B 站视频窗口全屏在前台，另一个会话又把它的标签导航到 B 站投稿页）。**不要为了自己的标签去抢前台**（人家在等用户拖文件）：`SendMessage` 约时段，对方说“Chrome 可以给你了”再 `navigate` 到前台用。
- **英文专名读不准是这个声线的常态**，而且 Tavus 这种词会被读成别的词。以后写配音稿：先用英文识别器（`language="en"`）听一遍专名，读歪的直接写中文音译。本期是生成之后才发现，多花了一轮。
- ASR 分数的两个假低分：数字（识别器输出 54，稿子是“五十四”）和繁体输出（`large-v3-turbo` 常给繁体字，和稿子的简体逐字比就低）；`medium` 加 `initial_prompt="以下是普通话的句子，使用简体中文。"` 做第二意见更好用。
- 原片自带烧录字幕：裁掉（`SRC_CROP`），不要盖——背景是真实画面，盖不干净。
- 对白字幕里“停顿后第一个词”的识别起点偏早 0.3–1 s，要用能量包络找真正开口的位置；一句话的断点要按**说话**的位置断，不是按语义断（E04/E05 错位 0.5 s 是这么来的）。
- 官网页面截图：吸顶元素要隐藏、一路滚到底触发懒加载、等动画放完；要截“没有文字的底图”就把文字容器 `visibility: hidden` 再截（`HIDE_EXTRA`）。
