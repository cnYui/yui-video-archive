## 发现的问题（按优先级，已发给移植会话）

1. **章末提前清板**（C1，整片确认）
   - 每场在 `sc.end − 0.36 − LEAD` 淡出，而最后一句要到 `sc.end − 0.6` 才说完。所以每章写在板上的结论，在声音说完之前 0.5–0.9 s 就没了，下一章标题已经开写。
   - 例：「Jev = 通用的判断模型」118.3 s 还在，118.9 s 已经换成“二、”。
   - 可选改法：本场画面留到最后一句说完后 0.2 s 再淡出，下一场从 `max(本场起点 − LEAD, 上一场留到的时刻)` 开始。
   - 代价：章节标题的提前量缩成章间停顿那么长（约 0.5 s）；场内内容仍然早 1 s。
   - 要不要这样改，建议问用户。
2. **疑问 → 目录的衔接**（C2 / D7）
   - 疑问块在“这期视频，就把这三个问题讲清楚”刚开口时就整块擦掉。之后白板空约 1.5 s，只有子任务补的一支箭头；右上目录以灰字淡入。
   - 建议：疑问块留到这句说完，或者做成“飞进目录”。
3. **页内翻页没有规则**（D1 / V1）
   - 照文档“scenes.js 照声音写时间”，擦板挂在下一句开口时。画面整体早 1 s，所以每页最后一句在声音说到之前就被擦掉。
   - 子任务的解法：翻页时刻 = 上一句声音结束 + LEAD − 0.15，新一页从翻页后 0.3 s 开写。
   - 建议写进 visuals.md，或者提供 `c.flip(seg)`；`check_layout` 也要查“擦板前没写完 / 显示不到 0.8 s”（C3）。
4. **写字窗固定、超出不报**（D2 / C6–C8）
   - 以下这些不加速，约 0.3–0.4 s 一个字：
     - `c.hand`；
     - handNode 框里的字；
     - statement；
     - questionCards / pointList / summary 的标题。
   - 超出时间窗只会悄悄顺延：63 行顺延 ≥ 0.25 s，最多 1.5 s。只有拖到场景淡出才报 hand-late。
5. **check_layout 不查内容之间的重叠**（C4）：子任务的第一版有 4 处重叠，都没报出来。
6. 小项：
   - handEllipse 外扩固定，圈小值会盖到邻行（C5）；
   - handNode 的 `until` 和 `c.hand` 含义不同（D3）；
   - 唯一的完整示例 DEMO_S04 放在可能被移走的 `_skilltest` 里（D4）；
   - `c.P` 找不到短语时不提示（D9）；
   - 手写组件不登记内容提示点（D10）；
   - 胶带压住“示意”（C9）；
   - 单线字体的数字 1 像 I（V14）。
