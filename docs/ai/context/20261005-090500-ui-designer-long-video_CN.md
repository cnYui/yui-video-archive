## 踩到的坑 / 新摸出来的
- **Fish 编辑框键入**：一次 `computer type` 超过约 25 句就会报 CDP `Input.insertText timed out after 30000ms`，但**文字其实已经写进去了**——别重打，等几秒用 JS 数 `div.content` 的个数；每块之后核对。最后用 `crypto.subtle.digest('SHA-256', …)` 对全部块文字的哈希和台本 `say` 的哈希（`'\n'.join` 后）比，一致才点“生成”。`javascript_tool` 要用顶层 `await`，别写 async 立即函数（返回 `{}`）；输出里出现带查询串的 URL 会被拦（`BLOCKED: Cookie/query string data`），别返回 `img.src`。
- **Chrome 窗口被最小化**时我的标签是 `hidden`：`docs/ai/tools/chrome_win.ps1`（SW_RESTORE + Alt + SetForegroundWindow，用完最小化 / 关掉标签）。关掉我最后一个标签，标签组和窗口一起消失。
- 多个会话排队用 Fish / 渲染：开工前 `SendMessage` 约时段，三个会话都回了“你先用”；我先抢 Fish 窗口把配音做完（约 25 分钟），再把 Fish 让出去，渲染开始 / 结束各发一句。
- **`图片的真实内容要对着台词看**：文章的文字描述和图不完全一致（上面三处）；做“按图讲解”的视频，台词里每个“左边 / 右边”都要回到图里核对。
- 规则对比图是宽横幅（宽高比 4–9:1）：并排 / 叠放时每个面板只有约 0.65 倍，UI 小字在手机上看不清 → 加了“聚焦放大”视图（讲到哪边就把那个面板推到铺满，约 1.3–1.9 倍），讲结论时缩回并排。放大不到 1.25 倍的图（近方形的）不做，改成另一边变暗。
- 相邻的高亮框（三个并排的按钮）标签会撞在一起；标签位置改成“右 → 上 → 下 → 左”试，避开别的框和已放的标签。
- 书官网首页的目录默认折叠，截完整目录要先点 “See all the chapters in the book”；首屏用 1440 宽的真实桌面视口（800 宽是手机排版，没有“From the creators of Tailwind CSS”那一行）。
- Windows 下 heredoc 里写 `\2026` 这类路径会被 Python 当成八进制转义（`MAT` 路径里混进了 `\x82`）：路径用 `chr(92)` 拼，或者写成文件再运行；bash 里夹大段带单引号的 JS 的 heredoc 会被工具误判（`unexpected EOF`），改成用 Write 写成文件再 Python 处理。
- 官网同一页上销量写 “30,000 copies” 又写 “20,000 people”，不一致，没引。
