# 日报竖屏版（10/5 整期转 1080×2340 短视频）：做成片（2026-10-05）

接 `20261005-083000-daily-vertical-short-layouts_CN.md`。用户看了三种排版样图后回：“**用标准竖版**”（= ① 素材主导：技能版式 B 单框 + 边框 6）。时长、3:4 封面、B 站合集这三个问题他没答，我按下面的默认继续做，并在交付包里再问一次。

## 默认（没问到的，交付包里列出让用户改）

- **时长 = 整期**（10/5 日报横屏 5:53 含 3.8 s 片头 + 4.8 s 片尾；竖屏不要片头片尾，t = 0 就是开场第一句，最后一句说完留 0.8 s，共 337.87 s = 5:37.9）；没精选、没拆 8 条。
- 声音**沿用日报的苏晓晓配音**（`2026-10-05/制作/build/voice_main.wav`，不重配、不换温柔男生）；`t = 0` 就是日报开场第一句。
- 不加悠一片头片尾；第一帧 = **原封面**（16:9 原图居中放进边框 + 背景，用户：“封面不要动”）；金句说完再留 0.8 s 收尾。
- 背景随机挑到 `pattern_orange.png`（`制作/00_整片/bg.json`）。
- BGM = 系列 BGM（`AI科普/素材/音频/bgm.wav`，程序合成 lo-fi 轻爵士，492 s，整期够用不循环），**比配音低 14.5 dB**（原始 −20 LUFS，床 ≈ −30.5 LUFS），没人说话的空档抬 +5 dB，头淡入 1 s、尾淡出 2 s。

## 做法（引擎在 `AI日报/短视频/01_日报竖屏版_1005/制作/00_整片/`）

不是用技能的 `new_short.py` 引擎模板，而是照它的页面模型**自己写了一套**（日报的素材是“10 个场景 + 66 个配音段 + 逐帧口型”，和模板的“上下框 + 原片抽帧”对不上）：

| 文件 | 作用 |
|---|---|
| `build_vertical.py` | 读日报 `timeline.json`（10 场景 S01 开场 / S02–S09 八条 / S10 回顾；66 段，每段 `subs` zh/en 起止、`expr` 动作、`mouth` 逐帧 0/1/2）+ `台本.json`（要点、`point` 下标）→ 出 `tl_v.json` / `tl_v.js`。`NEWS_V` 给每条新闻定标题 t1 / t2、来源角标、截图文件、截图上橙框圈出原文的坐标 `hl`、大数字卡 `bigs`；`MERGE` / `CUTS` 手动合并 / 指定字幕断点；`TAIL = 0.8` |
| `index.html` + `engine.js` | 1080×2340 页面：标题 280–570（kicker 30 + 黑 76 + 橙 60）、截图框 40/770 1000×569（边框 6：7 px 黑边 + 14 px 橙色硬阴影 + 黄贴纸）、字幕 y1498（中 52 / 英 30）、下面要点卡 / 大数字卡 y1660、鲸鱼娘站在卡片左边、10 段进度条 y1912；`renderAt(t)` 是纯函数，帧 0 显示封面（`cover0`） |
| `render_v.py` | `--check` / `--stills` / `--stills-segs`；N 路 Playwright 截 JPEG 管给 ffmpeg libx264 crf16，分段再拼接；`RENDER_WORKERS` 控制路数（本次 3 路：另一个会话的 ffmpeg 在吃 CPU、空闲内存 5.7 GB） |
| `mix_v.py` | 配音（70 Hz 高通 + 两遍 loudnorm −16 LUFS 线性）+ BGM（上面的床 / 抬升）→ 整体 −16 LUFS，−1 dBFS 软限幅 |
| `finish_v.py` | 成片（只挪 moov）+ 540×1170 手机预览 + 三份 SRT（时间从 0 起，没有片头偏移）+ 响度 |
| `qa_sync.py` | 每帧口型和成片配音能量按偏移 −8…+8 帧做相关，最佳偏移应为 0 |

- 鲸鱼娘：用日报同一套像素素材包（`AI科普/素材/角色/大肥鱼像素素材包/素材/sprites`）的 idle 呼吸循环 12 帧（时长 600/140/400/140/140/520/140/60/150/70/140/140 ms）× 嘴型 m0–m2 × 表情变体，口型直接用日报 `timeline.json` 的逐帧 `mouth`。
- 字幕：中英双语，按 `bilingual_std.split_pair_aligned`（Way to AGI 的标准库）重拆，中文 ≤ 17.5 个单位、英文 ≤ 60 字符、≤ 940 px；共 167 条；**手动断点**防止把词切开（“智能|体”“提示|词”）：`MERGE` 把几句短句合起来，`CUTS` 指定“中文锚点 + 英文锚点”。
- 来源截图框：日报现成的 `制作/assets/snaps/news_0N.png`，橙框圈出原文那句（每条一组坐标，截图尺寸 × 显示缩放要乘进去）；开头清单 4×2 行、回顾打 ✓ 逐条出现。

## 结果

- 成片 `AI每日日报_1005_竖屏版_成片.mp4`：1080×2340、30 fps、337.87 s（10136 帧）、32.1 MB、−16.0 LUFS、LRA 1.9、真峰值 −3.3 dBTP；H.264 `yuvj420p`（截图管线的全幅度范围，和已发的几条短视频一样，没动）；手机预览 9.3 MB。
- 渲染：3 路、302 s、0 页面报错（`__ERR` / `__WARN` 空）。
- 检查：静帧逐个看过（开场清单高亮、8 条新闻的圈框位置、大数字卡、回顾 ✓、第 0 帧）；成片按 14 个时间点抽帧联系表看过；字幕最宽 934 px（上限 940）；口型 × 配音能量最佳偏移 0 帧；音频时长 = 片长。
- 简介 1998 字（≤ 2000，去掉了章节列表和一段备注）；标题 3×4 `check_titles.py` 全在限内。

## 踩的坑

- 用 `scrollWidth` 量文字宽度永远 ≥ 容器宽度，要用 `Range.getBoundingClientRect()`（引擎里的 `textW`）。
- 第一版 Gemini 截图的橙框太小：把截图当 1:1 坐标读，忘了显示缩放；改成 (26, 64, 1116, 206)。
- ffmpeg 管线名字里带中文的相对路径在 bash 工具里被弄坏一次，改用 PowerShell / 绝对路径。
- 前台 `sleep` 被拦（用后台命令 + until 循环等渲染）；`rm -rf` 被 dcg 钩子拦（没绕）。
- 另一个会话（“短命令”）问要约 Chrome + Fish 15–20 分钟：这个会话没用 Chrome / Fish，已回复。
