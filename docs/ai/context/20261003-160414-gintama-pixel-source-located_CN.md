## 做成游戏的路线（待用户定）

1. **网页版（HTML5 Canvas）**：观众点名要“能分享 html”。需要一个烘焙脚本：用现有 `draw_char` / `render_sprite` 把 42 个角色的姿势帧导出成 PNG 图集 + JSON，背景导出成图层，配乐音效转 ogg；游戏逻辑（移动、碰撞、攻击、关卡、Boss）用 JS 新写。素材几乎全现成。
2. **Python / pygame**：直接复用引擎，384×216 的画布小，实时跑得动；缺点是分享要打包 exe。
3. 玩法候选：横版动作（银时闯关，章节 = 红樱篇 / 吉原炎上篇 / 银之魂篇，Boss 是似藏 / 凤仙 / 虚，过场用现成场景）；互动剧场（现有 15 个场景当过场，插入吐槽时机、躲避等小游戏）。
