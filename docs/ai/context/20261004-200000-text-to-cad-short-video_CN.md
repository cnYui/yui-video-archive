## 踩点 / 新规律（已补进技能）

- `pageShot()` 默认铺满整个场景，一个场景里连放几个页面会互相盖住 → 模板 `scenes.js` 加 `opt.t0 / opt.t1`，`layout.md` 写了 `mid()` 用法和 `ranges2` 的 hold 占位。
- 1 fps 联系表的秒数比真实切点早 0.2–0.5 s：灵巧手 17.2 s 才切走、机械臂 26.4 s 才开始，段首漏了 0.2–0.4 s 别的镜头；已改用 8 fps 逐帧表定切点。
- 演示视频被加速过：聊天面板里的计时是诚实性证据，做成“定格 + 高亮框”的特写。
- 7 月那条演示跑在 Claude Code 里（屏幕上是 `.claude/launch.json`、Sonnet 4.6），不是 Codex；台本里分开说。
- 故事工作室时间线上的 1:32 不是真实时长（真实 69.2 s）；多会话同时用 Fish 时 `segments (N).zip` 的编号会被占，用 `metadata.csv` 的文字核对。
- `render_all.py --concat` 默认按 4 路找分段，3 路渲染后拼接要带 `RENDER_WORKERS=3`。
