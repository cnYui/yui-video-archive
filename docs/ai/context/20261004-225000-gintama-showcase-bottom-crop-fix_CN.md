# 银魂宣传片 v2 底部裁切复查与修复

用户提供截图指出冷开场底部中文字幕被画面裁切，只剩半行。逐镜头检查发现根因是 `build_showcase_v2.py` 对多个镜头统一做 2 倍中心裁切；这会切掉源画面底部对白字幕和角色脚部。三联屏还会对已放大的画面再按列裁切。

## 修复

- 将近景类镜头放大从 2 倍降到 1.15 倍，并将取景中心略向上移，优先保留底部字幕和角色脚部。
- 三联屏及多段快切改为完整保留 16:9 源画面，再按 640 像素列宽排布，不二次放大裁切。
- 逐镜头中点拼图复查，冷开场、废刀令、虚、高杉、定春和终章段落均能看到完整底部字幕 / 角色区域。

## 验证

重渲染后须抽查整片关键帧和输出时长，并确认底部字幕、脚部未被切掉。原始录像与 GPT 版保持不变。
