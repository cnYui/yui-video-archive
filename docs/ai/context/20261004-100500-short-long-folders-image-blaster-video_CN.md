> 你用插件下载一下相关的视频，准备用来做短视频的素材，同时你在当前项目的所有不同分类的文件夹下，都新创建短视频和长视频两个文件夹，划分开来，素材可以公用

给了两个链接：https://x.com/liambraus/status/2106383261089849825 和 https://github.com/neilsonnn/image-blaster 。

## 做了什么

1. **下载视频**：Chrome 插件打开 AGENTS.md「常用网页」里的 SaveTwitter（https://savetwitter.net/zh-cn3），粘贴推文链接，解析出 720p / 360p / 270p 三档。
   - 没点页面上的下载按钮（广告多）：用 JS 读出链接，JWT 里就是 `video.twimg.com` 官方 CDN 的直链，`curl` 下载。
   - 结果：`独立视频\素材\2026-10_image-blaster\liambraus_2106383261089849825_720p.mp4`，1280×720、h264 + aac、126.7 s、20.5 MB，ffprobe 核对过有音轨；抽帧看过是 image-blaster 的演示。
   - 仓库本身没有视频（0 个 release，README 只有一张图，匿名访问 403），所以“相关的视频”只有推文这一个。
2. **建文件夹**：八个视频合集目录各建 `短视频\`、`长视频\`：AI实操、AI日报、AI科普、AI震惊瘫坐时代计算机研究生必须掌握的技能、Claude Code相关、OpenAI相关、Way to AGI、独立视频。
   - 没建的：`真人素材`、`星轨`、`游戏素材`、`声音克隆素材`、`B站互动`、`参考分析`、`死神vs火影`、`docs`（不是视频合集）；顶层 `短视频\`（另一个会话今天建的短视频技能，里面还没有 SKILL.md，没碰）。
   - 现有各期目录没挪进去：技能脚本、日报计划任务写死了路径。
3. **素材放哪**：用户说“素材可以公用”，所以放合集层 `素材\`，不放进 `短视频\` / `长视频\`。这条视频还没定属于哪个合集，暂放 `独立视频\素材\`。
4. AGENTS.md「目录结构」下加了一条规则，README 写了来源和挂名说明。
