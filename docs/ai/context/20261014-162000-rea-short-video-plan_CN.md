# REA 设备协议短视频制作计划

用户要求：搜索 REA 仓库，直接在线阅读代码，不克隆；制作一期短视频；使用本地模型配音；下载涉及的 X 帖子图片作为素材。

仓库已确认为 https://github.com/morluto/rea ，GitHub API 查询时 218,376 Star，MIT。用户提供的 12 万数字来自旧时点，因此稿件改为当前约 21.8 万；三天增长量未获得独立时序证据，不采用。

重点讲厂商 App 背后的设备协议：ADB 获取 APK、网络抓包对照代码、固件解包接 Ghidra、证据交给 Claude Code / Codex 后编写控制端。必须区分工具链可做的调查和自动还原所有设备的承诺。给定 X 帖子实际链接到蓝哥 AI 的恐龙游戏教程，空调 / AR 眼镜案例需要另找原帖；未核实前不把它归为 REA 的已完成实测。

制作归入独立视频：1080×2340、30 fps、单框、真实页面和 X 图片、统一背景与框版封面、双语字幕、BGM，结尾留 0.8 秒，不加片头片尾。封面三候选各三比例，标题三候选各三平台。

配音复用 AI日报 的 local_tts.py 和本机 Qwen3-TTS-12Hz-0.6B-CustomVoice，原速；等当前日报 TTS 进程结束再载入。按句缓存，依据音频实测时长制作时间轴。

交付前核对：代码和来源证据、字幕宽度与场景覆盖、逐段静帧、音轨识别、成片分辨率 / fps / 时长 / 响度，以及第 0 帧封面。此次未授权发布。
