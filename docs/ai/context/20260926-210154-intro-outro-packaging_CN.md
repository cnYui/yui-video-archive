# 片头片尾动画（UE）

时间：2026-09-26

## 需求（用户原话要点）

- 片头：简单的科技符号或 AI 图标转场，名字 UE 出现一下；3–5 秒，不要太长。
- 片尾：展示本期素材来源、拍摄设备、剪辑设备、需要致谢的人，最后感谢观众看到最后；3–5 秒。
- 片尾要有可编辑的动画展示，例如：拍摄：Pocket 4P / 剪辑：ChatCut / 视频剪辑模型：Opus 5.5；"感谢大家看到最后"写在屏幕上。

## 技术方案

- 每段动画是一个 HTML 页面，由 `render.py`（Playwright + ffmpeg）逐帧渲染：每帧先暂停所有 CSS 动画并定位到时刻 t，再调用 `window.renderAt(t)`。每一帧都是确定的，不会因为机器快慢掉帧。输出 1920×1080、60fps、H.264。
- 片尾内容数据化：`outro/data.json` 里 `items` 是 1–6 条"标签 + 内容"，另有 `closing`（结束语）和 `signature`（UE）。改文字后重新渲染即可。`outro/data.stress.json` 是 6 条长文本的压力测试。
- 片头数据：`intro/data.json` 里有 `name` 和 `tagline`；tagline 默认为空，可以填"原LAI如此"。
- 字体：思源黑体（Noto Sans SC）、Space Grotesk、JetBrains Mono、Orbitron、Unbounded、站酷快乐体，全部是 SIL OFL 1.1，可商用。刻意不用微软雅黑：它用在视频里有商用版权风险。
- 设计与技术规范：`CONTRACT.md`。

## 制作流程（工作流 run id `wf_8d52f2cf-928`）

1. 三个方向并行出片：
   - A 积木拆装：明亮扁平，符号积木拼合后"拆开"露出 UE。
   - B 神经电路：深色高级感，电路线汇聚、描画出 UE。

2. 两位评审（品牌与观众吸引力 / 动效工艺与可读性）看渲染画面打分，选出胜者。
3. 精修胜出方案 → 对抗式 QA（时长、可读性、条目自适应、转场顺滑度、字体、确定性、安全区）→ 修复。
