## 续接顺序

1. 恢复 Chrome / 浏览器连接，确认 B 站、抖音、小红书、视频号登录态。
2. 依次打开四个发布页，上传当前成片和对应封面，填写标题 ①、简介、话题、声明；四个平台均不选合集，视频号不显示位置。
3. 每个平台提交前读回标题、简介、声明和封面状态，再点击发布。
4. 发布成功后回写 `投稿信息.json` 的 `published`，并新增一份带时间戳的发布记录。
