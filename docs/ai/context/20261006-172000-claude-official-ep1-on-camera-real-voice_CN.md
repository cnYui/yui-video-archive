## 踩坑（下次直接用）

- **官方课视频里讲师的脸 = 不能用**（这期画面规则：只用屏幕 / 动画镜头）。每个官方视频的“安全段”要严格按已核过的清单（写在 `计划.md` / 本条 script_data.py 注释里）：c4 只有 22.4–30.4、43–52、81–86.6、88.9–101、104.5–110.5、112.5–115.9、117.1–119.4、122.5–123.7（**119.4–122.5、110.5–112.5、86.6–88.9 是讲师的脸**）；c6 只有 13.1–15.7、20.2–27.5、29.6–34、43.2–52.4、102.9–108.2、113.1–117.6、121.3–125.5、176.9–183.8、190.5–195.8（80–85 s 中间会切到讲师）；c8 的 59–75.5、84.2–90.8、98.6–101.0。我先靠 3 秒一帧的联系表“推断连续”，结果有 4 处露脸；**加了 `制作\00_整片\scan_faces.py`**（OpenCV Haar 每 0.2 s 扫一遍抽好的素材帧，脸宽 ≥ 90 px 的连成段打印）——**每次改选段、渲整片之前跑一遍**；它会把鼠标手形光标当成脸报 1 次（S02 24.4 s），不用管。
- `gen_ep.py` 的 `w`（权重）= 这一段占场景的秒数，**素材比份额长就截断（不会变速）**，比份额短先放慢（最慢 0.75×）再定格补；想让镜头跟着他说的词走，就把 `w` 写成“他说到这里的秒数”（S38 怎么用上它就是这样排的）。
- 全片 36% 的时间是说明卡（S07 / S14d / S17 / S19–S24 / S35 / S36），卡片开头别留空：第一个元素放在这一行开头，不要等“关键词”（S07 先写“聊天窗口”再换“顾问”）。
- `stills\` 里有上一版（255 s 草稿）留下的同名静帧：看静帧要认文件时间，或先清空再渲。
- 渲染时本机另有银魂游戏录屏（playwright 实时录），渲染用 `cmd /c start /B /BELOWNORMAL python render_all.py`（`RENDER_WORKERS=3`，空闲内存 4–5 GB）。
