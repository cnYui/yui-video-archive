## Way to AGI 候选

1. **成本账**（推荐先做）：一次成功 / 来回改几轮 / 做成游戏，各记一笔真实用量；顺带回答 high / xhigh / Max 差多大。对应选题池第 3、4 条；现有口径“6 分钟视频约占一周 20x 额度的 5%~10%”升级成完整账本。画面用真实用量页面录屏，不做文字卡片。
2. **同一句话许愿，换模型 × 换档位**：Opus 5.5、GPT 系（观众点名 astra）、DeepSeek；Opus 再跑 high / Max。先定公平规则（同提示词、同重试次数、同时长上限），失败也放；只报结果，不下“谁更强”的结论（和现有回复口径一致）。对应第 5、4 条。
3. **升级挑战**：把“许愿”推到极限，画面复杂度逐级升（景深镜头、3D、人物动作），最后一级做成能点开就玩的 HTML 游戏，链接放简介。对应第 5、7 条（观众要“能玩的”“能分享 html”）。
4. **代码做视频有几条路线**：canvas / SVG / HTML 逐帧 / Remotion / Manim 同一段 10 秒各做一遍，比成本、一致性、可修改性；落回 AGI 主线（AI 不直接出像素，而是写出像素的程序）。对应第 2 条。
5. **一个人用 AI 运营多个合集**（元视频，选题池里没有，我加的，讲不讲由用户定）：日报凌晨自动抓取 → 配音 → 渲染 → 定时发布，评论回复 routine，AGENTS.md 当记忆；要讲失败（配音放错位置叠了四个声音、漏选合集）。观众一直在问“用什么做的”，这是完整答案；“被观众看出回复是 AI 起草的”（是否公开说明还没定）可以做钩子。

## CS 研究生系列候选

按“评论热度 + 对研究生的独特价值”重排，不再按原大纲顺序：

1. **回应篇**（5–8 分钟，趁评论热度）：《关于“别再用 VS Code”，我来回应你们的质疑》。承认 VS Code + Claude Code 插件当然能用，把立场说准（工作台的中心换成了智能体；看 diff、调试、Jupyter 仍然会用 VS Code）；先决定第 516 行那句改口还是坚持；不做横评，用“我自己的真实用法”。也可以折成第 2 期开头 60–90 秒。
2. **原大纲第 2 集：国产模型 API 接进 Claude Code / Codex**：给“稳定用上”这个最大需求簇（累计 23）一条合规答案——不用订阅、不碰中转站，用官方兼容接口；base_url / key / model 三件套、key 不进仓库、设用量上限、为什么别用来路不明的中转（背后是什么模型无法验证）。录前按最新版实测（大纲里已写）。
3. **验收篇：AI 写的实验代码，你敢放进论文吗**（原大纲第 3 集 git 扩成）：回答“不审核吗”；git 当后悔药、diff 怎么看、让 agent 写测试和对照 baseline、固定随机种子、实验记录写 commit hash。研究生独有的痛点，也是和一般 AI 编程教程拉开差距的地方。
4. **（新）一句话配好深度学习环境**：conda / CUDA / WSL2 / Docker 的坑，前后对比直观。这是我的判断，不在选题池里。
5. **（新）论文写作流水线**：LaTeX + 逐条核对 BibTeX（DOI / arXiv / DBLP）+ 编译报错自动修 + 论文级图表；卖点是“不让它编引用”。要查各会议 / 学校对 AI 使用的披露规定，写进片子。也是这个系列从“写代码”扩到“做研究”的一步。
6. 后面几集：上实验室服务器（SSH、tmux、查空卡、rsync）、上下文管理（拿用户自己的 AGENTS.md 当案例，它已经长到 14 万字符，怎么压缩；真实且少有人讲）、大结局（从一篇论文到第一张结果图）。

建议顺序：回应篇 → 国产模型 → 验收篇 → 环境 → 服务器 → 写作 → 上下文 → 大结局。
