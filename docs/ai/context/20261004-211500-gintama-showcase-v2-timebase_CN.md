# 银魂宣传片 v2：源时间基准修正

v2 方案里的镜头时间是从三组原始 WebM 录像定位出的时间；当前目录的 `2026-10-04_精彩片段` 是再剪后的独立短片，时间基准从每个短片 0 秒重新开始，不能直接把原始录像秒数当作短片秒数。第一次逐帧渲染在“全江户集结”镜头请求 79.5 秒时越界，证明了这点。

合成脚本已改为：每个精彩片段先一次性解码为 60 fps PNG；取帧时根据该片段实际时长把源时间夹到最后一帧，避免关键帧 seek 和越界造成黑屏 / 0 帧。后续需要把原始录像时间重新映射到精彩片段相对时间，才能让每个动作精确落在方案指定画面上；当前版本先保证时间轴、画幅和音轨可验证。
