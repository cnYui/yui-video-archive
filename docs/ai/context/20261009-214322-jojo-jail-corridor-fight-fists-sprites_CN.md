# JoJo 序章拘留所改版：格挡判定、拳影墙、铁栏前后景、警帽和荷莉的头

用户 2026-10-09 晚拿三张序章截图反馈：

1. 教学第 3 步「火柱躲不开——按住 L」：按住 L 挡住了也进不了下一步。
2. 紫色拳头（连打拳影墙）画在人物下面，应该在替身面朝方向的前面；而且别的角色也在用这套紫色拳头，只有主角替身该有。
3. 铁栏没有前后景：除了主角，其他人都该画在铁栏上面；打斗的时候主角应该从铁栏里出来。
4. 追问：狱警的帽子和妈妈（荷莉）的头是不是也错位了。

游戏目录 `游戏素材/JoJo/游戏/`（整个目录被根仓忽略，没有提交）。

## 查出来的原因

| 问题 | 原因 |
|---|---|
| 第 3 步过不去 | `MR_FLAME_JET` 的 hazard 没写 `once`，默认 `once: true`：一道火柱只判一次，教学要连挡 5 次 = 连挡 5 道火柱（约 20 s）。另外 `fxActive: 'fire_jet'` 只拿到 x / y、没有 x0 / x1，火柱根本没画出来，`flashOnStart` 也没人读 |
| 紫色拳头在脚边 | 拳影墙挂在本体 `(x + 24·facing, y − 22)`，是本体腰 / 腿的高度；替身的手臂在替身图高一半处 |
| 别人也用紫色拳头 | `startRush` / `C.rush` 一律放 `fx.rush`，`fist: r.fist ‖ a.standId`；别的替身图集没有 `fist` 动作，回落到紫色 `FIST_GRID`（阿布德尔、波鲁纳雷夫、`bossFinish` 收尾都中招） |
| 连打火花看不见 | `clash_sparks` 认 `cx / cy`，调用处传的是 `x / y` |
| 铁栏盖住所有人 | 地图前景层在所有角色之后整层画 |
| 警帽飘走 | `art_npc.ka2` 的 `hats` 是整格坐标（头在 (8, 6)），警帽写成 (-1, -1)，落在格子左上角 |
| 荷莉的头 | 不是重烘造成的：游戏里的图和原图集逐像素相同。原工程 `h_frame` 把 15 px 宽的头放在 x 5（身体中线 16），头发团整体在身体后面约 4 px |

## 改了什么

- 教学战挪到铁栏外的走廊（用户：“打斗的时候主角应该从栏杆中出来”）：
  - 新增序-3b `breakout`：阿布德尔「那就由我把你拖出来吧！」之后，「……别小看我。」切入（原 `jail_bars` 标题）→ 白金之星掰开铁栏 → 承太郎从缺口走到走廊。荷莉退到狱警身后，乔瑟夫绕到阿布德尔身后；地图可走范围改成走廊 y 150–176。
  - 序1 场地 x 88–256，阿布德尔 (278,164)。火球从他身前发；火柱铺满整条走廊；水管挪到走廊左边铁栏前 (112,151)，调查点文字改成「栏杆外头的水管」。
  - 第 6 步 U 改成标准欧拉切入 + `finaleOra`：冲到阿布德尔面前、红色魔术师架住、欧拉连打 1.1 s、最后一拳停在他面前（只演、不判伤）。朝向直接设，因为 `C.aim` 对不能被打的人不转身。
  - 序-5 `standName`：「……够了。拳头停在了我面前——它听你的。」→「替身」大标题 → 乔瑟夫解释 → 压帽。
- 第 3 步：火柱 `once: false`（每 10f 烧一下）。在火里按住 L 满 1 s，或连续挡住 3 下就过；没挡住的一下清零。火焰画面改为两排错开的地面火舌，加一道胸口高的火焰洪流（`onActive`）。
- 连打特效 `rushFx`：每帧跟着替身身前走（替身 x + 面朝 × ahead，高度 = 替身 z + 图高一半）。各角色按 `kit.rush.fx` 用自己的特效：
  - 只有白金之星（`'fists'`）出紫色拳影墙；
  - 阿布德尔是火焰洪流（`'fire'`）；
  - 波鲁纳雷夫是银色刺剑残影（`'thrust'`，新网格 `THRUST_GRID`）；
  - 宝石、藤蔓、沙不另加。

  连打提前结束时拳影墙不再出新拳（`trimFx`）。连打火花改传 `cx / cy`，只在打中时冒。
- 铁栏前后景：地图 `fgDepth`（`jail_pro` 144）让前景层按脚底线参与纵深排序。
- 警帽：`POLICE_CAP_AT = (8, 5)`，所有动作的帽子都戴在头上了。
- 荷莉：新增 `tools/art/art_holly_fix.py`，在 D12 审计之后把 `idle / walk / wave` 用 `h_frame2` 按原参数重画，头往前挪 2 px。重画前先断言副本骨架和原工程逐字一致。`bake_art.py` 把被替换的 cid 加进受影响列表。

共享引擎文件的逐条记录在 `游戏素材/JoJo/游戏/docs/交付/收尾_共享改动.md` 末尾；`规划.md` 的序-3b / 序-4 / 序-5、5.1.2 参数表和调查点表已同步改（标了 2026-10-09）。
