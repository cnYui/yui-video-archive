## 银魂做了什么（我自己做的部分）

1. **烘焙角色图集**（`银魂\烘焙脚本\bake_characters.py`，约 1 分钟）：
   - 对每个角色的每个动作，按原工程动画帧率（12 fps）逐帧渲染；循环动作找最小周期 N（≤ 24）使首尾帧像素相同（`seamless: true`），找不到相同的就取首尾差异最小的 N（`"approx"`，json 里记 `loop_error_px`）；一次性动作（由进度 p 驱动：出拳、挥刀、受击……）p 从 0 到 1 采样 8 帧；与别的动作帧完全相同的记成 `aliases`。
   - 统一格子：以脚点为基准取全体最大外接范围 + 1 px 边；`pivot` = 脚点在格内的坐标。
   - 路人的 4 种配色（kw `variant=0..3`）：1..3 另存成 `townsman__v1..3`、`townswoman__v1..3`。
   - 结果：48 个目录，13124 帧；`验证图集.py` 检查 json 字段、图集尺寸、空帧、被裁帧（边缘不透明）：0 问题。
2. **导出剧情分镜**（`银魂\剧情分镜\export_storyboard.py`，不渲染视频）：
   - 数据层：`SCENE.subs`（80 条台词）、`SCENE.cues()`（974 个音效 cue）、`SCENE.music`（含中途切歌 / 静音）、代码里引用的角色 id 和背景函数；成片时间 = 场景时长累加，总 334.2 s，和原会话里 ffprobe 的 334.3 s 一致。
   - **设计层**：每个场景文件开头的模块 docstring 是场景代理写的**逐镜头镜头表**（SHOT LIST，景别 / 镜头运动 / 角色动作 / 特效 / 台词和音效触发秒数），整段原样收进来；再加 `CONTRACT.md` 第 8 节（主会话在启动工作流前写的 15 场分镜）。
   - `export_contact_sheets.py`：每个场景一张分镜图（每 0.5 秒一帧，引擎真渲染，带时间标签），15 张共 8.9 MB。
3. **导出可读版会话**（`游戏素材\导出会话.py`，银魂 / 火影 / JoJo / 进击的巨人都跑过）：主会话的用户话 + 助手话 + 工具调用摘要；会话里写过的设计文档（CONTRACT.md、STYLE.md、ENGINE_GUIDE.md、故事设计 md）、工作流脚本、工作流结果存成附件；每个子代理一份“任务书 + 最终报告”。银魂的主会话本身话很少（实质设计都在 CONTRACT.md、工作流脚本和 41 个子代理里）。
4. **文档**：`游戏素材\README.md`（总览 + 通用图集格式）、`银魂\README.md`、`银魂\角色图集\README.md`（格式 + canvas / Phaser / Godot 用法）、`银魂\音频\README.md`、`银魂\会话备份\README.md`、`银魂\剧情分镜\README.md`（含 15 个场景的玩法建议，标明是建议）。

## 踩到的坑

- **Windows 260 字符路径**：会话子代理的完整路径超长，Git Bash 里的 Python `os.walk` / `isdir` 静默返回空（我一开始还以为子代理目录是空的）；robocopy 没问题。会话备份目录的路径比原处短，之后读那里的文件没事。
- **工作流子代理的任务书在第 2 条用户消息里**：第 1 条是 harness 转述用户原话，第 2 条（`[Workflow harness — computed task]`）才是脚本算出来的任务书。
- **找循环周期被眨眼干扰**：引擎里 `_blink(t)` 每 3.1 s 眨一次，取样窗口里夹着第二次眨眼会把本来完全相同的循环判成“近似”；窗口缩到 33 帧（2.92 s）。`int((t*720) % 360)` 这类写法在 `t = k/12` 上有浮点误差（239 vs 240 度），取样时间加 1e-6。
- **12 fps 取样的限制**：跑步（2.6 Hz）不是 12 fps 网格的整数倍，找不到像素完全相同的周期，取了首尾最接近的 14 / 23 帧（`approx`）；`cheer` 这类 8 Hz 的开关动作在 12 fps 下变成 3 帧循环。游戏里需要更细的可以回源码里按更高采样率渲染。
- 引擎的字体写死 `C:/Windows/Fonts/simsun.ttc` 等（中文版 Windows 自带）；换机器重新渲染要有。
- 我用 heredoc 的 Python 给脚本打补丁时，`\n` 被写成了真换行，把导出脚本弄坏了一次；改脚本一律用编辑工具。
- 更正上一份记录：银魂音效是 **81 个 wav**（那个目录里共 88 个文件，含脚本和频谱图），不是 88 个。
