## 踩到的坑

- 搜索摘要不可信：澎湃那篇里「维普更新前 6%、更新后 74%」是社交网站匿名吐槽，摘要把它写成学生论文的事实；「教育部明确允许辅助、禁止代写」「清华建议 20% 以内」「南京大学声明」来自企业博客聚合，没找到原始通知，全部没用。事实审校用 curl 取原文逐句比对才发现更多走样（例如“维普”被写成“万方”）。
- 二手转述会把“记者做的实验”改成“网友反映”：写新闻类事实要追到首发稿。
- `build_script.py` 打印时间时 5:00 之后会显示成 `4:60.0`（显示小毛病，不影响时间轴），没改。
- 在 Bash 里用 heredoc 塞很长的中文 Python 会因为引号解析失败：大块文本先 Write 成文件再拼接。
