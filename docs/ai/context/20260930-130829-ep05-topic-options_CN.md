# 《原LAI如此》第五期候选方向

## 本轮范围

- 用户要求为第五期提供好的方向；先讨论选题，不创建本期工程、不写完整台本、不配音、不渲染。
- 用户说明目前有四个视频分组；本地 README 和 AGENTS.md 仍记录三个。第四组的名称和定位尚未提供，不推测、不修改既有分组表。
- 前四期分别讲 API、AGI、Jev 与 LLM、模型排名。第五期建议转向具体使用困惑，避免重复排名和宏观 AGI 讨论。
- 沿用现行节目技能：正片 5–7 分钟、白板手写、用户自己配音。讲解员和片尾清单在制作前确认。

## 候选方向

1. **为什么和 AI 聊久了，它就开始忘事？** 推荐优先。围绕上下文窗口、截断与压缩、信息未被有效利用，区分当前对话与产品的跨对话记忆；以长聊天中的设定遗漏切入，最后给出任务摘要和关键信息管理方法。避免声称所有产品每轮发送完整历史，也避免把所有错误都归因于窗口不足。
2. **Agent 到底比聊天 AI 多了什么？** 推荐备选。讲目标、工具调用、读取结果、继续行动与停止条件；沿用第一期 API 基础。用一次资料整理任务画出工作循环，说明需要权限边界与结果验收。不承诺 Agent 完全自主，不制作工具安装教程。
3. **AI 为什么能把假的说得这么像真的？** 讲幻觉、语言流畅与事实正确的区别、联网和引用的局限、核对原文。用虚构文献示例切入；正式稿之前需取得真实可复核的演示，不把示意当实测。
4. **一个汉字到底算几个 Token？** 承接 API。讲词元、不同分词器的差异、输入输出计费和长度限制。白板展示切分及一笔账，具体价格在写稿时核对官方资料，不使用固定的汉字换算比例。
5. **同一个 AI，为什么能当客服、老师和猫娘？** 原系列企划的第五题。讲系统提示词、人设、资料和工具对产品的影响，以及指令优先级的局限。用相同任务、不同设定对照，避免变成提示词模板教学或角色梗。

## 取舍

- 上下文题：使用痛点具体，白板容易表现，适合作为第五期的首选。
- Agent 题：承接 API，概念延展更强；必须收窄到一个工作循环，避免塞入 MCP、RAG、多智能体等内容。
- 幻觉题：面向普通观众更容易进入，但需要避免停留在泛泛的“别信 AI”。
- Token 题：基础价值高，标题吸引力相对弱。
- 系统提示词题：符合旧企划，但实际前四期已调整顺序，旧编号无需强行约束新选题。

这些是编辑建议，尚未由用户定题。技术事实和具体产品行为在定题、写台本时查询官方资料并记录日期。
