## 做了什么

1. **合集固定封面模板**：`skill/cs-grad-ai-episode/assets/template/制作/04_封面/`
   - `cover.html`：固定元素 = 左上角 `#期号`（JetBrains Mono 800）+ 合集胶囊「计算机研究生 × AI」→ 第一行小字（176 px）→ 第二行大字（214 px，强调色 + 官方图标）→ 右边真人抠像（白描边，16:9 高 930 / 4:3 高 540）；36 px 点阵背景；16:9 的字收在 x 96–1824，字不进底部 12%。每期只改 `cover.json`，模板不动。
   - 三个候选样式（配色表见 `references/cover.md`）：A 深色终端（深藏青 + 终端绿）、B 蓝色色块（左蓝块斜切 + 右浅灰，人像跨在斜边上）、C 黄底海报（黄底 + 黑字 + 白标签）。
   - `render_covers.py`：读 `cover.json`，每个样式出 16:9 + 4:3 + 预览图；渲染后自检——字超安全区、进底部 12%、**压人像按抠图 alpha 逐像素查**（第一版 C 的 4:3 就被查出标签右下角碰到头，把 4:3 的人像右移 60 px 后过）；`--select X` 复制成 `封面_选定_*.png` 并记进 `cover.json`。
   - `cutout.py`：通用版（jpg / png 都认，`PICK` 每期改），默认挑安静的帧。
   - `cover.json` 例子 = 第 1 期的。
