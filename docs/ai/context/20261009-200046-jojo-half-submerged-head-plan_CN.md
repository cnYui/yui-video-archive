# JoJo 落水角色像素形象修改方案

用户要求重新绘制落水角色，重点是第一章坠机落海后的几人，海面只露半个头。

## 当前问题

`游戏素材/JoJo/游戏/tools/art/art_later_existing.py` 的 `float` 动作画成横躺的全身，身体和四肢都露在水面。第一章 `story/ch01.js` 的 `crash()` 使用该动作，现场四人依次为承太郎、乔瑟夫、阿布德尔、花京院。波鲁纳雷夫也有同一类落水资源。

## 实施决定

- 重画五位角色的两帧落水动作；沿用各自头部的原有像素、帽子和发型，水线位于眼睛附近，下半张脸和身体完全隐藏。
- 锚点设在水面；两帧仅有一像素沉浮和少量水纹变化，保持最近邻像素风。
- 定向重烘五位角色图集，再更新正式 `chars`、`data` 资源包，避免只更新审计预览。
- 检查图集回读、锚点、翻转与实际第一章海面渲染，保存验收截图。

本次只处理用户重新授权的落水美术；此前暂停的整体续建不在本次范围内。原素材目录只读，Python 使用 `-B`，上下文记录只新增。
