# 银魂像素游戏：30 秒宣传片 v2

- 时间：2026-10-04 晚写方案，2026-10-05 上午出成片（UTC+9）。
- 起因：用户把 GPT 剪的宣传片 `录屏素材\2026-10-04_精彩展示\银魂像素游戏_高能展示_30秒_横版.mp4` 给我看，说“你过一下看看有没有可以优化的地方”，原来的要求是“剪辑的视频需要你用不同的手法，来展示出炫酷的游戏宣传片的感觉”。我列完问题、写完方案时额度用完，之后用户说“继续剪辑”。

## GPT 版的问题（实测）

- “终章　两年后归来”那段是 0 帧，后面的镜头整体提前了 2.1 秒。
- 四格里 3 格、分屏的右半边是静止画面（`-ss` 写在 `-i` 后面，多路输入时起点错了）；分屏还把 16:9 压成了 8:9。
- 剪辑点离拍子最多偏 250 ms；用的是歌的 0–30 秒，前奏很弱，结尾唱到一半硬切。
- 17 个镜头有 15 个是同一种做法；画面里露着半截对白和操作提示；最有冲击力的几个镜头没剪进去。

详见 `录屏素材\2026-10-04_精彩展示\优化方案_v2.md` 第一节。

## 成片

- 文件在 `D:\大疆\游戏素材\银魂\录屏素材\2026-10-04_精彩展示\`：
  - `银魂像素游戏_宣传片_v2_30秒_横版.mp4`：1920×1080，60 帧，30 秒；
  - `…_BGM.wav`、`…_音效.wav`：和成片对齐 0 秒，成片里的声音就是这两条相加。
- 脚本 `build_trailer_v2.py`：一条命令出片，约 3 分钟；`preview` 出预览，`sheet` 出联系表。
- 结构跟着歌的段落走（用户给的歌，约 113 BPM）：
  - 冷开场（歌的间奏）：天人降临 → 刀落进水洼 →「武士的时代，结束了。」→ 废刀令 → 死鱼眼变红眼 → 虚；
  - 第 6.4 秒乐队砸回来：标题；
  - 角色和打斗快切 → 斜切三联屏 → 高杉；
  - 歌里半秒急停：黑场 + 毛笔刀光「第十三章　银之魂篇」；
  - 副歌：全江户集结 → 背靠背 → X 字斩 → 高杉挡刀 →「高杉——!!」→ 回忆 → 天亮决战 → 最后一斩 → 两年后 → 神乐飞踢；
  - 唱片急刹：定春咬头 →「完」字定格 → 一脚踢飞 → Logo。
- 用到的手法：
  - 推拉、裁近景、慢放 / 变速、冲击帧、震屏、闪白、RGB 错位；
  - 电影黑边、调色（冷色 / 红月 / 回忆褐色）、斜切三联屏；
  - 音乐急停留白、毛笔刀光、名牌滑入、大字砸入、副歌每拍轻推、唱片急刹 + 定格、Logo 砸入 + 混响尾巴。
- 不剧透结局：方案里原本有“虚化成光”“松阳的笑脸”，成片里没放。

- 声音：混音 −12.6 LUFS，峰值 −0.9 dBFS；成片的声音和 BGM + 音效相关 0.9994，延迟 0 ms。
