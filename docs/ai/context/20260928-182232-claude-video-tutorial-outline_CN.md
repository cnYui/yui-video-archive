## 主线

每一层结尾留一个问题，下一层回答：

看到成品 → 一段提示词怎么出片 → Claude 交出来的是什么 → 代码怎么变成视频 → Claude 怎么自己跑代码 → 它不是扩散模型，凭什么能做 → 画面好在哪 → 声音和字幕怎么对上 → 花多少钱 → 怎么一次比一次好

建议 12–15 分钟，录屏里的等待剪掉。

## 0. 开场（0:30）

- 先放 10 秒成品。
- 钩子：这条视频没用视频生成模型。画面、字幕、配音对齐、合成，都是 Claude 做的。
- 本期讲四件事：一段提示词怎么出片；原理；Claude 不是扩散模型，为什么也能做视频；为什么效果好、成本低。
- → 先不讲原理，直接做一条。

## 1. 一段提示词，先出一条片（录屏，2:30）

- 准备：Claude Code（桌面版的 Code 标签页，或命令行），一个空文件夹。模型我用 Claude Opus 5.5。第一次要装 Playwright、Chromium、ffmpeg，Claude 装之前会问你。
- 贴【提示词 1】。
- 录屏重点：先列计划 → 写文件 → 运行 → 报错后自己改 → 出片。播放成片。
- 打开文件夹，看它交了什么：一个 HTML 文件（画面）、一个 Python 脚本（截图）、一个装着 600 张截图的文件夹、一个 MP4。
- → 它从头到尾没“画”过一张图。视频是怎么来的？

## 2. 视频是“算”出来的（1:30）

- 视频 = 每秒 30 张图 + 一条音轨。20 秒就是 600 张。
- 每一张图 = 网页在某一刻的截图。
- 关键是 `renderAt(t)`：给一个时间，画出那一刻。同一个 t 永远是同一帧。所以：
  - 逐帧截图，电脑卡了也不掉帧；
  - 能拆成几段同时渲染；
  - 能随便抽一帧出来检查。
- 分工：Claude 写网页和脚本；无头浏览器（Chromium）把网页画成像素；ffmpeg 把图片和声音压成 MP4。
- 同一思路的开源工具：Remotion（用 React 写视频）、Manim（做数学动画）。
- → Claude 只会输出文字。它怎么“运行”浏览器和 ffmpeg？

## 3. Claude 会自己动手：智能体（1:00）

- Claude Code 官方的介绍：智能体编程工具，能读代码、改文件、运行命令。
- 智能体（Agent）= 大模型 + 工具 + 循环：决定下一步 → 调用工具 → 看结果 → 再决定下一步。Anthropic 的定义：大模型根据环境反馈，循环使用工具。
- 回放第 1 层里“报错 → 读报错 → 改代码 → 重跑”那一段，这就是循环。
- 它还能看图：打开自己渲出来的截图，检查版面。
- → Sora、Veo、可灵也能出视频。两条路差在哪？

## 4. Claude 不是扩散模型，为什么也能做视频（核心，1:30）

- 扩散模型：从一片噪声开始，一步步去噪，直接生成像素。Sora、Veo、可灵这类视频模型，大多走这条路。
- Claude 是大语言模型：一个 token 接一个 token 往后写文字。代码也是文字。
- 所以 Claude 生成的是视频的“源代码”，像素交给浏览器画。它写出一个能生成视频的程序，再自己把程序跑起来。
- 这条路为什么走得通：视频里有两类信息。
  - 结构：写什么字、放在哪、第几秒出现、怎么动。能用语言说清楚，是语言模型的主场。
  - 质感：光影、皮肤、真实的镜头运动。很难用语言说精确，是扩散模型的主场。
  - 讲解类视频，几乎全是结构。
- Claude 为什么写得好：网页和 Python 是最常见的代码，写得熟；会拆步骤、会看报错；能看截图改版面。
- → 走代码这条路，画面具体好在哪？

## 5. 为什么效果好（上）：画面（1:30）

- 字和数字准：页面上是真文字，不糊、不错字；按成片分辨率直接渲染，字边缘锐利，要 4K 改个尺寸重渲就行。
- 前后一致：同一套代码，每一帧的字体、配色、角色都一样，不闪、不漂。
- 想改就改。录屏：让它把标题改一个词，重渲这 20 秒。视频模型要重新生成。
- 边界要说清楚：适合讲解、图文动画、数据图表、字幕、像素风和扁平风。写实人物、实拍感的镜头，还是用视频模型或者自己拍。两条路也能一起用：视频模型出素材，Claude 排版、加字幕、合成。
- → 现在只有画面。配音和字幕怎么和画面对上？

## 6. 为什么效果好（下）：同步和自检（录屏，2:30）

- 贴【提示词 2】：旁白 → 录音或语音合成 → faster-whisper 识别出每句话的起止时间 → `timeline.json` → 画面和字幕都挂在台词上。
- 原理：时间不写死。配音多长，画面就停多长。换了配音，重跑一遍就重新对齐。
- 贴【提示词 3】：均匀抽 8 帧拼成一张图，Claude 自己看，找出界、遮挡、太小的字，改完再出片；最后用 ffprobe 核对分辨率、帧率、时长。
- 录屏重点：它指出问题 → 改代码 → 重渲 → 再看一遍。
- 收一下“效果好”的五条：字准、一致、能改、音画同步、能自检。
- → 做一条要花多少钱？

## 7. 成本拆开算（1:00）

- 视频生成模型：一般按生成的秒数或次数收费，不满意要重新生成。（录制前查当前价格，截图上屏）
- 这条路花在哪：
  - Claude：订阅或 API 用量。（放你的档位和这次用量的截图）
  - 渲染：在自己电脑上跑。浏览器、Playwright、ffmpeg、faster-whisper 都免费开源，用 CPU 和内存，不用显卡。
  - 配音：自己录不花钱。用语音合成也便宜：我的系列用 Fish Audio，6 分钟一期约 0.09 美元。
  - 返工：改哪段重渲哪段。
- 实际数字：6 分钟正片 1 万多帧，4 路并行渲染，三分钟左右。
- 提醒：并行数别开太大。我开过两个任务各 10 路，32 GB 内存直接吃满。
- → 每次都写这么长的提示词太累。怎么让它一次比一次好？

## 8. 从一段提示词到一条流水线（1:30）

- 记忆文件 `CLAUDE.md`：Claude Code 每次开工先读。把偏好写进去：白底、短句、字幕大小……
- 技能（Skill）：把重复的流程打包成“说明书 + 脚本”。贴【提示词 4】，演示下一条只要一句话。
- 检查脚本：每次出片都跑，版面、帧数、时长、响度不对就停。
- 我的系列就是这么做的（放目录截图）：
  - 《原LAI如此》：选题 → 台本 → 配音 → 画面 → 合成 → 封面 → 投稿。我做五件事：定选题、确认台本、配音、确认封面、点发布。其余是 Claude。
  - 我提的每条意见都写进记忆。第一期第一版台本被我否了：太像 AI，例子太多。这条变成规则，之后每期照着写。
  - 《AI每日日报》全自动：每天凌晨开工，检查通过后，北京时间早上 6 点定时发布。
- → 回到开头的四个问题。

## 9. 总结（0:30）

- 一段提示词：说清时长、尺寸、画面；要求 `renderAt(t)` + 逐帧截图 + ffmpeg 合成。
- 原理：视频 = 帧 + 音轨。Claude 写代码，浏览器画像素，ffmpeg 合成。
- 不是扩散模型也能做：它写的是视频的源代码；讲解类视频几乎全是结构。
- 效果好：字准、一致、能改、音画同步、能自检。成本低：渲染在本地、工具免费，改哪重渲哪。

## 四段提示词（录屏直接贴）

**提示词 1：先出一条片**

```text
在当前文件夹里，做一条 20 秒的横屏动画视频，主题是「什么是 Token」。

做法：
1. 画面用一个 HTML 页面来画。页面里写一个 renderAt(t) 函数：给一个秒数 t，就把画面画成这一刻的样子。不要用 CSS 动画和定时器，同一个 t 必须画出同一帧。
2. 写一个 Python 脚本，用 Playwright 打开页面，每秒 30 帧，从 0 秒到 20 秒逐帧调用 renderAt(t) 并截图。
3. 用 ffmpeg 把截图合成 1920×1080、H.264 的 MP4。
4. 画面：白底，一个大标题，三条要点依次出现，字要大、要清楚。
5. 缺什么工具就自己装，装之前先问我。

做完告诉我视频在哪。
```

**提示词 2：加配音和字幕**

```text
给这条视频加上配音和字幕：
1. 先写一段 20 秒左右的旁白给我看，短句、口语。
2. 我确认后自己录一个 voice.wav 放进文件夹。
3. 用 faster-whisper 识别 voice.wav，拿到每句话的开始和结束时间，写进 timeline.json。
4. 画面上的要点和字幕都按 timeline.json 出现，不要写死秒数；视频长度跟着配音走。
5. 把配音混进去，重新出片。
```

不想自己录：第 2 条换成“用 XX 语音合成生成 voice.wav”。

**提示词 3：让它自己检查**

```text
出片前先自查：
1. 从视频里均匀抽 8 帧，拼成一张图，你自己看一遍：文字有没有出画面、互相遮挡、太小看不清。
2. 有问题就改代码、重渲，改完再抽帧看一次。
3. 最后用 ffprobe 核对分辨率、帧率、时长，把结果告诉我。
```

**提示词 4：固化成技能**

```text
把我们刚才的整套做法，写成一个 Claude Code 技能（Skill）：
1. SKILL.md 写清楚每一步做什么、做完检查什么。
2. 渲染、识别、合成的脚本放进技能的 scripts 文件夹，以后直接调用。
3. 在项目根目录建一个 CLAUDE.md，记下我的偏好：白底、短句、字幕大。
以后我说“做一条关于 XX 的视频”，就按这个技能来。
```
