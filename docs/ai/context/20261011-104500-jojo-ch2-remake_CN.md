## 1. 替身错位（已修，体验版已重打包）

原因：`stand.js` 画替身只用本体的 `y`，没减本体自己的 `z`。序-8 石阶上人的 z = 台阶高度（坡顶 80），所以替身掉在地面那一层。
改法：替身的 z 当成“离本体脚底多高”，画面、残影、召唤线、沙子、`origin()`、`chest()`、`combat.js` 的 `standFront` / 远程弹出发高度 / 替身碎裂特效、银色战车剑尖闪光都加上本体 z。地面战斗（z 0）不变。
验证：坡顶 / 石阶中段 / 人行道三处亮替身，替身脚底比承太郎高 5–7 px（正常浮空量）；test_combat 14/14、test_specials 79/79、test_special_visuals 12/12；序章全流程 0 报错（323 s）。
