# JoJo 大招命中与特效修复计划

用户反馈：花京院大招朝向反了，其他角色大招经常打空，阿布德尔的大招缺少明显特效，希望扩大效果。

## 范围与依据

- 游戏目录：`游戏素材/JoJo/游戏/`。数值以 `规划.md` 为依据，接口沿用 `docs/技术约定.md`。
- 优先修复 `engine/moves.js` 与 `engine/combat.js`，复用 `engine/fx.js` 已有的像素特效。
- 保留现有伤害、能量门槛、Boss 防御与剧情教学规则；不修改角色图集，保留五人半淹水面与成年承太郎的形象。
- JoJo 文件被根仓忽略，修改前在游戏的专用排查目录保存原文件。根仓已有工作不属于本轮，不提交、推送或清理。

## 已定位的问题与待验证项

- 花京院大招传入的是固定朝右的世界角度，左向释放不随角色或敌人方向改变。
- 阿布德尔的安卡弹体由通用小方块绘制，弹体 `size` 没有接入已有 `fire_ankh` 特效。
- 近战大招冲刺使用旧朝向，敌人在背后时落点与前方攻击区域可能不一致。
- 特定剧情地火使用 `speed: 0`，通用弹体的 `|| 160` 会将零速度替换为默认速度。
- 攻击高度、纵深与受击位移是否造成其他打空，用实际战斗回归确认，避免凭代码猜测扩大改动。

## 实施与验证

1. 在生产战斗引擎上建立可重复的大招回归，记录修复前的左右、背对、纵深和多目标命中表现。
2. 统一大招目标与朝向处理，修复弹体初始瞄准、零速度语义和必要的连打定位。
3. 为大招接上可见且有限寿命的特效：扩大火焰安卡与爆炸、绿宝石弹体与拖尾，并检查六人的演出。
4. 运行定向大招测试、既有战斗回归与相关剧情验收，检查错误日志和特效残留；保存实际画面供复核。
5. 新建结果记录，在根 `AGENTS.md` 留下精简的战斗接口规则与记录链接。

## 取舍

不通过增加伤害、忽略防御或强制扣血来掩盖打空。扩大演出时将视觉尺寸与实际伤害范围分开；保留明确的射程与近战距离，避免变成无限距离必中的技能。
