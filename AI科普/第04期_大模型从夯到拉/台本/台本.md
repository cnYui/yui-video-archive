### 配音

- 音色：Fish Audio「苏晓晓」（本期讲解员 鲸鱼娘，音色 id e7219cb8cfab46bebba2ee570932b0a6），模型 s1。音色页上的示例可能是别的模型生成的，以 s1 实际效果为准。
- 按 `台本/配音分段.json` 的 `tts_text` 生成，字幕用 `text`。用 Fish Audio API 整期一次生成：`scripts/chunk_voice.py --whole` → `scripts/tts_api.py`（key 在用户环境变量 FISH_API_KEY） → `select_takes.py` 语音识别打分 → `segment_audio.py` 切句。
- “夯”读 hāng（第一声），全片 9 处，是本期最关键的字：整期生成前先用 API 单独试读「从夯到拉。夯，又强又值。给到，夯。」（花费不到一分钱），三处都对再整期生成；整期里哪处读错，就多生成一版挑对的，不换字（hāng 没有常用同音字，“航”是第二声，不能用）。
- 缩写逐字母读：GPT → G P T，NPC → N P C，API → A P I，GLM → G L M，LMArena → L M Arena，App → A P P。
- 品牌拆词：DeepSeek → Deep Seek，OpenAI → Open A I，OpenRouter → Open Router，MiniMax → Mini Max。
- 版本号、分数、年份在 TTS 里写成中文（G P T 六、Opus 五点五、K 三、M 三、Step 五、四十六点三、二零二六年），免得夹在英文里被读成英文数字。
- 英文原样读：Claude、Opus、Fable、Gemini、Flash、Pro、Grok、Muse Spark、Kimi、Step、Preview、Artificial Analysis、Astra。MiMo 写成“Mimo”，读不好改“米莫”。Jev 的 TTS 一律写“杰夫”（用户在第 3 期定的：写 Jev 时 S1 念得像“JAV”；本期第一版三处念成 Jeff / Jell / Jav，统一改）；字幕照旧写 Jev。Artificial Analysis 全片只念一次，读不好就把字幕和 TTS 都改成“A A”。
- 逗号只放在真正换气的地方和“给到，X”前面（这一停是锤音）；锐评要快，别处少断句。
