# 第 1 期「什么是 API」成片制作规范

所有路径相对 `D:\大疆\第01期_什么是API\制作\`（下称 ROOT）。台本：`..\台本_v3.md`（内容以它为准），时间轴：`timeline.json`（由 `build_timeline.py` 生成，**不要手改**）。

## 用户的硬性要求（最高优先级）

- 这是**科普视频，不是游戏视频**：重点是内容。不要激烈切镜头、不要频繁的人物走动、不要 BGM 切换。画面平稳、清楚、克制。
- 讲解员是像素风山田凉（素材包 `D:\大疆\角色素材\山田凉像素素材包`）。动作只用：开头走入一次、说话时嘴动、讲要点时偶尔抬手（reach 姿势）。其他时间待机呼吸。
- 背景用《孤独摇滚！》场景画面（空镜，画面里不能有原作角色），**压暗**后使用。
- 底部有自定义**章节进度条**：《孤独摇滚！》的配色和风格，标注每一章是几分到几分、讲什么（中文小字），位置对齐 B 站播放器的进度条，方便观众对照跳转。
- 字幕要有（烧录进画面，另出 SRT）。
- 最终产物是一个完整的视频文件：片头（现成）+ 正片 + 片尾（现成）。

## 画面规格

- 1920×1080，30 fps。正片时长以 `timeline.json` 的 `main_duration` 为准（约 7 分钟）。
- 字体只用 `fonts/fonts.css` 里的 OFL 字体：Noto Sans SC（正文/标题）、JetBrains Mono（代码、英文字段）、ZCOOL KuaiLe（进度条章节小字等活泼处，可选）。不要用系统字体。

### 视觉语言（和片头片尾一致的“终端小票”风格）

- 纸白 `#EDEAE3`、墨黑 `#141414`、橙 `#FF4F1A`（重点、箭头、勾）、红 `#D8342A`（只用于禁止/报错）、辅助灰 `#6E6A63`。
- 知识卡片 = 纸白卡片（小票质感：顶部一条 2px 橙线、轻微投影），墨黑字。代码卡 = 墨黑底 + JetBrains Mono，字段名橙色、字符串浅绿、注释灰，右上角小字「示意·已简化」。
- 动效克制：卡片 0.3–0.4 s 淡入 + 轻微上移；列表逐条出现；打勾 0.25 s；没有弹跳、闪烁、抖动。
- App、工具界面一律虚构示意，不画真实品牌 logo（DeepSeek、OpenAI、Claude 只以文字出现）。Key 永远打码（`sk-••••`）。
- 实操那一节**不录屏**：用简洁的“步骤卡 + 示意界面”讲四步（示意界面标“示意”，不仿真实网站截图）。

### 章节进度条（《孤独摇滚！》风格）

- 全宽，覆盖**整个视频**（片头 + 正片 + 片尾）的时长：`timeline.json` 的 `chapters[]` 用的就是整片时间，按 `start/end ÷ total_duration` 算宽度，所以和 B 站播放器进度条一一对应。正片的时刻 t 对应整片时刻 `intro + t`。
- 配色取结束乐队四人代表色，按章节轮换：波奇粉 `#F2A0BD`、虹夏黄 `#F6C945`、凉蓝 `#4A6FD0`、喜多红 `#E2463F`。已播放部分饱和度高，未播放部分同色但降低不透明度；当前章节略加高并有细描边。
- 每段上方或内部写中文小字：`0:33–1:22 API 是什么`（太窄放不下时只写序号，完整信息放在当前章节的浮标里）。播放头用一个小吉他拨片形状（或小星星），颜色纸白，带墨黑描边。
- 风格参考《孤独摇滚！》的活泼手作感：圆角、粗描边、可以用 ZCOOL KuaiLe 写章节名。但整体要轻，不能抢字幕和内容。

## 数据契约

渲染器 `render.py`：每帧暂停 CSS/Web 动画并定位到 t，再调用 `window.renderAt(t)`。`--data timeline.json` 会把时间轴注入为 `window.__DATA__`。页面必须设置 `window.DURATION = __DATA__.main_duration`。禁止依赖真实时间（rAF 循环、setTimeout、Date.now、CSS transition）；随机数必须固定种子。

`timeline.json`（时间单位秒，正片时间）：
- `segments[]`：`id`（如 S03-12）、`scene`、`start`、`end`、`text`（字幕原文）、`visual`（这一段画面的文字说明，来自台本）、`pose`（`reach` 表示这一段开头抬手约 1.2 s，否则 `idle`）、`lines[]`（字幕分行：`text/start/end`）。
- `gaps[]`：纯画面停顿（`scene/start/end/visual`）。
- `scenes[]`：`id/title/start/end/bg`。
- `chapters[]`：`id/title/start/end`（整片时间）。
- `walk_in`：`{start, end}`，开头走入。
- `mouth`（后期加入，可能不存在）：数组，每帧一个 0/1/2（闭嘴/半张/张嘴），由配音音量算出。不存在时，说话段内按 8 fps 在 1、2 之间交替。

**时间会变**：配音生成后每段时长会重算。所以所有画面必须按 `segments[].start/end` 和 `gaps[]` 来驱动，**不许写死秒数**。
