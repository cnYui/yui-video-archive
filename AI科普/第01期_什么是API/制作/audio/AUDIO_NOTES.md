# 音频说明（第 1 期「什么是 API」）

所有声音都由 `synth_audio.py` 用 numpy/scipy 程序化合成，没有用任何采样或外部素材。随机种子固定为 20260926，所以重新运行会得到完全相同的文件。`analyze_audio.py` 负责画检查图和统计数值。

```
python synth_audio.py [临时目录]   # 生成 bgm.wav / sfx_pop.wav / sfx_tick.wav，约 30 s
python analyze_audio.py            # 生成 bgm_analysis.png / sfx_analysis.png，并打印统计
```

## BGM：风格和编排

- 风格是安静的 lo-fi 轻爵士，**80 BPM**，4/4 拍，8 分音符带轻摇摆（后半拍落在 58% 处）。**F 大调**。
- 和弦进行 16 小节一轮，一轮 48 s。每个和弦占 1 小节（3 s）：
  - A 段：`Fmaj9 – Dm9 – Gm9 – C13` ×2（Imaj9–vi9–ii9–V13）
  - B 段：`Bbmaj9 – Am7 – Dm9 – C13 – Bbmaj9 – Am7 – Gm9 – C13`（IVmaj9–iii7–vi9–V13）
  - 结尾：`… C13 → Fmaj9`，最后一个和弦慢速琶音后让它自然延音。
- 电钢琴用的是无根音的爵士排列（A/B 型），集中在 E3–E4 音区，相邻和弦之间声部级进，没有大跳。
- 伴奏型从 4 种里按固定种子挑选：整小节长音、1 拍半/2 拍半处轻轻再触键、慢速琶音。时值和力度带 ±6 ms、±6% 的人性化偏差。
- 编排变化都用 smoothstep 做 12–18 s 的慢过渡，没有突变。下表时间是 **BGM 文件内的时间**：

| 时间 (s) | 编排 |
|---|---|
| 0–9 | 只有电钢琴和贝斯（开头 2 s 淡入） |
| 9–27 | 沙锤和刷子慢慢进来 |
| 27–234 | 完整编排：电钢琴 + 贝斯 + 很轻的沙锤和刷子 |
| 141–237 | 叠加高音装饰（141–153 s 淡入，225–237 s 淡出） |
| 234–294 | “呼吸段”：节奏降到 20% |
| 294–456 | 完整编排 |
| 399–465 | 高音装饰再出现一次，力度 85% |
| 456–474 | 节奏渐出 |
| 474–492 | 电钢琴和贝斯收尾（最后 3 s 淡出） |

正片加片头片尾共 435.7 s，所以结尾那段在成片里听不到，混音时在视频结尾处淡出即可。

## 合成方法

- **电钢琴（Rhodes 质感）**：两对 FM 算子。
  - 1:1 载波/调制对负责主体，调制指数从约 1.4 随时间衰减到约 0.25，所以触键时亮、之后变暗。
  - 14:1 的调制对只存在几十毫秒，模拟音叉“叮”的瞬态。
  - 包络是双指数衰减，低音区的延音更长；松键时带 90 ms 的制音。
  - 4 个声部在声像上左右微微展开，外加 Suitcase 式立体声颤音：2.8 Hz、深度 ±12%，左右相加恒定，所以单声道兼容。
  - 单独做了 110 Hz 高通和 3.8 kHz 低通，让声音温暖、不发亮。
- **贝斯**：6 个谐波的加性合成，高次谐波衰减得更快，再加一段很短的低通噪声模拟拨弦。
  - 音区是 A1–G2，750 Hz 低通。
  - 音型是根音、五音和到下一小节根音的经过音。
  - 电平比电钢琴的 RMS 低 7 dB，只托底，不抢。
- **沙锤**：带通噪声（2.8–8.5 kHz），打 8 分音符，后半拍稍重。
- **刷子**：带通噪声（0.9–4.5 kHz）做成缓起缓收的“刷”声，落在第 2 拍和第 4 拍，替代军鼓的位置但没有重音。
- 沙锤和刷子这一组的 RMS 比电钢琴低 24 dB。整首**没有底鼓和军鼓**。
- **高音装饰**：同一电钢琴音色，在 G4–A5 的和弦音里零星弹一两个音（约 45% 的小节有），电平约为一个伴奏声部的一半，混响更多，不构成旋律。
- **磁带 wow**：所有有音高的乐器共用一条轻微扭曲的时间轴（0.31 Hz ±0.12% 加 4.7 Hz ±0.04%，约 ±2 音分）。整体有 lo-fi 的晃动感，但乐器之间的音准始终一致。
- **混响**：用合成的立体声冲激响应做卷积，RT60 约 1.7 s，预延迟 18 ms，尾巴越往后越暗。电钢琴发送 30%，装饰 45%，打击乐 18%，贝斯不进混响。
- **母带处理**：
  - 30 Hz 高通去直流和次低频。
  - 2.5 kHz 衰减 2.5 dB（Q 0.8），给人声的清晰度让出位置。
  - 7 kHz 低通，让整体温暖。
  - 左右声道 RMS 对齐。
  - 很轻的 tanh 磁带饱和，饱和之后再做一次 25 Hz 高通去直流。
  - 开头 2 s、结尾 3 s 的余弦淡入淡出。
  - 用 ffmpeg 测量后，按增益归一到 -20 LUFS。
  - 最后加 TPDF 抖动，量化为 16 bit。
- 频带能量（单声道）：
  - 50–200 Hz：-27.0 dBFS
  - 200–1000 Hz：-25.1 dBFS
  - 1–4 kHz：-53.5 dBFS
  - 4–20 kHz：-53.3 dBFS

  也就是说，1–4 kHz 这段人声清晰度频段比主体低约 28 dB，给配音让出了空间。

## 音效

- **`sfx_pop.wav`（卡片出现，0.12 s）**：柔和的木质轻“嗒”。
  - 主体是一段正弦，频率在 12 ms 内从约 1.1 kHz 下滑到 470 Hz，按 22 ms 的时间常数衰减。
  - 叠了 0.5 ms 起音的低通噪声轻敲，外加 5 kHz 低通和 120 Hz 高通。
  - 能量集中在 400–900 Hz，2 kHz 以上很少，所以不刺耳。
- **`sfx_tick.wav`（打勾，0.26 s）**：两个柔和的马林巴式音，A5（880 Hz）之后 65 ms 接 E6（1318.5 Hz），纯五度上行，听感轻快、表示“完成”。
  - 每个音由基音和 3.93 倍泛音组成，泛音衰减很快；1.5 ms 起音，60 ms 衰减。
  - 做了 6 kHz 低通，结尾 30 ms 线性收尾。
  - 这两个音都在 F 大调里，和 BGM 不冲突。
- 两个音效的峰值都是 -6 dBFS，内容是单声道（左右相同），混音时按需要再调音量。

## 混音建议（给合成成片的任务）

- BGM 在整片的时间轴上从 0 s 开始即可：片头期间可以在 0.5–1 s 内淡入，也可以直接从正片开头进入。
- 有人声时，把 BGM 压到比配音低约 18–22 dB（配音约 -16 LUFS 时，BGM 在 -34 到 -38 LUFS）。停顿时可以回升 3–4 dB，但升降要慢，用 300 ms 以上的斜坡，不要泵动感。
- 视频结束（整片约 435.7 s）前 2–3 s 让 BGM 淡出。
- 音效：“嗒”建议在 -18 到 -14 dB 之间（相对原文件），“打勾”在 -16 到 -12 dB 之间，能听到但不要盖过人声。
