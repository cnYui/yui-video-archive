## 制作说明

### 角色动作（只用这几种）

| 动作 | 来源 | 用在哪 |
|---|---|---|
| 走入 / 走出 | 素材包 walk（正面走路），整体从画面左侧平移进来 | S01 开头、S07 结尾 |
| 待机 | 素材包 idle（待机呼吸） | 不说话的时候 |
| 说话 | 新生成：在 idle 上逐帧叠 2–3 个嘴型（用素材包 `源代码/ryo` 的现成嘴型部件拼，不新画像素） | 所有台词 |
| 抬手 | 素材包身体姿势 reach（伸手，掌心朝右），配合说话口型 | 全片 5 次左右：抛出疑问前、列要点时，每次约 1 秒 |

- 角色 ×6 放大（最近邻），站画面左 1/3；S04 讲流程和 S06 录屏时缩到 ×4 放左下角。不镜像翻转。
- 不用：吃草、借钱、被叫怪人、睡觉、贝斯、贴纸表情。

### 背景

- BG1：STARRY Live House 吧台（空镜）。用在 S01–S03、S05、S07，S06 录屏时垫底。
- BG2：下北泽街道（空镜）。用在 S04。
- 处理：深色底 + 背景不透明度约 45% + 轻微模糊，保证文字卡和角色清楚。

### 画面风格

- 文字卡片：纸白底、墨黑字、橙色强调，和片头片尾同一套配色。每个要点一张卡，编号清楚。
- 字幕放底部居中，避开左侧角色。术语（API、接口文档、API Key）用橙色。
- S06 录屏：用浏览器实际录制 DeepSeek 开放平台的操作。账号、余额、实名信息、Key 全部打码，画面上不能出现真实 Key。
- App、工具界面都用虚构示意，不用真实 App 截图和 logo。
- 音效只用两种：卡片出现的轻“嗒”声、打勾声。BGM 用无人声的轻音乐，人声时压低。

### 配音

- 按 `配音分段_v2.json` 的 `tts_text` 生成，字幕用 `text`。
- 英文读法：API 写成“A P I”逐个字母读；DeepSeek 写成“Deep Seek”；网址念“platform 点 deepseek 点 com”。试读时重点听这几处。

### 出片前核对

1. 开放平台的菜单名（“API keys”“创建 API key”“充值”）、Key 是否只完整显示一次、Key 是否以 sk 开头、充值前是否要实名认证：官方文档里查不到原文，录屏时以实际页面为准，不一致就改台词。
2. 接口地址 `https://api.deepseek.com`（OpenAI 格式）/ `https://api.deepseek.com/anthropic`（Anthropic 格式）、模型名 `deepseek-flash`：已按 2026-09-26 的官方文档核对（api-docs.deepseek.com）。出片前再看一次。
3. 余额不足报错码 402：已按官方文档“错误码”页核对。
