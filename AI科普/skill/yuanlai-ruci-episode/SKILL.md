## 流程（✋ = 停下来，等用户确认后再往下做）

### 0. 准备
- **题目**：用户指定就用指定的；没指定就按系列企划 `docs\ai\context\20260926-210154-series-plan-yuanlai-ruci_CN.md`「视频清单」往下取下一期，先告诉用户。企划只用来选题（核心问题、讲什么、关键概念）；企划里的“每期结构模板”（小元翻车现场、主类比贯穿、下期悬念、8–12 分钟）已被用户的台本规则取代，不要照做。和往期内容重叠的部分一句话带过。
- **时长**：正片 5–7 分钟。
- **讲解员**：用户指定哪位就用哪位（第 2 期用户定的是鲸鱼娘）；没说就问。
- 建目录：`python scripts/new_episode.py --number N --title "题目" --presenter ryo|whale`（默认 ryo；生成 `episode.json`（含完整的 `presenter`、`"canvas": [2340, 1080]`、白底 `"bg_color": "#FFFFFF"`、居中 `"layout": "center"`、白板手写版 `"style": "board"`、用户自己配音 `"voice_source": "user"`）、`台本\script_data.py` 骨架、`制作\engine\`）。不改往期任何文件。讲解员的帧还没画完时，`new_episode.py` 会提醒；出草稿用 `sync_assets.py --frames <已有的帧目录> --allow-missing`（不改 episode.json；帧目录不存在时 sync_assets 直接报错，并给出可以临时用的目录）。
- **必须问用户、不许用默认值的两件事**（可以和台本一起问）：
  - 片尾制作清单 `outro_items`（例如拍摄 / 剪辑 / 配音 / 素材来源，按本期实际情况）。用户没说就问，不要沿用上一期或 `片头片尾\outro\data.json` 的默认值。用户自己配音的期，「配音」一栏写 `悠一`（用户 2026-09-28 先定写 UE，当晚改成“之后统一换成悠一”），其余几项照旧每期问。
  - 背景图：2026-09-28 起视频默认纯白背景（`episode.json` 的 `bg_color`，引擎开关；用户：“白底做成引擎开关，以后默认白底”），白板版的封面也是白底（用户 2026-09-28 看了第 3 期白板封面：“可以，你用插件把封面换一下，视频内容也要换一下”），所以**白板版的期不用背景图，不用问**。只有用户要回到卡片版 / 图片背景时（`new_episode.py --style cards --bg-color none`，或删掉 `bg_color`）才问这期有没有新图：有就放进 `素材\背景图库\`（编号续上，原文件不动），没有就从已有的图里给每个章节选一张写进 `backgrounds`，封面也从里面选。不要自己上网找图。

### 1. 台本 ✋
读 `references/script.md`。写 `台本\script_data.py` → `python scripts/build_script.py <期目录>` 生成 `台本.md`、`配音分段.json`。技术事实查官方文档并记下查询日期。写完做两路审校（口播语气与结构 / 技术事实），改完再给用户。
✋ 把分场和全部台词给用户确认，可以改多轮。定稿前不开始配音。

### 2. 配音（用户自己录）✋
读 `references/voice.md`「自己录音」。用户 2026-09-28 定：**《原LAI如此》由用户自己配音**（“原LAI如此配音之后需要我来配音，ai配音用来做每日日报”）；`episode.json` 的 `"voice_source": "user"`（`new_episode.py` 默认写好）。
`python scripts/chunk_voice.py <期目录> --whole`（它打印的音色和 tts_api 提示不用管）→ `python scripts/record_script.py <期目录>` → `配音/录音稿.md`（怎么录、读法表、按章节列段号和字幕原文）+ `配音/录音稿.txt`（提词用）。
✋ 把录音稿发给用户录：手机或麦克风（wav / m4a / mp3），安静的房间，按顺序读、句间停 1 秒左右，读错了停一下把这一句从头再读（脚本保留最后读完整的那一遍），整期一个文件或按章节几个文件都行，录好发文件路径。
- **等录音的时候把别的先做好**（用户：“其他的内容你都要帮我写好，我配音完成后，你再做后续的事情”）：没有录音时 `build_timeline.py` 按字数估每句时长（已有功能），照它写 scenes.js、抽帧自查（第 4 步）、做封面（第 6 步）、写投稿信息草稿。录音到了再按实际时长重跑时间轴，scenes.js 按段号 / 短语挂时间，不用改。
- 用户给了文件：`python scripts/import_voice.py <期目录> <文件1> [文件2 …]` → `select_takes.py`（用最新导入的一版）→ `segment_audio.py`（全局对齐跳过重读和噪音，按停顿切句，对齐字幕）。
✋ 看 `配音/segments/report.txt`：匹配 < 0.8 的句子（可能读错 / 漏读）、按声音修正过切点的句子、跳过的声音，发给用户听；要重录的句子让用户单独录一个文件，`import_voice.py <期目录> --segment <段号> <文件>` 后重跑 `segment_audio.py`。
- 真人录音的第一期：混音后听一下人声和 BGM 的比例（mix_audio 按人声峰值归一，真人录音的峰值比平均响度高得多，BGM 可能显得偏响），有问题再调。
- AI 配音（Fish Audio API，讲解员音色）《原LAI如此》不再用，只在用户点名要时用：`voice_source` 改成 `"tts"`，按 voice.md「AI 配音」做（chunk_voice --whole → tts_api → select_takes → segment_audio；API key、402 改用网页版等规则不变）。AI 配音现在只用于《AI每日日报》。

### 3. 素材

### 4. 画面

## 原则

**内容**（详见 references/script.md）
- 短句、口语、分点讲清楚，不要 AI 腔，少用语气词，不用“不是……而是……”。
- 开场只一句：“大家好，我是{讲解员}，今天给大家介绍 XX。”（讲解员 = `presenter.name`，如山田凉、鲸鱼娘；`build_script.py` 会检查，台词里出现别的讲解员的“我是……”也会提醒）。用户自己配音以后也照旧（用户 2026-09-28：“开场还是说我是鲸鱼娘，配音署名写UE”）：用户用本人的声音念“我是鲸鱼娘”。
- 片头之后先抛出观众实际会遇到的 2–3 个困惑，再逐个拆解。
- 直接给干货（定义、全称、具体操作），不堆例子和比喻；不加角色小癖好（山田凉：吃草、借钱、怪人；鲸鱼娘：白饭、不许叫胖）；不做下期预告。
- 事实以官方文档为准并记下日期；界面、代码一律做“示意”，Key 打码，不画真实品牌 logo。

**画面**（详见 references/visuals.md）
- 版面与尺寸（用户 2026-09-27：之后的视频都做 19.5:9）：视频 2340×1080（`episode.json` 的 `canvas`），封面 16:9 + 4:3。页面 = 画布；scenes.js 按居中的 1920×1080 内容舞台写坐标，全局层铺满画布。第 1 期保持 1920×1080。
- 科普为主，画面平稳克制：不激烈切镜头，不切换 BGM。
- 版面每期固定：左上只有「原LAI如此 #NN」（贴画布左边）；右上「本期目录」（第 1 期样式，贴画布右边）；左下本期讲解员（像素形象，贴画布左边）；字幕按整个画布水平居中；最底是《孤独摇滚！》四色章节进度条（全宽）；背景默认纯白（`bg_color`，2026-09-28 用户：以后默认白底；不写 = 深藏青 + 按章节切换的淡背景图，第 1、2 期）；内容以画面中线居中（`layout: "center"`，和字幕同一条中线，右上目录除外；2026-09-28 起新一期默认，第 1–4 期是旧版面）。
- 白板手写版（`style: "board"`，2026-09-28 起新一期默认）：说到的要点边说边手写，画面比声音早 1 秒，字幕 56 px 墨黑字白边（和《AI每日日报》一样大）。第 1–4 期是印刷体卡片版，不动。
- 角色动作两层：自动层（台本不用写）+ 台本动作词表（讲解员动作，贴着台词用；「好耶」的拉炮保留）；不做角色梗、不频繁走动。“多少合适”按 AGENTS.md「角色动作尺度」逐期校准。
- 只用 `素材\字体\` 的 OFL 字体，不用微软雅黑等系统字体。

**安全与合规**
- 不点「立即投稿」，不替用户付费、充值或升级（用户点名要 AI 配音时：Fish Audio API 按字节从用户余额扣费，只用 s1；余额不足就改用网页版（用户的 Plus 额度），不替用户充值）。
- Fish Audio 的 API key 只放在用户环境变量里：不回显、不落盘、不输入到网页。用户的录音文件只读，导入产物放本期 `配音\raw\`。
- 不点允许浏览器的安全类权限提示（如“访问本地网络”），也不尝试绕过插件的上传大小限制。
- 用户装了 dcg 钩子拦截删除命令：不要绕过，需要清理就移到 `SERIES\_旧稿\` 或本期的 `_旧稿\`。

**工程**
- 所有时间由 `timeline.json` 驱动（它由脚本生成，不手改）。
- 每个阶段的产物都落盘，可以单独重跑。
