# 封面

**封面和标题的协定**（用户 2026-10-03：「封面文字中最下面一行的小字可以删除，因为用户根本看不见……封面中的文字要简略要大，标题则需要详细，这个规则对我目前做的所有的视频skill都要生效」）：封面上只放几个**简短的大字**（关键词 / 钩子），**不放最下面那行小字**（副标题、说明、清单、来源署名之类，缩到信息流里根本看不见）；**标题写详细**，把封面放不下的信息（时间、数量、对象、结论……）写进标题，不和封面是同一句。例：封面「大模型 / 谁夯谁拉？」→ 标题「2026下半年大模型谁夯谁拉？18个模型锐评」。系列名、期号这类合集标识照旧。
黑板版因此只有 `t1`、`t2` 两行大字，`cover.json` 里写了 `sub` / `hl` 也不画（`make_cover.py` 会提醒）。白板版、小票版是以前的模板，里面的第三行小字只是历史。

封面有三套模板，都在 `assets/cover-template/`。同一个命令 `python scripts/make_cover.py <期目录>`，按这个顺序选：`封面/cover.json` 的 `"style"` > `episode.json` 的 `"cover_style"` > `episode.json` 的 `"style"`。

| 模板 | 用在哪 | 样子 |
|---|---|---|
| **黑板版** `cover.chalk.html` | 新一期默认（`new_episode.py` 在 episode.json 写 `"cover_style": "chalk"`）；第 1–6 期 2026-10-03 也换成了它（各期 `封面/cover.json` 写了 `"style": "chalk"`） | 深绿黑板，标题是粉笔手写，讲解员站在粉笔槽上指着标题 |
| 白板版 `cover.board.html` | 第 3–6 期以前用的（旧图在各期 `封面/_旧稿_20261003_换黑板版前/`） | 白底，标题手写，讲解员在左下角指着标题 |
| 小票卡片 `cover.template.html` | 第 1、2、4 期以前用的（同上） | 背景图 + 倾斜的纸白小票 |

黑板版的由来：用户 2026-10-02：「原LAI如此的封面，你重新设计一下，要出现鲸鱼娘的形象，但是要和每日日报的风格区分开来，你给我设计三种不同的风格」。白板版和日报一样是白底，放在一起分不出来。三个方向（A 黑板粉笔 / B 橙色海报：系列橙满版 + 集中线 + 大半身贴纸 / C 像素对话框：深蓝像素夜空 + 复古游戏对话框）用第 6、3 期的文案出样稿、在信息流尺寸下比，用户选了 A。样稿和生成脚本在 `SERIES\_skilltest\cover_styles_20261002\`。

往期也换了：用户 2026-10-03：「你去b站投稿页面看一下之前的几期视频，然后重新生成之前的封面并进行替换」。第 1–6 期全部用黑板版重出（文案沿用各期原来封面上的字；第 1 期是山田凉那期，标题也是“凉前辈来教你”，封面用她），在 B 站编辑页换掉 16:9 和 4:3 两个位并核对过；旧封面挪进各期 `封面\_旧稿_20261003_换黑板版前\`，重出用的暂存目录是 `SERIES\_skilltest\cover_chalk_redo_20261003\`。

白板版的由来：用户 2026-09-28 看完第 3 期白板测试样片：「就是这个风格的，没问题，然后封面你也要重新生成一下相同的风格」。看了白板封面后，用户说「可以」。
小票卡片的由来：第 1 期三个方向并行出稿（小票卡片 / 超大字 / 三个问题），在信息流缩略图尺寸下评审后选定。

尺寸按 B 站要求：**16:9（1920×1080）和 4:3（1440×1080）**，4:3 是 16:9 正中间 1440 宽的裁切。视频从第 2 期起是 2340×1080（`episode.json` 的 `canvas`），封面不跟它走，`make_cover.py` 不读 `canvas`。

## 黑板版（全部期数，2026-10-02 / 10-03 定）

2026-10-03 用户看了第一版（鲸鱼娘在画面偏左 1/4、标题在右半）：「鲸鱼娘的形象再往左一些，标题可以再大一些」，看了微调版后「可以，统一替换吧」。下面是微调后的版式（第一版的图在各期 `封面\_旧稿_20261003_黑板版第一版\`）。

### 版式

- **背景**：深绿黑板（中间亮一点的径向渐变 + 固定种子的粉笔灰点 + 两块擦过的淡白痕迹），最底下一条木头粉笔槽（y 1016 起），槽上三支粉笔（白、黄、橙）。
- **左上**：印刷体的系列名「■ 原LAI如此」（LAI 橙色）、四色胶囊、黄框期号 `#NN`（16:9 x 120 起，4:3 x 60 起）。
- **右边两行粉笔手写**（`hand.js`，和视频同一只手；加一层噪声做粉笔颗粒，颗粒别调重，缩略图会发灰）：
  - `t1`：粉笔黄 `#FFE066` 大字，下面一道白粉笔波浪线；
  - `t2`：白粉笔，结尾的 ？ 用橙色粉笔；
  - 没有第三行（2026-10-03 起：最下面那行小字删掉，原来的 `sub` 信息写进标题）。第 1–6 期同日去掉小字重出、在 B 站两个位又换了一次并核对过（带小字的第二版在各期 `封面\_旧稿_20261003_黑板版第二版\`，暂存目录 `SERIES\_skilltest\cover_chalk_v3_20261003\`）。
  - 标题块 16:9 x 730–1800、4:3 x 670–1390，在 y 150–930 之间上下居中；字号上限 16:9 `t1px` 380 / `t2px` 260，4:3 340 / 240；一行太长自动缩小，两行加起来太高就一起缩小。
  - 4:3 宽度有限，四个字的 t1（深度思考、AI率62%）在 4:3 里和第一版差不多大，短的（API、Jev）大一圈；16:9 里都大了 1.2–1.5 倍。
  - 笔宽是字号的 0.1（视频 0.07），粉笔粗一点，缩到信息流也看得清。
- **左下**：本期讲解员 `reach_m2/00.png`（指向标题），×9 最近邻，**不镜像**，贴着画面左边（帧左边 16:9 x 100、4:3 x 40；指着标题的手 / 尾巴尖到帧左边 + 585）；外面一圈奶白描边（1 个精灵像素，`make_cover.py` 加好存成 `封面/sprite.png`，深色的轮廓线在黑板上才不糊），脚踩粉笔槽。
- **构图**：16:9 和 4:3 **各排一版**（`make_cover.py` 的 `CHALK_LAYOUT`）：鲸鱼娘贴左边以后 4:3 不能再从 16:9 中间裁。模板按 `__DATA__.canvas` 的宽度排版，`make_cover.py` 渲染两次（1920 宽、1440 宽，后一次切左边 1440 px）。B 站上传时两个位各传各的（见下面「已发布的稿件换封面」）。

### 做法

1. `python scripts/make_cover.py <期目录>`：第一次运行写出 `封面\cover.json` 骨架并停下。
2. 填 `cover.json`（第 6 期的文案放进黑板版就是这样，测试图见 `_skilltest\cover_styles_20261002\`）：
   ```json
   {
     "t1": "深度思考",
     "t2": "AI 在想什么？",
     "sprite": "reach_m2/00.png"
   }
   ```
   这期的标题对应写成详细的一句：「点了“深度思考”，AI那几十秒到底在想什么？｜原LAI如此 #06」（封面两行是关键词和钩子，标题把“点了”“几十秒”这些细节补上）。
   - `t1` / `t2` 的写法和白板版一样（见下）；有写不出来的字（没有笔画数据）会直接报错，换个写法。
   - 可选 `eyes`：换表情，写她帧目录里另一帧的 key（`idle_happy_m0`、`idle_surprised_m0`、`idle_determined_m0`），只换眼睛那一块（她 anims.json 的 `patch_rects.eyes`）。
   - 可选 `fx`：叠特效帧，例如 `["fx_emph"]`（！）、`["fx_think#2"]`（思考泡，第 3 帧）。
   - 模板参数可以在 cover.json 里覆盖：标题块 `bx` / `bxr` / `btop` / `bbot`、字号上限 `t1px` / `t2px`、行距 `gap1`、笔宽 `pen`、颜色 `colors` `{t1, text, q, ul}`、下划线 `ul` `{on, w, gap}`、系列名 `brand` `{x, y, px}`、讲解员 `scale` / `whoX` / `foot`、粉笔槽 `tray`。直接写的键两个比例都改；只改一个比例写在 `"16x9": {...}` 或 `"4x3": {...}` 里（默认值见 `make_cover.py` 的 `CHALK_LAYOUT`）。
3. 再运行一次，输出 `封面_16x9_1920x1080.png`、`封面_4x3_1440x1080.png`、`封面_预览.png`（同下）。

## 白板版（第 3–6 期）

### 版式

- **背景**：纯白，和视频的白板一样，不用背景图。
- **左上**：印刷体的系列名「■ 原LAI如此」、四色胶囊、墨黑期号 `#NN`。和视频左上角、小票票头是同一套。
- **右边三行手写**：
  - `t1`：大字，下面一道黄色记号笔波浪线；
  - `t2`：第二行，结尾的 ？ 用系列橙；
  - `sub`：小一点的第三行，结尾问号也是橙色，其中 `hl` 那一段下面划黄线。
  - 三行按墨迹外框叠起来，在 y 150–846 之间上下居中。每一行太长就自动缩小，不会超过右边界。
- **手写和视频是同一只“手”**：用这一期 `制作/engine/` 的 `hand.js` 画，笔画数据由同目录的 `hand_glyphs.py` 生成，只收封面上的字，写在 `封面/_handdata.js`。
  - 所以字形、字距、抖动、记号笔都和视频一致，封面等于“写完那一刻”的白板。
  - 期目录里没有这两个文件时（引擎是白板版之前复制的），先用 `assets/engine-template` 的，并打印提醒。
  - 笔宽是字号的 0.075，比视频的 0.07 略粗，为了缩略图。
- **左下**：本期讲解员 `reach_m2/00.png`，伸手指向标题。
  - 最近邻 ×9，**不镜像**，不描边，脚下一小块淡投影；
  - 头顶是小票版的像素问号（`q.on`）。
  - 鲸鱼娘的尾巴在右边，不压标题；4:3 裁切裁不到她。
- **构图**：所有要紧的东西都在正中间的 1440 宽里，所以 4:3 裁切和 16:9 一样完整，16:9 只是两边多留白。

### 做法

1. `python scripts/make_cover.py <期目录>`：第一次运行写出 `封面\cover.json` 骨架并停下。
2. 填 `cover.json`：
   ```json
   {
     "t1": "Jev",
     "t2": "是什么？",
     "sub": "和 LLM 有什么区别？",
     "hl": "有什么区别",
     "sprite": "reach_m2/00.png",
     "ul": {"gap": 26},
     "q": {"on": true}
   }
   ```
   这就是第 3 期白板版的 cover.json。
   - `t1`：放本期最核心、观众会搜的词（API、Token、MCP……）。
     - 英文词短，写出来最大、最醒目；太长会自动缩小。
     - 中文标题可以把整句放 `t2`，`t1` 只放关键词。
   - `sub`：对应标题里的第二个疑问，一行写完。
     - 从小票版改过来的 cover.json 只有 `subHTML` 时，脚本会去掉标签当 `sub` 用。
     - 小票版的 `bg_file`、`bg`、`plain` 在白板版里不读。
   - `hl`：`sub` 里要划黄线的一段，必须一字不差；不需要就留空。
   - `sprite`：规则和小票版一样（见下）。
   - 这些模板参数可以在 cover.json 里覆盖（对象参数只覆盖写了的字段）：
     - 字号上限 `t1px` 430 / `t2px` 214 / `subpx` 84；
     - 笔宽 `pen`；
     - 标题块 `bx` 860 / `bxr` 1652（左边、右边界）、`btop` / `bbot`（上下居中的范围）、行距 `gap1` / `gap2`；
     - 下划线 `ul` `{on, w, gap}`、`hlW`；
     - 系列名 `brand` `{x, y, px}`；
     - 讲解员 `scale`、`whoX`（帧的左边 x）、`foot`（鞋底 y）、`shadow`；
     - 像素问号 `q` `{on, sx, sy}`；
     - 手画的橙色箭头 `arrow` `{on, x0, y0, x1, y1}`，默认关。
   - 小票版讲解员预设里的 `cover` 参数（小票的几何）白板版不用。
   - 有写不出来的字（没有笔画数据）会直接报错，换个写法。
3. 再运行一次，输出和小票版一样：
   - `封面_16x9_1920x1080.png`；
   - `封面_4x3_1440x1080.png`；
   - `封面_预览.png`。

## 小票卡片版（第 1、2、4 期）

### 版式

- **右侧**：一张略微倾斜的纸白小票。
  - 票头「■ 原LAI如此」+ 四色胶囊 + 墨黑期号 `#NN`；
  - 主标题两行：大字 `t1` + 第二行 `t2`，结尾问号橙色；
  - 虚线下面一行副标题 `subHTML`，关键词垫黄色荧光笔。
- **左侧**：本期讲解员伸手指向标题，头顶一个像素问号。
  - 用她帧目录 `presenter.frames` 里的 `reach_m2/00.png`，最近邻整数倍，墨黑 + 纸白双描边，**不镜像**。
  - 山田凉 ×11（第 1 期的样子）。
  - 鲸鱼娘比她宽（头饰、头鳍、尾巴），预设是 ×9、`ryoX` 232、小票 `rx` 790 / `rw` 850，让尾巴不压标题、4:3 裁切不裁到她。
- **背景**：背景图库里的一张（`cover.json` 的 `bg_file`），模糊 8px、不透明度 0.36，叠在深藏青上，加暗角。
  - 视频白底（`bg_color`）不影响小票版封面，照旧用图（第 3 期用户当时：“封面背景不要变，视频里的背景修改为白色即可”）。
  - 白底的一期 `backgrounds` 是空的，第一次生成的 cover.json 里 `bg_file` 也是空的，脚本会停下来提醒：填上和用户商量好的那张再跑。
  - 用户要纯色封面、不用图时（第 4 期），在 cover.json 写 `"plain": "#FFFFFF"`：不读 `bg_file`，没有暗角和暖光，小票和角色的阴影变淡。

### 做法

1. `python scripts/make_cover.py <期目录>`：第一次运行写出 `封面\cover.json` 骨架并停下。
2. 填 `cover.json`：
   ```json
   {
     "t1": "Token",
     "t2": "是什么？",
     "subHTML": "问 AI 一句话，<span class=\"hl\">到底花了多少钱</span><span class=\"o\">？</span>",
     "bg_file": "02_斑马线_夕阳.jpg",
     "sprite": "reach_m2/00.png",
     "bg": {"scale": 1.0, "fx": 0.5, "fy": 0.5, "opacity": 0.36, "blur": 8}
   }
   ```
   - `t1`：放本期最核心、观众会搜的词（API、Token、MCP……）。
     - 太长会自动缩小，并把小票撕短，不会溢出。
     - 最好不超过 6 个字符宽；中文标题可以把整句放 `t2`，`t1` 放关键词。
   - `subHTML`：对应标题里的第二个疑问，一行写完。
     - `.hl` 荧光笔、`.o` 橙色、`.qm` 收紧的中文引号。
     - 用法见第 1 期：`<span class="hl"><span class="qm o1">“</span>已接入 DeepSeek<span class="qm c">”</span></span>`。
   - `sprite`：讲解员帧目录里的路径，或 anims.json 的 key（`reach_m2`、`reach_m2#3` = 第 3 帧）。她还没有这一帧时（例如鲸鱼娘的动作帧没画完），先用 `idle_m0` 第 0 帧并打印提醒，帧画完后重跑。
   - 背景构图不好时，调 `bg.fx / fy`（0–1，焦点位置）和 `bg.scale`（放大倍数）。
   - 其他模板参数也能在这里覆盖：`rx`、`rw`、`t1px`、`scale`、`ryoX`（角色左边 x，名字是历史原因）、`q`、`shadow`、`floor` 等。
     - 对象参数（`bg`、`q`、`spot`、`shadow`、`floor`）只覆盖写了的字段。
     - `q` 可以写 `x` / `y`（屏幕像素），或 `sx` / `sy`（精灵像素，跟着 `scale`、`ryoX` 走）。
   - 覆盖顺序：模板默认（第 1 期）< 讲解员预设 `scripts/epcommon.py` `PRESENTERS[id]["cover"]` < `episode.json` 的 `presenter.cover` < `cover.json`。某位讲解员每期都要的调整写进预设，只这一期的写 `cover.json`。
3. 再运行一次，得到：
   - `封面_16x9_1920x1080.png`；
   - `封面_4x3_1440x1080.png`：中间 1440 宽的裁切，角色和小票都在里面；
   - `封面_预览.png`：两个比例 + 信息流 320×180、480×270、4:3 320×240 的模拟缩略图（带播放量和时长角标）。

## 自查（两套都一样，给用户看之前）

用 Read 看 `封面_预览.png`，在 320×180 那一格检查：
- 两行大字一眼能读出来；封面上没有小字（黑板版；白板版 / 小票版的副标题是历史）；
- 右下角的时长角标、左下的播放量没有压住关键文字；
- 角色是本期讲解员，没有被 4:3 裁掉、没有镜像；鲸鱼娘的尾巴没有压到标题；
- 小票版：背景不花，文字和背景对比足够；
- 白板版：手写字没有缺笔、黄线没有压进字里、三行之间不挤；
- 黑板版：粉笔字在 320×180 里读得出来（`t1` 的黄字最醒目），颗粒没有把字吃掉；讲解员的奶白描边完整、没被 4:3 裁到，指的方向朝着标题。

不满意就改 `cover.json` 重跑。想尝试新版式时，可以像第 1 期那样几个方向并行出稿、在缩略图尺寸下评审。新版式定稿后要更新模板，保持以后每期一致。

已发布的稿件换封面（2026-10-03 第 1–6 期全部换成黑板版时走通的）：

2. 点「封面设置」（`.cover-module-main .edit-text`，JS `click()`）。
3. 在封面制作弹窗里：**关掉「双比例同步改动」**，点「个人空间封面（16:9）」标题，`file_upload` 传 `封面_16x9_1920x1080.png`；再点「首页推荐封面（4:3）」标题，传 `封面_4x3_1440x1080.png`。文件框是 accept `image/png, image/jpeg` 的那个（`find`「上传封面」）。截图看两栏都是新图。
4. 点「完成」（`div.button.submit`，JS 按文字找）。
5. 核对标题、标签、简介字数都没变，表单封面缩略图是新的 4:3。
6. 「立即投稿」：新投稿永远由用户点；换已发布稿件的封面，用户明确说了“替换”才由我点（2026-10-03 就是这样），只点一次，看到「稿件投递成功」。
7. 用接口核对两个位（见下面的规律），状态会先变成「修改内容待审核…」，过一会儿回到「开放浏览」。

旧封面文件移进 `封面\_旧稿_<日期>_…\`，放进上传的那几张和 cover.json。

**B 站封面编辑器的规律（2026-10-03 给第 1–6 期换封面时摸清的，以这里为准）**：
- 「双比例同步改动」（`label.sync-checkbox`，勾上时 class 多一个 `bcc-checkbox-checked`）6 期打开时**全都没勾**。
- 开着同步传 16:9 不可靠：第 1 期 4:3 位按裁切框裁成了 1440×1080，第 2 期 4:3 位却存成了整张 1920×1080；第 4 期先点了「首页推荐封面（4:3）」再开同步上传，16:9 位变成了从 4:3 裁出来的放大图。
- **确定的做法：关掉同步，两个位各传各的**：点「个人空间封面（16:9）」标题 → 传 `封面_16x9_1920x1080.png`；点「首页推荐封面（4:3）」标题 → 传 `封面_4x3_1440x1080.png`（4:3 位两边留灰 = 装的是 4:3 那张）→ 截图看两栏 → 「完成」。
- 只换了一个位就点「完成」，会弹「检测到个人空间封面（16:9）未修改……是否将 4:3 的改动同步到 16:9」：点「不同步，手动编辑」，把另一个位也传上再「完成」（点「确认同步」会拿 4:3 裁出一张放大的 16:9）。
- 「完成」后表单里的封面缩略图是 4:3 位（1440×1080），用它确认 4:3 位换上了；提交后用 `x/vupre/web/archive/view` 的 `cover`（要 1920×1080）、`cover43`（要 1440×1080）各取样核对，`x/web-interface/view` 的 `pic` 是公开页用的 16:9。
- 提交后状态先是「修改内容待审核…」，这 6 期几分钟内都回到「开放浏览」。
