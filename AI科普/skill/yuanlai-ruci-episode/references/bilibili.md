# B 站投稿页

用 Claude in Chrome 插件在用户自己的 Chrome 里操作（用户在那里登录了 B 站）。投稿页：https://member.bilibili.com/platform/upload/video/frame

**两条红线**
- 「立即投稿」（以及任何“发布 / 提交”按钮）永远不点。填完就停，让用户检查后自己发。
- 不点允许浏览器的安全类权限提示（本地网络访问等），不尝试绕过插件的上传大小限制。

## 1. 上传视频（用户操作）

插件单次上传上限 10 MB，成片通常 70–90 MB，所以请用户自己在投稿页点「上传视频」，选 `第NN期_<题目>\第NN期_<题目>_成片.mp4`（给出完整路径）。表单只有选了视频之后才出现。用户说开始上传了，再往下填。

第 1 期曾尝试在本机 127.0.0.1 起服务器让页面去取文件：Chrome 弹出“访问本地网络”权限提示，页面被挂住。不要再这么做。

## 2. 标题

- 格式：`问题式标题｜原LAI如此 #NN`，总长 ≤ 80 字。第 1 期：`什么是API？“已接入DeepSeek”接的是什么？API Key怎么拿？｜原LAI如此 #01`。
- 前半截放观众会搜的词、和片中抛出的疑问对应；系列名和期号放在最后。
- 操作：`triple_click` 标题框 → `ctrl+a` → `Delete` → `type` → 截图确认计数。第 2 期 `type` 之后框里文字对了、计数却还停在旧值（18/80）：用 `javascript_tool` 对标题 input 派发 `input`、`change`、`blur` 事件，计数变成 48/80 才算写进去。
- 用户指定了标题就一字不改地用（第 2 期用户：“用我原定的标题”=「你的一句话就否定了AI一路的努力——AI是怎么从学会说人话到实现AGI的？｜原LAI如此 #02」）。
- 第 3 期：按截图坐标点标题框时页面刚好滚动，点空了（ctrl+a 选中了整页，打的字没进任何输入框）。标题框用 `find`（“请输入稿件标题”）拿 ref → `scroll_to` → `triple_click` ref → ctrl+a → Delete → type，再派发 input / change / blur，截图看计数。

## 3. 标签（10 个）

- 组成：本期核心词 4–6 个 + `AI科普`、`人工智能`/`大模型` 这类大词 + 固定的 `原来如此`、`原LAI如此`。单搜“原LAI如此”会被动画《玲音 Lain》的结果淹没，所以两个都要带。
- B 站会根据视频自动加标签（第 1 期加了“学习”“编程”“api”），先点它们的 × 删掉。
- 逐个输入：`type` 标签 → `Return` → 等 0.6 秒。
- 有些词是**话题专用标签**（第 1 期的“Claude”），只能通过“参与话题”加，不能自定义输入；换成别的词（第 1 期换成了“API调用”），并告诉用户。还有的词回车后**悄悄消失**（第 2 期的“通用人工智能”，输入框清空、没有提示，试两次都一样）：换词（第 2 期换成“AI发展史”），用 `javascript_tool` 读 `.tag-container .label-item-v2-content` 核对最后是不是 10 个。
- 删自动标签：`.tag-container .label-item-v2-container svg.close` 逐个派发 `click` 最稳。
- 2026-09-28 教程视频：B 站自动加的“教程、低成本、claude”都贴题就留着了（小写的 claude 自动加上是可以的，自己输入“Claude”才会被当成话题标签）；“AI视频生成”回车后被吞，换成“像素动画”。
- 填标签可能让 B 站**自动改分区**（第 1、2 期都被改成了 vlog），所以分区放在标签之后设置，最后再核对一遍。

## 4. 分区

分区现在是一层平铺的列表（2026-09-27：影视、娱乐 … 资讯、知识、**人工智能**、科技数码 …）。AI 科普选「人工智能」（第 2 期；上传后 B 站起初自动推荐的也是它），告诉用户，用户想和第 1 期一样放「知识」也可以。

第 3 期：填完标题 B 站推荐成「人工智能」，关掉封面弹窗后又变回「科技数码」。所以分区放在最后设：点开下拉，用 `javascript_tool` 点 `.drop-list-v2-item-cont` 里文字是「人工智能」的那一项，再读一遍分区那一行核对。

## 5. 封面

- 封面 PNG 只有 1–2 MB，可以用插件的 `file_upload`：`find` 封面编辑器里接受 image/png 的文件输入框 → 上传 `封面\封面_16x9_1920x1080.png`。
- 编辑器里有 16:9 和 4:3 两个比例：两个都要设置，4:3 用 `封面_4x3_1440x1080.png`（或在 4:3 里把裁切框对准同一构图）。完成后截图确认两个比例都是新封面。
- 第 2 期的封面编辑器（「封面制作」弹窗）：文件输入框在左下「上传封面」下面（accept `image/png, image/jpeg`），上传 16:9 那张；「双比例同步改动」默认勾着，4:3 自动取正中间，和 `封面_4x3` 的裁法一样，不用再单独传。点「完成」后表单里的封面缩略图会晚一两秒出来。
- **4:3 用单独排版的封面**（2026-09-28 教程视频，4:3 版和 16:9 取正中间不一样时）：先在同步开着时传 16:9；再点掉「双比例同步改动」的勾（在 4:3 预览上方那条工具栏右边），点一下「首页推荐封面（4:3）」标签，用同一个「上传封面」文件框传 4:3 那张——只有 4:3 换了，16:9 不变。截图核对两栏后点「完成」，表单缩略图显示的是 4:3。
- 第 4 期（2026-09-28）：`find` 看不到这个弹窗里的按钮；「完成」是 `div.button.submit`，用 `javascript_tool` 找文字是“完成”、可见的那个 `click()`。

## 6. 简介

按第 1 期的格式（每行之间用 `Return`，段落之间空一行）：

```text
《原LAI如此》AI 科普系列第 N 期。

<一两句：观众的困惑 + 这期讲清楚哪几件事>

本期内容
00:00 开场
00:09 <疑问章节>
…（和 _章节.txt 一致，mm:ss 格式，B 站会自动变成可点击的时间戳）

补充说明
· 接口地址、模型名等信息截至 YYYY 年 M 月，以官方文档为准（<官方文档域名>）。
· 视频里的代码和界面都是简化示意。<本期相关的安全提醒，例如 Key 不要外传>
· 配音为 AI 合成；背景图片来自《孤独摇滚！》，版权归原作方所有。（2026-09-28 起用户自己配音的期不写“配音为 AI 合成”，写“配音：悠一”（用户 2026-09-28 先说“配音署名写UE”，当晚改成“之后统一换成悠一”）；视频不用背景图的期删掉背景图出处，封面用了背景图就写“封面背景图片来自……”）
```

写完用 `javascript_tool` 读回编辑器里的文本核对一遍（找内容包含“原LAI如此》AI”的 textarea 或 contenteditable）。

第 4 期（2026-09-28）起简介用 Quill `setText` 写入，比逐行 `type` 快，也不会把行首“1. ”变成列表：
- 找 `data-placeholder` 以“填写更全面”开头的 `.ql-editor`，调用 `closest('.ql-container').__quill.setText(简介, 'user')`。
- 再用 `getText()` 去掉末尾换行，和本地原文逐字比对，只返回 true / false 和字数。
- **还要看表单自己的计数**：简介框下面的 `N/2000` 要变成这个字数。只看 `getText()` 不够，那只说明编辑器里有字。
- 做法同《AI每日日报》技能第 8 步。

第 3 期的教训（2026-09-28 晚查出）：
- 填写时 `getText()` 读回 559 字、逐字一致，用户也点了投稿，线上简介却是空的（接口 `desc` 长度 0）。
- 同样用 setText 写的第 4 期（630 字）和日报（979 字、1996 字）都正常。
- 原因没查实：可能是编辑器里有字、表单的数据没跟着更新，也可能是提交时没带上。
- 2026-09-28 晚在第 3 期编辑页试过：`setText(…, 'user')` 之后计数马上变成 532/2000。
- 所以：setText 一定带 `'user'`，看计数，投稿后按 §9 用接口核对。

## 7. 合集

- 合集「原LAI如此」已经建好（2026-09-27），直接选它，不要再新建。
- 2026-09-28 第 4 期：在下面的「加入合集」下拉里选了「原LAI如此」以后，同名的标签「原LAI如此」被自动删掉了（标签剩 9 个），「创作声明」也同时变成了「含AI生成内容」。所以**选完合集再读一遍标签**（`.tag-container .label-item-v2-content`），少了就重新输入补回；创作声明照样提醒用户核对。
- 如果将来要新建合集：在“创建合集”输入框里 `type` 名字后，字数计数可能不刷新，需要用 `javascript_tool` 对这个 input 派发 `input` 和 `change` 事件。
- “此稿件不生成更新推送”保持不勾。
- 第 3 期：下拉里的「原LAI如此」是 `.season-item`（文字在 `p.season-item-title`），叶子节点找不到时用 JS 点 `.season-item`；选完合集 10 个标签都还在（第 4 期那次少了一个），照样读一遍核对。

## 8. 停下 ✋

截图整页（分几屏），告诉用户：
- 已填：标题、10 个标签（说明换掉了哪些）、分区、封面两个比例、简介、合集。
- 请用户处理：选创作声明（AI 合成内容那一项），检查分区是否被改回，然后自己点「立即投稿」。页面底部「立即投稿」旁边还有「存草稿」，两个都不点。
- 第 3 期：用户说“然后发布”，创作声明由主会话选好「含AI生成内容」（`.bcc-option`），填完用 JS 读回标题、声明、分区、10 个标签、简介字数、合集核对后停下，问用户；用户自己点了「立即投稿」。投稿后在「内容管理 → 稿件管理」（https://member.bilibili.com/platform/upload-manager/article ）的标题链接里能拿到 BV 号，记进 AGENTS.md。
- 版权提醒：形象、背景图、配音音色都来自《孤独摇滚！》相关素材，适合非商业投稿；开通激励、充电或接商单之前要重新评估。

## 9. 投稿后核对（用户点了「立即投稿」之后）

- 拿到 BV 号，隔几分钟在插件的标签页里用 `javascript_tool` 查接口：
  ```js
  const r = await fetch('https://api.bilibili.com/x/web-interface/view?bvid=<BV号>', {credentials: 'include'}).then(r => r.json());
  ({code: r.code, title: r.data.title, descLen: (r.data.desc || '').length, duration: r.data.duration, state: r.data.state})
  ```
- 看 `descLen` 等不等于简介字数、`duration` 对不对。**简介为空就告诉用户**，用户同意后按 §10 在编辑页补回。补简介要重新过审。
- 还在审核中的稿件，接口可能查不到，或者还是旧的内容：过审后再查一次。

## 10. 已发布稿件的修改（换封面、换视频、补简介）

2026-09-28 第 3 期试过：用户先让把封面和视频换成白板版，后来又说「这期已经发布了，先不动」，就没提交。步骤是实测过的。
- **编辑页**：`https://member.bilibili.com/platform/upload/video/frame?type=edit&bvid=<BV号>`。
  - 标题、标签、分区、创作声明、合集都会带出来。
  - 简介也会带出来；线上是空的，这里就是空的。
- **换视频**：视频条目右边有「更换视频」（`.file-list .file-item` 里）。成片超过插件的 10 MB 上限，由**用户自己点、自己选文件**；插件不传、不绕过。等条目显示「上传完成」再往下核对。
- **换封面**：
  1. 在封面上悬停，点「封面设置」（`.cover-module-main .edit-text`，用 JS `click()`）。
  2. 在弹窗里 `find`「上传封面」的文件输入框（accept `image/png, image/jpeg`），`file_upload` 新的 `封面_16x9_1920x1080.png`。「双比例同步改动」默认勾着，4:3 取正中间。截图看两个比例。
  3. 点「完成」：它是 `.cover-editor-content-right-bottom` 里的 `div.button.submit`。`find` 看不到这个弹窗，用 JS 找文字是“完成”、可见的叶子 div，`click()`。按截图坐标点容易点偏：页面缩放是 0.896，弹窗大小还会变。
- **补简介**：同 §6，用 setText 带 `'user'`，看计数。
- **核对后停下**：用 JS 读回标题、10 个标签、简介字数、合集、封面缩略图，告诉用户改了什么。「立即投稿」由用户点，修改后要重新过审。
- **不提交就关掉标签页**：表单里的改动全部作废，线上不变。
- **这个页面截图常超时**（`Page.captureScreenshot` 30 s）：等几秒重试一次；不行就用 `javascript_tool` / `get_page_text` 读状态，别连续重试截图。
