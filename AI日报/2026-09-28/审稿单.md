## 8. 笔记本硬跑 744B 大模型
- 来源：量子位 · GitHub　日期：9月26日
- 要点：1. 744B GLM 塞进笔记本；2. 专家权重放 SSD；3. 最低 16GB 内存；4. 笔记本每秒≤0.1 token
  1. 最后一件轻松点：笔记本能不能跑七千多亿参数的大模型？　〔—〕
  2. GitHub 上很火的开源项目 Colibrì 做到了，它是纯 C 写的推理引擎。　〔✓〕
  3. 项目在 GitHub 上已经拿到 3 万多星标。　〔✓〕
  4. 它把每次都要用的部分放在内存里，其余的专家权重放在 SSD 上，要用的时候再读。　〔✓〕
  5. 这样，总参数 744B 的 GLM-5.2，压到 int4 大约 372GB。　〔✓〕
  6. 最低 16GB 内存就能跑，不需要显卡。　〔✓〕
  7. 它现在已经支持 9 个模型家族，包括 Kimi K3 和 DeepSeek V4 Flash。　〔✓〕
  8. 代价是速度：在 25GB 内存的笔记本上，每秒只能出 0.05 到 0.1 个 token。　〔✓〕
  9. 换成 128GB 内存的台式机，大约每秒 1.8 个。　〔✓〕
  10. 所以它更像一次技术验证，想在家用起来，还得等它再快一些。　〔—〕
