## 第一条：EmbeddingGemma 2

第一件，Google DeepMind 发布了 EmbeddingGemma 2，一个开放的多模态嵌入模型。
First, Google DeepMind released EmbeddingGemma 2, an open multimodal embedding model.

它把文字、图片、视频和音频映射到同一个向量空间，方便搜索和比较相似度。
It maps text, images, video and audio into one vector space for search and similarity comparison.

模型有 740M 参数，输出 768 维向量，也能截短到 512、256 或 128 维。
The model has 740 million parameters and outputs 768-dimensional vectors, which can be shortened to 512, 256 or 128 dimensions.

它支持一百多种语言，采用 Apache 2.0 许可，权重当天公开。
It supports more than 100 languages, uses the Apache 2.0 license, and released its weights the same day.

对做本地搜索和问答的人来说，重点是四种媒体可以一起检索。
For local search and Q&A, the key is that four media types can be retrieved together.

## 第二条：RTX Spark 把智能体带到 Windows

第二件，英伟达和微软宣布合作，让 AI 智能体更深地跑在 Windows 电脑上。
Second, NVIDIA and Microsoft announced a partnership to run AI agents more deeply on Windows PCs.

NVIDIA 的 RTX Spark 今天开放预订，定位是一台本地 AI 设备。
NVIDIA's RTX Spark opened for preorders today as a local AI device.

英伟达还预览了 DGX Station for Windows，面向企业桌面环境。
NVIDIA also previewed DGX Station for Windows for enterprise desktop environments.

双方的方向很清楚：让智能体直接调用 Windows 上的软件和算力。
The direction is clear: let agents directly use software and compute on Windows.

这不是单纯换一台电脑，关键在于本地模型和桌面操作开始合在一起。
This is more than a new computer: local models and desktop actions are starting to come together.

## 第三条：Liquid AI 发布端侧决策模型

第三件，Liquid AI 发布了 open d1，一组面向边缘设备的多模态决策模型。
Third, Liquid AI released open d1, a family of multimodal decision models for edge devices.

它的目标不是只生成文字，而是根据画面和输入，直接判断下一步该做什么。
The goal is not just to generate text, but to decide what to do next from visual and other inputs.

官方把模型设计给手机、机器人和其他算力有限的设备。
The models are designed for phones, robots and other compute-limited devices.

文章同时公布了速度和准确率测试，并给出了开源使用方法。
The article also reports speed and accuracy benchmarks and explains how to use the open models.

端侧模型的价值，在于减少网络往返，也让设备在断网时仍能做简单决策。
The value of edge models is less network round trips and simple decisions even when offline.

## 第四条：Claude 接入 Google 文档

第四件，Claude 现在可以直接和 Google Docs、Sheets、Slides 一起工作。
Fourth, Claude can now work directly with Google Docs, Sheets and Slides.

Anthropic 发布了新的连接器和插件，Workspace 团队可以把文件交给 Claude 处理。
Anthropic released new connectors and an add-on so Workspace teams can work on files with Claude.

当前功能还是 Beta，适合先做摘要、整理和内容修改。
The feature is still in beta and is suited to summarizing, organizing and editing content.

它的变化是，Claude 不再只在聊天框里回答，而是能进入用户每天用的文件。
The change is that Claude no longer answers only in chat; it can work inside everyday files.

## 第五条：Anthropic 扩大网络安全验证

第五件，Anthropic 扩大了 Cyber Verification Program，给合格的安全人员更强的网络能力。
Fifth, Anthropic expanded its Cyber Verification Program with stronger cyber capabilities for qualifying security professionals.

新计划分成三个层级：防守、红队和特殊访问。
The new program has three tiers: Defense, Red Team and Specialized access.

防守档用于应急响应和恶意软件分析，个人研究者与开源维护者也能申请。
The Defense tier is for incident response and malware analysis, and individuals and open-source maintainers can apply.

红队档包含授权渗透测试，只面向机构；特殊访问则用于关键系统测试。
The Red Team tier includes authorized penetration testing for organizations, while Specialized access covers critical-system testing.

计划覆盖 Claude Opus 5.5、Sonnet 5.5 和 Mythos 5.1。
The program covers Claude Opus 5.5, Sonnet 5.5 and Mythos 5.1.

## 第六条：Claude 合规接口更新

第六件，Claude 平台更新了 Compliance API 的聊天接口。
Sixth, Claude Platform updated the chat endpoints in its Compliance API.

企业组织现在可以在 Beta 功能里，获取统一 Claude 体验产生的聊天记录。
In beta, enterprise organizations can retrieve chats from the unified Claude experience.

这个功能继续使用现有的 Compliance Access Key，不需要换一套密钥。
The feature continues to use the existing Compliance Access Key, so no new key is required.

它解决的是企业审计和留存问题，普通用户暂时用不到。
It addresses enterprise auditing and retention, and is not aimed at ordinary users for now.
