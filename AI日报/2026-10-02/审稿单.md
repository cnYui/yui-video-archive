## 1. 谷歌发布 Gemini 4 Argon
- 来源：Google 博客 · The Decoder　日期：9月30日
- 要点：1. 先给网络安全伙伴；2. 输出上限一百万；3. 限时价 2 美元起；4. 独立测试和 Astra 持平
  1. 第一件，9 月 30 日，谷歌发布了新一代旗舰模型 Gemini 4 Argon。　〔✓〕
  2. 不过现在还用不上。它先开放给一小批做网络安全防御的合作伙伴，走谷歌的 Fairwind 计划。　〔✓〕
  3. 谷歌说会尽快开放，先给付费 API 用户和 AI Ultra 订阅用户，没给具体日期。　〔✓〕

  5. 价格方面，上线初期每百万 token 输入 2 美元、输出 10 美元；之后恢复到 4 美元和 20 美元。　〔✓〕
  6. 成绩是官方称的：DeepSWE 编程测试 77.9%。　〔✓〕
  7. 第三方 Artificial Analysis 的测试里，它的智能指数 53 分，和 GPT-6 Astra 持平。　〔✓〕
  8. 但它每个任务平均要输出 6.2 万个 token，GPT-6 Astra 只要 2.7 万，跑起来更费 token。　〔✓〕
  9. 另一项测试看胡编的比例：Argon 是 15%，GPT-6 Astra 是 51%，这一项它明显更好。　〔✓〕

## 2. Claude Code 支持 Mods
- 来源：Claude 博客 · 更新日志　日期：10月1日
- 要点：1. TypeScript 小函数；2. 能拦截、改写工具调用；3. 打包成插件分享；4. 团队版先加载安全默认
  1. 第二件，10 月 1 日，Claude Code 更新到 2.1.287，加了一个新功能，叫 Mods。　〔✓〕
  2. Mods 就是用 TypeScript 写的小函数，用来改 Claude Code 自己的行为。　〔✓〕
  3. 比如在提示词发给模型之前改写它，拦下、改写或者重试工具调用，替你批准或拒绝权限请求。　〔—〕
  4. 还能把工具输出里的密钥打码，或者在界面上加按钮和输入框。　〔—〕
  5. Mods 装在插件里，用 /plugin 命令就能装，分享方式和普通插件一样。不会写的话，可以让 Claude Code 帮你写。　〔✓〕
  6. 团队版、企业版会先加载一个内置的 sec-default，限制有风险的写法，比如推翻已经拒绝的权限。　〔—〕
  7. Mods 在 Claude Code 的命令行版和桌面版里都能用。　〔✓〕
  8. 这次还自带一个 Mod，叫 You should know：旁边有个子代理帮你盯着，提醒你和 Claude 可能漏掉的地方。　〔✓〕
  - Claude 博客：https://claude.com/blog/claude-code-mods
  - Claude Code 更新日志（GitHub）：https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md

- 来源：Cohere · MarkTechPost　日期：9月30日
- 要点：1. Pro 和 Fast 两档；2. 上下文 128K；3. 每百万 token 0.12 美元；4. 两档共用向量空间
  1. 第五件，9 月 30 日，Cohere 发布了新一代向量模型 Embed 5，主要用在企业搜索和 RAG 检索。　〔✓〕
  2. 它分 Pro 和 Fast 两档，都支持 100 多种语言。　〔✓〕
  3. 两档的上下文都是 128K token，向量维度可以在 256 到 2048 之间选。　〔✓〕
  4. 价格是每百万 token，Pro 0.12 美元，Fast 0.08 美元；图片两档都是 0.40 美元。　〔✓〕
  5. 官方称，在 ViDoRe V3 测试里，Pro 拿到 85.8 分，高于 Voyage 4 Large 的 83.7 分。　〔✓〕
  6. 在金融文档测试 FinanceBench 上，Pro 拿到 80.1 分，排第一。　〔✓〕
  7. 还有个实用的设计：两档共用一个向量空间，用一档建索引，用另一档查询，不用重建索引。　〔—〕
  8. 现在可以通过 Cohere API、微软 Foundry 和 Amazon SageMaker 使用。　〔✓〕

- 来源：Strands 博客 · TechCrunch　日期：10月1日
- 要点：1. 只做选择，不写文字；2. 基于 Qwen3.5-2B；3. 电脑上一百多毫秒；4. 权重放在 Hugging Face
  1. 最后一件，10 月 1 日，亚马逊云科技的实验项目 Strands Labs，开源了一个小模型，叫 Strands Decider 2B。　〔✓〕
  2. 它是一个决策模型：不生成文字，只在给定的几个选项里挑一个，并且给出打分。　〔—〕
  3. 做法是拿阿里的 Qwen3.5-2B，去掉输出文字的部分，换成一个给选项打分的输出头。　〔✓〕
  4. 官方数据是，小任务在 RTX 3090 显卡上中位延迟大约 115 毫秒，在 M3 MacBook 上大约 153 毫秒。　〔✓〕
  5. 官方说，在 JevBench 排行里，它在 2B 这一档的 33 个模型里排第三。　〔✓〕
  6. 适合做模型路由、挑工具、做护栏判断这类智能体里的小决定。　〔—〕
  7. 权重已经放在 Hugging Face，代码在 GitHub，本地电脑就能跑。　〔✓〕
