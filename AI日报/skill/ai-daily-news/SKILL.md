- 每条结构：发生了什么（谁、什么、哪天）→ 2–3 个关键信息（型号、价格、开放范围；跑分写“官方称”）→ 对国内用户的影响（能不能用、有没有 API、多少钱）。每条约 230–300 字。
- 句子里的数字和英文名要能在原文里找到（第 7 步会逐个核对）：换算过的数字写成原文里有的形式。
- `text` 是字幕原文；`tts` 只在读法要改时写（数字写成汉字，英文缩写拆开：`T P U`、`C E O`、`百分之五十七`）。
- `expr` 只有 开心 / 吃惊 / 认真。`point` = 这一句出现第几个要点（从 0 开始）。
- **`en` = 这句的英文字幕**（每句都要有，2026-10-02 起）。中文先定稿再写英文；台本改了中文，回头把英文也改了。翻译规则（项目统一标准）：
  - 口语、简洁，按意思翻，不逐字直译；只用英文和半角标点（`make_episode.py --check` 见到汉字、全角标点会报错）。
  - 专有名词保留原名：中文句子里出现的英文名（型号、产品、公司、`/plugin` 这类命令）必须在 `en` 里原样出现（检查会报错）。中文名用通行英文名：鲸鱼娘 → Whale Girl，豆包 → Doubao，千问 / 通义千问 → Qwen，元宝 → Yuanbao，文心 → ERNIE，智谱 → Zhipu，月之暗面 → Moonshot AI，阿里 → Alibaba，字节 → ByteDance，腾讯 → Tencent，百度 → Baidu，华为 → Huawei，昇腾 → Ascend，谷歌 → Google，英伟达 → NVIDIA，微软 → Microsoft，亚马逊 → Amazon，亚马逊云科技 → AWS，国庆 → National Day holiday，悠一 → Yui。没有通行英文名的写拼音（航班管家 → Hangban Guanjia）。
  - 日期写 October 2 / September 30；钱写 $2、$0.12；“6.2 万”写 62,000，“116 亿”写 11.6 billion；百分比照抄。数字在英文里找不到时 `--check` 会提示，确认意思一致。
  - 一句太长时 `bilingual_subs.py` 会把中英文一起拆成几条。**写完跑 `python ...\scripts\bilingual_subs.py <期目录> --check`，把每条的中文和英文并排读一遍**：说的必须是同一件事，没有断在词组中间（2026-10-02 测试时 52 句里 7 句自动拆得不对，比如中文断在“中位 | 延迟”、英文多带了下一条的词）。拆得不对的句子写 `cuts`：`[["中文锚点", "英文锚点"], …]`，每对 = 中文在这段文字之后断、英文在这段文字之后断，按出现先后找；英文语序和中文差太多时，把英文改成和中文同样的顺序再切。`--check` 报“一行放不下”就多加一个断点或把句子写短。
- `cover`：`item` = 封面大字讲第几条（1 起，挑最能让人想点进来的那条，不一定是第 1 条）；`line1` 灰色铺垫（≤10 字宽，谁 + 什么）、`line2` 蓝色钩子（≤8 字宽，最好是问句或反差，如「也要收钱了？」「为啥停训了？」）；`mood` = 吃惊 / 开心 / 疑问 / 认真（决定鲸鱼娘的姿势）。不写日期；数字、公司名要和那条新闻原文一致，不夸大。其余新闻标题由封面脚本自动列成小字。
- **竖屏版的可选字段**（2026-10-05 起；缺了会自动退回，`make_episode.py --check` 只给提示，不挡）：
  - `news[i].vhook`：竖屏标题第二行（橙色钩子，≤ 15 字宽；**具体、带数字或动作**，如“10 月 9 日起只剩 Flash-Lite”“78B 参数，每词只动 3.46B”；不和 `headline` 重复，不夸大）。缺了用 `points[0]`。
  - `news[i].vbigs`：数字卡，每条 0–2 个：`{"line": 第几句（0 起）, "n": "3.46B", "small": "活跃参数", "d": "总参数 78B · 每个词只动这么多"}`；挑那句里最抓人的**硬数字**（原文里有），`n` ≤ 8 字宽、`d` ≤ 20 字宽；念到那一句时数字卡替换要点卡。
  - `titles`：`{"bilibili": "≤80", "douyin": "≤30", "xiaohongshu": "≤20"}`——三个平台各一个标题，事实陈述角度（主体 + 动作 + 数字，和封面大字不是同一句）。例：`10月5日AI圈8件事：Gemini免费版只剩Flash-Lite，DeepSeek Harness试着兼容Claude Code插件` / `Gemini免费版降级，DeepSeek试接Claude插件` / `Gemini免费版降级！AI圈8件事` / `AI圈8件事：Gemini降级`；中文和英文之间不留空格；数字和“首次”要在原文里；不用夸张词。缺了或超限，`daily.py` 用自动生成的（第 1、2 条的 rundown_key 拼起来）。
  - `vertical.cuts`：竖屏字幕的断点：`{"合并后的整条中文": [["中文锚点", "英文锚点"], …]}`（锚点 = 在这段文字之后断）。竖屏一行最多约 18 个汉字 / 60 个英文字符，日报字幕大多要再切一刀，自动切常常中英错条（2026-10-06 那期 AI 复核连挂 3 次几乎都是这个）。**渲染前 `make_vertical.py all` 会跑字幕对齐检查（`lint`，见第 6 步），有错就停**：按它打印的整条中文写 `vertical.cuts`，或把那句 `en` 改成和中文同样的语序（`en` 不进配音，改了不用重配）。写法要点：
    - 中文这段出现的数字、英文名、专名（欧盟 / 视频 / 英伟达 / 水印……），英文要在同一段；英文语序和中文差太多就先改英文语序再切（“it will, over the coming weeks, watermark EU text” 对不上“未来几周会给欧盟的”，改成 “over the coming weeks, in the EU, | it will watermark text output …”）。
    - 不要断在词中间（“英 | 伟达”“研究 | 人员”“开源模 | 型”“维基 | 媒体基金会”）。
    - 一段至少停 1 秒左右；“强化学习”这种 4 个字单独一段，0.7 秒读不完英文。
    - 键必须是**合并后**的那条中文（`bilingual_subs.py` 拆出来的一条；“官方称，”“第三件，”这种 < 6 字的会并进下一条），lint 输出里 `‖` 连起来的就是它。台本句子或 `cuts` 改了，键也跟着变，重跑 lint 看有没有对上。

### 5. 配音（Fish Audio 网页版，用户 2026-09-29 定）
整期一次生成；台本改过就整期重新生成（`D webvoice` 会把文字对不上的旧版本挪进 `配音\raw\_旧稿_*`）。整条流程 2026-09-29 实测过（`SERIES\_旧稿\_测试_网页配音_20260929\`）。
1. Chrome 插件新开标签页打开 https://fish.audio/app/text-to-speech/?modelId=e7219cb8cfab46bebba2ee570932b0a6 （苏晓晓）。核对：右上是用户的账号（「My Team · Plus」），语音「苏晓晓」，模型下拉是 **Fish Audio S1**（不是 S2.1 Pro），音频控制保持默认（音量 0、速度 1x、温度 0.9、Top P 0.9、文本归一化 关）。
2. 把 `配音\chunks.json` 里 C01 的 `text`（整期约 2300 字 / 5700 字节；页面计数按字节算，上限 15000）贴进编辑框。编辑框是 Tiptap（`.tiptap.ProseMirror`），用 `javascript_tool`：focus → 选中全部 → `document.execCommand('insertText', false, 全文)`，返回 `ed.innerText.replace(/\n/g,'') === 全文`（布尔）核对。不要逐字 `type`。
3. `read_network_requests`（`urlPattern: api.fish.audio/task`，`clear: true`）先清空，再让编辑框获得焦点按 **Ctrl+Enter** 生成（出现播放器后「生成语音」按钮会移位，别按坐标点）。
4. 页面一次出**两个完整版本**（两个播放器；旁边「第 1 条更好 / 第 2 条更好」不用点）。等 1–2 分钟，`read_network_requests`（过滤 `api.fish.audio/task/`）拿两个 32 位任务编号（同一个编号会反复出现，去重后是两个）。在页面里 `fetch` 任务接口会被跨域拦，不用试。
5. `D webvoice --task <编号1> --task <编号2>`：自己找音频地址（`platform.r2.fish.audio/tasks/<日期>/<编号>.mp3`，日期前后一天都试）、下载成 `配音\raw\C01_vN.mp3`（短于 60 秒会报错：还没生成完，等一会儿再跑）、把文字记进 `api_takes.json`、在 `web_usage.txt` 记一行。不点浏览器的下载按钮（Chrome 会拦连续下载）。
6. 关掉 Fish Audio 标签页。
- 插件连不上、没登录 / 登录失效、页面弹付费 / 额度不足 / 人机验证 → 停下推送；不点升级、充值、购买，不改账号设置，不换别的 TTS 或模型，也不改用 API。

然后 `D voice`（select_takes 在当前文字的版本里按语音识别打分挑最好的 → segment_audio 按句切开、对齐字幕）。看输出的 `total voice`：**低于 285 秒**，总长就到不了 5 分钟（加不了分段章节）——每条补一句原文里有的细节，重新 build → 网页版配音 → webvoice → voice。分数 < 0.75：网页上同样的文本再按一次 Ctrl+Enter（又出两个版本），`D webvoice` 下载（文字相同的旧版本会留着一起比），重跑 `D voice` 挑分高的，最多 2 次。分数低多半是英文名（Anthropic、Akamai 等），可以在 `tts` 里写中文近音。

### 6. 出片（竖屏，用户 2026-10-05：“之后日报的 routine 都是竖屏，并且都要发四个平台”；2026-10-06 起视频号不发）
`D render` → build_timeline → mix_audio（口型、`voice_main.wav`）→ bilingual_subs（中英字幕拆条，写进 `timeline.json` 的 `segments[].subs`）→ 封面（`make_cover_white.py --from-script`：台本 `cover` 块 → 白底两行大字 + 右下鲸鱼娘 + 左边其余新闻小字，鲸鱼娘蓝；**封面不动**）→ **`make_vertical.py all --upload`**：
