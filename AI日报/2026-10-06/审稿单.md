## 2. ChatGPT 欧盟文本加水印
- 来源：OpenAI · The Decoder　日期：10月5日
- 要点：1. 欧盟文本加隐形水印；2. API 全球可选开启；3. 心理学文本约 95%；4. 改写 25% 剩 17%
  1. 第二件，在欧盟用 ChatGPT 写出来的字，以后会带一个看不见的水印。　〔✓〕
  2. OpenAI 10 月 5 日说，为了符合欧盟 AI 法案，未来几周会给欧盟的 ChatGPT 和 Codex 文本输出加水印。　〔✓〕
  3. 怎么做到的？这个技术叫 textGrain，在模型挑词的时候藏进一个统计信号。　〔✓〕
  4. API 客户全球都能选择开启，默认是关的。　〔—〕
  5. 官方测试，心理学类文本、误报率压到 1% 时，400 个 token 的段落大约 95% 能测出来。　〔✓〕
  6. 但改写会削弱它：替换 25% 的词，检测率就掉到 17%。　〔✓〕
  7. 数学类的文本更难测，400 个 token 只有约 60%。　〔✓〕
  8. 检测工具一开始只给通过审批的研究人员和专业机构。　〔—〕
  9. The Decoder 对比说，Anthropic 给 Claude 加的水印是全球强制的，OpenAI 的 API 可以不开。　〔✓〕
  10. 水印防得住复制粘贴，防不住动手改。　〔—〕
