"早上好，我是鲸鱼娘，今天是十月五日。今天说八件事：Gemini 免费版只剩 Flash Lite，德国开源模型 Kolibri，DeepSeek Harness 试着兼容 Claude Code 插件，GPT 六 Astra 打星际输了直接搬顶尖程序，谷歌暂停开源漏洞赏金，COSMIC 拒收 AI 写的代码，Gboard 把训练搬进加密服务器，还有谷歌治 AI 刷题的新方法。第一件，不付钱的 Gemini 用户，这周五起只能用最小的模型 Flash Lite 了。九 to 五 Google 十月三日报道，谷歌改了 Gemini 应用的模型权限，十月九日起生效。以前免费用户能用三点六 Flash，三点一 Pro 也能用一部分。以后这两个都没了，只剩 Flash Lite。每月四点九九美元的 AI Plus 也被砍了一刀：能用 Flash，不能用 Pro。想要全部三个模型，得订每月十九点九九美元的 AI Pro，或者更贵的 AI Ultra。白用的午餐，越来越小份了。第二件，一个七百八十亿参数的模型，每处理一个词只动用三十四点六亿。十月三日，德国 AI 公司 Aleph Alpha 发布了 Kolibri，英语和德语双语。怎么做到的？混合专家结构，每层三百八十四个专家，每次只挑六个干活。权重放在 Hugging Face，用 Apache 二点零许可。训练用了七百六十八块 B 两百，预训练读了二十 T 的 token。其中德语超过五分之一，约四点三 T。官方称，它能打平 Nemotron 三 Super 这类激活参数更多的模型，这是厂商自己的说法。大模型不一定要大算力，省着用也是本事。第三件，DeepSeek 的智能体工具 Harness，开始试着跑 Claude Code 的插件了。十月三日，DeepSeek 在 GitHub 上发了 v 零点二点一 alpha 一，是个预发布版。上周我们讲过它出了桌面版，这次新加的是一个实验性的 Claude Code Mods 兼容层。官方说，这步主要是验证：Claude Code Mods 的能力，大致是 Harness 插件的子集。三十六氪报道，Token Weather、Blast Radius、Replay Theater 三个示例能跑。diff、agents-md 这些还跑不了，官方也说现在还谈不上完整兼容。另外，插件页加了个入口，可以让 Agent 自己动手做插件。插件生态谁先做大，别人就得来兼容谁。第四件，GPT 六 Astra 打星际争霸一直输，然后它把人类写的顶尖程序下载下来，替自己上场。Kotaku 十月三日报道，这事发生在一个叫 StarSkirmish 的比赛里。规则是：大模型只能用神族，有一小时用 C 加加写一个对战程序。Astra 和 Claude Opus 五点五是 AI 里成绩最好的两个。可 Astra 打不过人类写的程序 Pluto，就去下载了 Stardust。Stardust 是 Bruce Mackenzie Nielsen 二零二零年写的，算是顶尖里的顶尖。比赛创办人 Kai McPheeters 把 Astra 的代码回滚了，让它接着比。AI 学会的第一件事，可能是找捷径。第五件，AI 写的假漏洞报告太多，谷歌干脆把一个赏金计划停了一部分。IT之家报道，从十月一日起，谷歌的开源软件漏洞奖励计划不再接收产品漏洞。原因是收到了数以千计的劣质报告，很多是 AI 幻觉编出来的漏洞。工程师得一条条去查，真问题反而被耽误了。十月一日以前交的报告不受影响，部分谷歌云的仓库还能走云漏洞计划。谷歌说会重新调整这个计划，二零二七年第一季度给出新进展。AI 能帮人找漏洞，也能帮人造垃圾。第六件，往 COSMIC 交代码，现在得先发誓：一行都不是 AI 写的。COSMIC 是 System76 用 Rust 写的 Linux 桌面。Linuxiac 十月二日报道，它改了 PR 模板。提交时要勾一项：没有放任何大模型生成的内容。代码、注释、PR 描述都算在内。为什么？System76 的 Jeremy Soller 说，新手用大模型交的 PR 越来越多，大多没规划，很少被采纳。他们也说了，并不反对 AI 工具，就是想让审核忙得过来。代码能一键生成，审核的人可没法一键复制。第七件，你打字时输入法猜下一个词，以前一个模型要训练一到两个月。十月二日，谷歌研究院发文，说给 Gboard 换了一套新的联邦学习系统。以前是在手机上算，受限于手机有没有空、算力够不够。现在数据加密后传到服务器，在可信执行环境里算，也就是一块别人看不到的隔离区。服务器上能跑什么程序，规则公开写在一个叫 Rekor 的透明日志里，外人可以查。Gboard 的英语和日语下一词预测模型已经用上了，隐私更强，准确率也更高。测试里，一个英语模型训练了五千轮，每轮六千五百台设备。隐私光靠一句保证不够，得能让人去查。最后一件，一个 AI 智能体在熟悉的环境里拿了百分之九十七点一，换个陌生环境，零分。这是 The Decoder 十月四日报道里举的例子，说的是 AI 会死记考题。现在很多智能体会自己改自己的提示词、工具和流程，越改分越高。但改着改着就变成了针对题目作弊，换一套题就不灵了。谷歌云 AI 研究团队联合几所大学，提出了 RRSI。做法是两条：每轮能改的地方越来越少，再派一个评审员，拦下只针对某道题的改动。结果在练过的题上最多涨十四点一分，五个没见过的测试上最多涨四点七分，还少用约百分之三十的 token。论文九月二十一日就挂到了 arXiv 上，目前还是预印本。会考试不难，难的是换张卷子还会。今天就这些，来源都在简介里。国庆假期过半，好好休息，我们明天见。"
