# 制作流程细节（参考实现：第 02 期）

每期目录 `D:\大疆\Way to AGI\NN_<标题>\`：

```
素材\            演示素材（录屏、作品视频、截图；用户发来的从“下载”复制，原文件不动）
制作\02_出镜\     剪口播：ingest / asr / make_cues / build_edit / qa_asr / where / show_asr
制作\03_成片\     画面和合成：build_timeline / prep_media / index.html / mix_audio / render_all / export_srt
制作\04_封面\     cutout / cover.html / render_covers
```

## 1. 录像入库（02_出镜）

- `ingest.py`：`SRC`（SD 卡目录）、`IDS`（DJI 文件名末尾 4 位编号）每期改。`audio` → `audio\<编号>.wav`（48 kHz 立体声，混音用）+ `audio16\<编号>.wav`（16 kHz 单声道，识别用）；`proxy <编号…>` → `proxy\<编号>.mp4`（1280×720、30 fps，出镜画面用）。只转本期要用的编号，别把上一期的也转了。
- 原片是 HLG 10-bit（BT.2020）。直接按 SDR 转 8-bit 的肤色最自然；zscale 线性 + hable 偏暗，直接转 BT.709 过曝（02 期试过），所以代理和出镜帧都不做色彩转换。封面取帧时饱和度 +12%、对比度 +4%。
- `asr.py`：faster-whisper large-v3-turbo，CPU int8，beam 5，逐词时间，`condition_on_previous_text=False`。提示词里放本期专有名词，**故意带“嗯、那个、就是说”**，口癖才会被写出来。大约 1 分钟音频 1 分钟跑完，放后台跑。

## 2. 字幕条（make_cues.py）

- 每条：段号 pid（N01…，一段 = 一个画面的大致范围）、录像编号、原录像起止秒、中文、英文、`skip`（条内剪掉）、`cut`、`hold`。
- 一条字幕 1–2 句，中文不超过约 28 字（52 px 一行放得下），英文不超过约 90 个字符；**括号注释算在内**。
- 说错重来：保留最后一遍完整的；数字说错、说法不准确的整句删掉，告诉用户删了什么。
- 听不准的词（专有名词、ASR 写成别的字）标出来问用户，字幕先按上下文最合理的写并标出来；数字、人名、引用归属这类会改变含义的不猜，直接问。
- 去口癖、术语表、括号注释、中英翻译、终检：见 `references/subtitles.md`。全角括号里的字是没说出口的注释，`cueT` / `tm.at()` / `mix_audio.py` 对齐说话时间时会跳过它。

## 3. 剪口播（build_edit.py）

- 每块前后多留 0.06 / 0.10 s；同一段录像里前后两条间隔 < 0.35 s 就连着不切；不连着的中间插停顿（同一段 0.12 s，换段 0.30 s）；块里超过 0.45 s 的静音（比这段录像说话电平低 30 dB）缩成 0.22 s。
- `hold`：作品展示这类地方，念完后留 1.5–2 s 不出人声，出镜用同一条录像里没说话的镜头（先用能量找静音段、抽帧看表情是否自然）。结尾“拜拜”后多留约 0.5 s 挥手。
- 输出 `edit\narration.wav`、`edit\facecam.mp4`、`edit\edit.json`（每条字幕在成片里的起止、每小块的源时间、holds）。
- **拼接出镜视频要按帧重编时间戳**（`setpts=N/30/TB`），抽帧加 `-fps_mode passthrough`。直接 `-c copy` 拼接会有时间戳空档，按时间抽帧多出几十帧，口型越往后越慢（02 期多出 74 帧 = 2.5 s）。
- `qa_asr.py`：剪好的口播再识别一遍，对照查：漏剪的“就是/那个”、切进下一句的半个字、重复的词。`where.py <秒>` 把成片里的秒换算回原录像的编号和秒，方便改边界。

## 4. 画面（03_成片）

- `build_timeline.py`：`SCENES = (画面类型, 版式, 章节, 目录第几项, 第一句字幕序号)`。每个画面从第一句话前 0.35 s 开始；每句字幕带“字 → 秒”对照表（来自 qa_asr 的逐词时间），页面里 `tm.at("某个词")` 就是这个词说出来的时刻。
- 版式（2340×1080，30 fps，白底）：
  - A：出镜大框 (120,150) 1156×666 在左，右边写要点（x 1400 起，宽 880）。开场、提问、结尾用。
  - B：出镜缩到左上角 (48,48) 696×402，左下目录卡 (48,492) 696×408，演示区 x 790–2292、y 40–900。版式切换时出镜框移动 0.7 s。
  - C：作品展示（左下作品说明 + 提示词，右边大画框放片段），口播说到第几个就换哪个。
  - 字幕带在 y 922 以下：中文 52 px 墨黑白边，英文 30 px 灰，按整个画面居中；每句从开始前 0.1 s 显示到结束后 0.45 s（不和下一句重叠）。
- 出镜画框：大框放大 1.06、小框放大 1.3，对着脸（`transform-origin 55.5% 38%`，按本期机位调）。开场左下角“悠一 Yui”名字条 0.4–5.6 s。
- 目录：四个左右的章节，每章 5–6 项，当前项橙色竖条。
- 画面跟着口播走：说到哪个词就出哪个卡片 / 高亮 / 切片段。片段类素材（录屏、作品）按口播的节奏变速或跳切（例如说到“客厅”“书房”时切到对应房间）。
- 我们自己排的中文文字层（标题卡、章节名、要点、标签）配英文小字，同一处、同一风格；录屏和截图里本来的文字不用。发 YouTube 的期数必做（见 `subtitles.md`）。
- `prep_media.py cam` 抽出镜帧（1280×720 JPEG），其他素材按本期写（02 期的 gpt6 / show 是例子）。
- 自查：`render_all.py --stills 秒 秒 …` 或 `--stills-auto`（每个画面 3 张）出联系表，逐张看：字压没压到出镜框和目录、有没有进字幕带、标签有没有压到画框标题、说到的东西有没有出来。

## 5. 混音（mix_audio.py）

- 口播：高通 70 Hz，两遍法 loudnorm 到 −16 LUFS（线性增益，不改动态）。录音底噪约 −64 dBFS、动态 4 LU，不降噪不压缩。
- 作品片段原声：各自先统一到 −18 LUFS；有人声时压 13 dB（片段里本身有人声的压 17 dB），hold 停顿时抬回来，0.25 s 过渡。
- 系列 BGM（母带 −20 LUFS）全程 −15 dB 垫在下面，作品展示时让开；开头 1 s 淡入、结尾 1.2 s 淡出。
- 限幅 −1 dBTP。成片 −16 LUFS 左右。

## 6. 正片、片头片尾

- `render_all.py`：4 路并行，每路一段帧，Playwright 截图（JPEG q95）交给 ffmpeg（x264 CRF 16，`-filter_threads 1`：ffmpeg 8.0 在 2340 宽时多线程会在左边缘出黑点），拼接后混入 `audio\mix.wav` → `<NN_标题>_正片.mp4`。02 期 6:23 渲了约 5 分钟。
- 片头片尾：`add_to_video.py <正片> --outro-data outro.json -o <成片>`。三个合集共用 `AI科普\片头片尾`：片头 3.8 s（打出“悠一”），片尾 4.8 s（清单 + “悠一”印章）。清单每期问用户。
- `export_srt.py`：双语 / 中文 / 英文 SRT，时间已经加上片头的 3.8 s；B 站简介里的章节时间也要加 3.8 s。
- 手机预览：`ffmpeg -i 成片 -vf scale=1170:540 -crf 23 …`。
- 检查：帧数和时长（ffprobe）、响度（ebur128）、抽几帧看片头、正片开头、片尾。
