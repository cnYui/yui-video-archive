# 踩过的坑（第 02 期，2026-09-28 / 29）

| 现象 | 原因 / 做法 |
|---|---|
| 出镜口型越往后越慢，按时间抽帧多出 74 帧 | 出镜片段 `-c copy` 拼接，时间戳有空档。拼接时 `setpts=N/30/TB` 重编，抽帧加 `-fps_mode passthrough`，核对帧数 = 口播秒数 × 30 |
| 原片颜色不对劲 / 取出来的 PNG 是黑的 | 原片是 HLG 10-bit：PIL 读不了 16 位 PNG（用 Windows 路径读，别用 `/d/...`）；颜色直接按 SDR 转最自然，zscale 的转换偏暗或过曝 |
| 剪好的口播里还有“就后来”“看作”这种半截字 | 前后留白把相邻的字带进来了：用 qa_asr 找出来，按逐词时间和能量把 s / e 挪到字缝里，必要时 `cut=True` |
| 作品展示每个例子只露两秒 | 口播一口气说完了：念完加 `hold` 停顿（用这条录像里没说话的镜头），片段原声在停顿时抬起来 |
| 抠像多出一块背景（晾衣架带子） | birefnet 会把小块背景当前景：只留最大连通块 |
| 挥手那张指尖被切掉 | 抠像前的裁切框太窄，挥手的帧放宽到整幅 |
| 封面 4:3 取 16:9 正中间，标题左边被切 | B 站封面编辑器关掉「双比例同步改动」，4:3 单独传一张单独排版的 |
| 用户说“字再大一点，人再小一点” | 4:3 首页推荐位很小：标题横跨上半部分（≈216 px），人缩到右下角（高 ≈540） |
| B 站标签回车后消失 | 换词，最后 JS 读标签数量核对 |
| YouTube 自定义缩略图传不上 | 插件 file_upload 不触发 YouTube 的上传，请用户手动传 |
| 挪项目目录时报“文件被占用” | 之前的终端当前目录还停在项目里：先把工作目录切到上一级再挪；挪之前把脚本里的相对路径（`../../../AI科普`）改成绝对路径 |
| 内联 python（heredoc）里的 `\\U`、`\\n` 被改坏 | 带反斜杠的路径和字符串，先写成 .py 文件再运行 |
