## 做法（用户 2026-09-28 定）

1. Claude 先按稿子和用户给的编排做出整条视频，出镜的位置先空着（占位）。
2. 用户看着做好的视频，按稿子录自拍（控制语速，不用边演示边解说）。
3. Claude 把自拍合成进去。

画面：白色背景；出镜画面不全屏，像画框一样框在画面里；讲到演示时出镜缩到左上角，画面主体放演示内容。
