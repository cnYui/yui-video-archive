## 怎么切的（`build_clips.py`，改常量重跑）

1. 切点：整条口播里所有**自然停顿**——安静段不短于 0.15 s（能量 < −46 dBFS，说话电平约 −14.5、底噪约 −66），停顿前话音自然收尾、停顿后不是硬切起音。
   - 剪辑时逐句拼接的接缝有一部分话音没落完（收尾处 −17～−25 dB），这些不当切点。第一版按字幕条边界切，`ep1_03` 的结尾切在了话音还没落完的地方，已作废，挪进 `_旧稿\`。
2. 分组：动态规划，每段 ≤ 58 s（官方“1 分钟以内”留 2 s 余量）、尽量 ≥ 48 s；优先在长停顿处断开；段中间不留 ≥ 1 s 的长停顿。
3. 段首留 0.20 s 静音，段尾留 ≤ 0.30 s；切点两端 10 ms 淡入淡出（`ep1` 最后一段结尾原片就在说话，淡出 50 ms）。
4. 只做了：截取、左右声道平均成单声道、两端淡入淡出。**没有**降噪、压缩、变速、改响度。
5. 两处 > 1.2 s 的停顿（`wta02_02`、`wta02_03` 各一处，是剪辑时插入的“不说话镜头”的空档）在静音里压到 0.6 s。

## 体检（对输出文件本身量的）

- 格式：21 个文件全是 PCM 16-bit / 48 kHz / 单声道；最长 57.8 s；总长 1072 s。
- 电平：说话电平（p95 帧 RMS）−15.8～−13.4 dBFS，峰值 −0.8～−4.3 dBFS，无削波；底噪 −63～−70 dBFS（信噪比约 47–56 dB）。
- 首尾：所有段首尾 20 ms 能量都在 −56 dBFS 以下（整条口播最后一段的结尾除外，−45 dBFS，已淡出）。
- 段中最长停顿 1.15 s。
- 音效 / 杂音：用 ASR 逐词时间对齐，找“没在说话却有能量”的事件，第 1 期 14 个、Way to AGI 02 3 个，抽查了最响的 4 个（第 1 期 3 个、Way to AGI 02 1 个）的频谱，都是带谐波的人声（ASR 漏了时间，或是拖长的语气音），没有拍手、敲击、口水音。开头“合十”那下也没有拍手声。
- 窄带噪声：底噪里没有明显的嗡声或啸叫；Way to AGI 02 说话时 4.1 kHz 有一条比邻近高 7 dB 的窄线，比话音低约 30 dB，听不出来。
- **没有做的**：没跑 Fish 自己的分析器（要登录后才能跑），所以“会不会被拒”还没有实测。

## 上传步骤

1. 用你自己的浏览器（已登录 Fish Audio）打开专业声音克隆的草稿页。
2. 点「上传」，在文件对话框的地址栏粘贴 `D:\大疆\声音克隆素材\上传用`，回车，Ctrl+A 全选 21 个，打开（文件框支持多选）；或者直接把这些 wav 拖进上传区。页面写着：每段少于 1 分钟，总时长 10–180 分钟。
3. 点「开始分析」：每一段会标“通过”或“被拒 + 理由”。
4. 有被拒的，把理由发给我：
   - “背景噪音”：先看是哪一段、哪一秒；再决定要不要轻度降噪（会带来失真，优先换掉那一段）；
   - “音效”：定位到那一秒，切掉；
   - “长段空白”：压短段中停顿。
5. 全部通过后，**你本人**对着话筒现场朗读屏幕上的那段话（声音验证）；通过后开始训练。
