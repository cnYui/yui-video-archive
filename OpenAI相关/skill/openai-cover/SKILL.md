# OpenAI相关 · 封面

用户 2026-10-02 的要求（原话）：“做一个封面，用openai的品牌色”（绿色第一版被否：“就用v1，但是请使用openai的蓝色”）；“封面的文字只保留：…”（V1 / V4 / V5，砍到只剩一句钩子）；第 1 期出三个候选后选了 B，并说“当前封面图设计你也固定下来，用这样的openai的品牌色”。版式和数字的来历、被否掉的做法见 `references/design.md`。

## 硬性要求（`check_cover.py` 查前 4 条）

1. **品牌色**：黑底 `#050505`、第 1 行白字、第 2 行 **OpenAI 蓝 `#0285FF`**、左边 14 px 蓝竖线；不用别的强调色（绿、橙…），不用渐变色块。
2. **不放 OpenAI 标志**（官方规范不允许放在复杂画面上 / 当主品牌 / 暗示合作），只用文字和颜色。
3. **只有两行短钩子**（每行 ≤ 约 7 个字）：不加标签、药丸、副标题，**也不放左下角的来源小字**（2026-10-03 封面协定：小字看不见；主体是第三方作品原帧时，来源写在简介里，`make_cover.py` 不再画 `source`）。
4. **字和主体收在 B 站 16:10 安全区内**：16:9 字框 x 96–1824（主体里的关键内容右端同样 ≤ 1824）；4:3 标题在上、主体在下。
5. **封面字和视频标题不写同一句**：封面短钩子，标题完整一句；开工前先和用户定好各写什么。**封面和标题的协定**（用户 2026-10-03：「封面文字中最下面一行的小字可以删除，因为用户根本看不见……封面中的文字要简略要大，标题则需要详细，这个规则对我目前做的所有的视频skill都要生效」）：封面上只放几个**简短的大字**（关键词 / 钩子），**不放最下面那行小字**（副标题、说明、清单、来源署名之类，缩到信息流里根本看不见）；**标题写详细**，把封面放不下的信息（时间、数量、对象、结论……）写进标题，不和封面是同一句。例：封面「大模型 / 谁夯谁拉？」→ 标题「2026下半年大模型谁夯谁拉？18个模型锐评」。系列名、期号这类合集标识照旧。
6. **主体 = 素材原帧**（裁掉浏览器壳 / 第三方水印），不自己画角色；先出 **3 个候选**（不同主体）让用户选，选定后复制成 `封面_选定_*`。
7. 出图后**一定要打开两张 PNG（和 `_封面预览.png`）看一眼**：字有没有压在主体的大字上、主体有没有被裁、有没有第三方水印、4:3 有没有硬边。

## 用法

```bash
cd "D:\大疆\OpenAI相关\skill\openai-cover\scripts"
# 1) 规格：复制 ../assets/cover.example.json 到 <本期>\制作\04_封面\cover.json（new_episode.py 已经复制好），改 line1 / line2 / source / candidates（src 相对 cover.json 所在目录）
python make_cover.py --spec "<本期>\制作\04_封面\cover.json"            # 出 3 个候选 + .meta.json + _封面预览.png
python make_cover.py --spec … --only B                                  # 只重出 B（调 crop / h16 / cx16 之后）
python check_cover.py "<…>\封面_B_16x9.png" "<…>\封面_B_4x3.png"       # 验收
python make_cover.py --spec … --select B                                # 用户选定后：封面_选定_16x9.png / 封面_选定_4x3.png
```

- 调主体：`crop = [x, y, w, h]` 在原帧里裁（去掉浏览器壳 / 水印），`h16` / `cx16` = 16:9 里主体的显示高度 / 水平中心（高 940–1130、中心 1330–1400 最常用，主体越大越要让左边淡入的部分不碰标题），`h43` = 4:3 里主体显示高度（700–800）。
- 标题字号自动适配：最大 190 px，按“主体淡入完成处 − 60”和 x 1000 两者较小的那个算可用宽度；英文钩子（例 `GPT-6.1 Sol`）会缩到 140 px 上下，4:3 通常能到 190。
- 依赖：Playwright、ffmpeg、Pillow、共用字体 `D:\大疆\AI科普\素材\字体\fonts.css`（Noto Sans SC 900）。
- 公开仓库：第三方作品原帧做的封面不进 git，`.gitignore` 里加 `/OpenAI相关/NN_…/制作/04_封面/*.png`（`new_episode.py` 会打印）。
