# OpenAI相关封面：固定版式的数字和来历

## 来历（用户的原话）

- 2026-10-02 做《OpenAI DevDay 2026 解读》6 条：“做一个封面，用openai的品牌色” → 我出了绿色（#10A37F）第一版，用户：“就用v1，但是请使用openai的蓝色”。
- 之后用户把 V1 / V4 / V5 的封面文字砍到只剩一句钩子（“封面的文字只保留：…”），标题改成完整的一句 → **minimal 版式**：没有顶部标签、没有小标签、没有底部小字，只有两行字（白 + 蓝）和主体。
- 同一天晚上《GPT-6.1 Sol / GPT-6 Astra 模型效果展示》：出了 A 地球 / B Sol 的 3D 游戏 / C 毛绒 dots 三个候选，用户选 B，并说“当前封面图设计你也固定下来，用这样的openai的品牌色” → 这份文档和 `make_cover.py` 就是那个固定下来的设计。

## 色值

| 用途 | 色值 | 说明 |
|---|---|---|
| 底 | `#050505` | 近黑，不用纯黑（压缩后不发死） |
| 第 1 行字 | `#FFFFFF` | 白 |
| 第 2 行字、左竖线 | **OpenAI 蓝 `#0285FF`** | OpenAI 官网样式表里的 ChatGPT 强调蓝；发布会幻灯片上的蓝抽样是 #0684EA / #0078D8 / #0090EA，是它被舞台屏幕和视频压缩压暗后的样子 |
| 小字（来源） | `#9AA0A6` | 灰 |

- **不放 OpenAI 标志**：官方设计规范页（openai.com/brand）只讲标志的用法（Blossom 不能加色、不能放在复杂画面上、不能当主品牌、不能暗示合作），没有给色值；封面只用文字和颜色，来源写“画面：…”或不写。
- 只用这四个颜色和主体图自带的颜色；不要渐变色块、不要别的色相的强调色（绿色第一版被否）。

## 版式数字

16:9（1920×1080）：
- 左边 14 px 蓝竖线（全高）；标题左边距 104；标题垂直居中（字框中心 y ≈ 520）；
- 标题字 Noto Sans SC 900，行高 1.16，最大 190 px，**按可用宽度自动缩小**（可用宽度 = min(主体淡入完成处 − 60, 1000) − 104）；黑色多层阴影让字压在主体上也读得清；
- 主体：高度 h16（940–1130）、水平中心 cx16（1330–1400），左边 330 px 渐变淡入黑底，上下边缘 90 px 淡出（不留方形硬边）；底部再压一层 26% 的黑渐变；
- 小字：不放（2026-10-03 封面协定）。以前左下距底 64 px、30 px 的灰色来源行已去掉，来源写在简介里。

4:3（1440×1080）：标题在上（左边距 84，顶 96，最大 190 px，宽 ≤ 1272），主体在下（高 h43：700–800，水平居中，顶部 230 px 淡入、左右 16% 淡出）；没有小字。

**B 站安全区**：首页推荐卡片会把 16:9 裁成 16:10（左右各切约 96 px）→ 字框 x 在 96–1824；主体里的关键内容右端 ≤ x 1824（主体边缘的背景可以越界）；底部约 12% 留给时长角标。`check_cover.py` 对 x > 1824 一带还有亮内容只**警告**不判失败：第 1 期选定的 B（骑士和机器人在 x 1030–1500、剑尖越过 1824）会触发这条警告，确认被切掉的只是边缘背景就放行；真的把主体切掉了才改。

## 钩子文字规矩

- 两行：第 1 行白、第 2 行蓝；每行 ≤ 约 7 个字（或 ≤ 11 个英文字符宽）；不写 `source`（来源写在简介里）。
- **封面字和 B 站标题不写同一句**：封面短钩子（例：“GPT-6.1 Sol / 网友实测”“合上笔记本 / 任务照样跑”），标题完整的一句。**封面和标题的协定**（用户 2026-10-03：「封面文字中最下面一行的小字可以删除，因为用户根本看不见……封面中的文字要简略要大，标题则需要详细，这个规则对我目前做的所有的视频skill都要生效」）：封面上只放几个**简短的大字**（关键词 / 钩子），**不放最下面那行小字**（副标题、说明、清单、来源署名之类，缩到信息流里根本看不见）；**标题写详细**，把封面放不下的信息（时间、数量、对象、结论……）写进标题，不和封面是同一句。例：封面「大模型 / 谁夯谁拉？」→ 标题「2026下半年大模型谁夯谁拉？18个模型锐评」。系列名、期号这类合集标识照旧。
- 模型名按官方写法（GPT-6.1 Sol，不写 GPT-6.1 Astra 这类官方没有的名字）；不夸大（“网友实测”不写成“官方发布的效果”）。

## 主体怎么选

- 来自视频的整帧：抽出来 → 用 crop 裁掉浏览器壳、第三方水印（Higgsfield 的 HIGGSFIELD / 模型标签这类）、会被 16:10 裁掉的边；
- 一个清晰的主体：黑底友好的（太空地球、夜景、毛绒 dots、游戏场景）最稳；大片白色界面（文档、表格）压暗后发灰，不选；
- 主体自带的大字（发布会幻灯片标题、网页大标题）不能被我们的标题压住：把主体放在右边，必要时 crop 掉；
- 不自己画角色（尤其是 OpenAI 的 dots 等官方形象）：只用素材原帧；
- 第三方作品原帧 → 封面不进公开仓库（`.gitignore` 里加 `制作/04_封面/*.png`）。

## 被否掉 / 踩过的

1. 绿色（#10A37F）第一版：用户要 OpenAI 蓝。
2. 标题压在主体自带的大字上（dots、ChatGPT Space、1.2B）：改成主体在右、从左淡入，标题字号按主体左边缘自动缩。
3. 方形素材的硬边（B 的 4:3 第一版是一个竖条矩形）：两层遮罩（淡入 × 边缘淡出）。
4. 白色界面主体被压暗后发灰（V4）。
5. 候选 A / C 的主体贴着标题字尾：标题字号 150 → 140 / 主体右移。
6. 标签、药丸、底部小字：用户要“只保留一句”，所以默认版式里没有；只有主体是第三方原帧时才留一行来源小字。
