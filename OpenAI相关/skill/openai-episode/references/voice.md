用户 2026-10-02：“你可以新建一个空白的fishapi页面来做tts”（因为 TTS 页的编辑框草稿是服务端存的、所有标签页和会话共享，日报流程、Fable、DevDay 都往里贴稿）。第 1 期实测下来，**故事工作室的空白项目**就是那个“空白页面”：独立、不碰共享草稿。声音「赛马娘（曼波欧耶版）」、模型 **S2 Pro**（这个声线一直用 S2 Pro；日报流程会把共享页面的模型重置成 S1，工作室里不受影响）。记忆 `fish-tts-use-blank-page` 里也有这份做法。

## 步骤（Chrome 插件，账号内网页不用内置浏览器）

1. `https://fish.audio/zh-CN/app/story-studio/` →「新建项目」→「空白项目」（里面有一句示例文字）。
2. **声音**：右侧「声音」卡片上的 ⇄ 图标 = 重新选择语音（点它弹出“选择语音”，“最近使用”里第一个就是赛马娘（曼波欧耶版）；鼠标悬停卡片出现「使用」再点）→ 弹窗问“当前章节还是所有章节”选“所有章节”。
3. **模型**：右侧「模型」下拉（默认 S2.1 Pro 稳定版）→ 选 **S2 Pro（旧版）**。
4. **台词**：点示例文字 → `Ctrl+A` → `computer type` 整篇（一行一句，每个换行 = 一个区块；`say` 列的字）。
   - **只有一个区块时 Ctrl+A 才选得全**。长文档（几十个区块）里 Ctrl+A 只选中渲染出来的那部分，整篇替换会新旧稿混成一团（第 1 期混成 50 块）——要换稿就「章节」按钮 →「新篇章」，在新章节的空白区块里键入；**新章节的声音（默认 Ethan）和模型（默认 S2.1 Pro）是按章节记的，要重选一遍**。
   - **改某一句的文字要用真实键入**（点进那一块、选中、`type`）。用 `execCommand('insertText')` 程序化改，界面上看着改了、刷新又变回旧稿（第 1 期 9 句里只有 2 句保存了，所以第二次导出只有 2 个文件）。改完用 `javascript_tool` 读 `div.content` 的文字核对（`document.querySelectorAll('div.content')`），**重新打开页面再读一遍**确认真的保存了。
5. **生成**：右上黑色「生成」（只生成改过 / 没生成的块，整稿 25 句约十几秒；生成完按钮变“重新生成”，别点它——会整稿重来）。
6. **导出**：「导出项目」→ 面板里「章节」默认只含当前章节 → **「文件结构」选“按段落拆分”**（每次打开面板都回到“单个文件”，要重选；下拉项用 JS 按文字点最稳）→「导出」→ 几秒后 Chrome 下载 `C:\Users\yui\Downloads\segments*.zip`（里面 `segments/<章节>/000000.wav …`，**逐句单声道 44.1 kHz wav**，顺序 = 台词顺序）。面板里的“预计费用”≈ 要生成 / 导出的文本字节数（积分）：整稿 1,100 字节左右 1,000–1,150 积分；只导出改过的块很少。
7. `cp` 到 `<本期>\制作\02_配音\tts\seg_raw\`，解压后把 wav 按顺序放进 `tts\seg_raw\final\000000.wav …`（`build_voice.py` 读这里），**句数必须等于台本的 `lines` 数**。要换其中几句：把新导出的那一句放进 `tts\seg_pick_v3\<句号>.wav`（盖过 final 里同序号的）。
8. `python build_voice.py [--qa]`（在 `制作\02_配音\`）：逐句转 48 kHz 立体声 → 去头尾静音（> −45 dB）→ 前留 0.12 s / 后留 0.25 s → 音量拉到各句中位数（±4 dB，工作室逐块生成音量会有起伏）→ 拼成 `edit/tts_narration.wav` 和 `edit/tts_edit.json`（`build_timeline.py` / `mix_audio.py` 读）；`--qa` 逐句 large-v3-turbo 识别和 `say` 比。
9. 项目会留在用户账号的“故事工作室”里（我建的叫“未命名项目”），做完告诉用户可以删；**项目 ID 属于账号内编号，别写进仓库文件**。

## 写 `say`（念的字）

- 数字写汉字：两美元、十美元、一点五美元、百分之四、两千二百三十四；版本号“六点一”；`3D` → “三 D”；`@` → “艾特”；“一比一”。
- 英文专名原样写：GPT 六点一 Sol、Astra、Ultrafast、Higgsfield、Blender MCP、dots、OpenAI。
- 每句短，**一句一个区块**（区块 = 一句 = 一个 wav）。语速约 6.3–7.6 字/秒（这期整稿 473 字 → 65 s，每句另留 0.4 s 左右）。
- 这个声线的老毛病：英文专名读得偏中文腔（Sol 像“苏 / Soul”、dots 像“道茨”）、sh/x、q/x、ch/q 被 whisper 听错——**机器识别分低不等于读错，也判断不了读对**，要用户耳朵听；用户说哪句不好，只重生成那一句（真实键入改字 → 生成 → 导出 → `seg_pick_v3`）。
- 一次生成不用出两个版本（工作室逐句出一个）；想挑版本就对个别句在工作室里重新生成（区块的“生成历史”里有历次版本）。
