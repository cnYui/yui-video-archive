## 做对的（留着，已经写进技能）

- **下载前解 JWT 核对源站**；**X 嵌入接口**读推文全文、发帖时间、引用关系、t.co 展开（SamGCoder 的帖子带出了演示页和仓库，成了片尾的“你也能玩”）。
- **调研子代理读官方原文**（不信摘要）：查出“GPT-6.1 Astra”不存在、“ultra code mode”不是官方名、Ultrafast 只有 Astra、官方最省钱的是 Luna、人体图谱是转发（原作者 Ashe）、Higgsfield 的“快 4 倍”官方没有数据；台本和画面小字照“能写 / 不能写”改，网友说法全部挂名。
- **增量抽帧**（`_manifest.json`）：改台本 / 改配音后只重抽变了的段；**静帧逐张自查**抓到 3 处版面问题（价格表注释压住 $50.00、竖排标签换行太碎、片尾来源行被裁）。
- **混音按字幕逐句识别**（25 条窗口里都是对应的那句话）+ **成片抽帧复核**；响度从 −18（被峰值限住）改成按 −16 LUFS 拉 + 软限幅（只有 7 s、112 s 两处接近峰值）。
- **封面先出 3 个候选**让用户选；做成参数化脚本 + 验收脚本。
- **全程写记录**（`docs/ai/context/20261002-172700-…`）和 AGENTS.md。

## 字幕：Claude Code相关里是怎么做的（用户让我看的）

- **第 1 期（Claude Code 模组发布）**：Fable 系引擎，**中文一行**（`#subZh`，52 px，y 966），没有英文、没有 SRT——是双语标准定之前做的。我这期照抄的就是这一套，所以缺英文。

- **项目统一标准**（用户 2026-10-02 定）：`Way to AGI/skill/way-to-agi-episode/references/subtitles.md`「中英双语」+ `scripts/bilingual_std.py`；**OpenAI DevDay 解读 6 条**把它做进了自己的引擎（引擎里画字幕、`split_pair_aligned` 拆条、`check_subs.py`、`package.py` 导出 SRT）——这就是 OpenAI相关 合集的做法，本次技能的引擎模板照它整理。
