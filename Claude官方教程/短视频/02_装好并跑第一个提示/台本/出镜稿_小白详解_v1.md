## 0　开场钩子（3 句，56 字，约 10 秒）

1. 装 Claude Code，比你想的简单：就一条命令。
2. 难的是装完以后：第一个提示，该怎么说？
3. 这期从零开始，带你装好，再跑出第一个提示。

> 画面建议：脸出镜。第 1 句出一个终端录屏：粘贴一条命令、回车、滚出 “successfully installed”；第 3 句切到 Claude Code 的欢迎界面。

## 1　开始之前，你要准备什么（9 句，183 字，约 34 秒）

4. 先说准备，三样东西。
5. 一，一台电脑：Mac、Windows、Linux 都行。
6. Mac 要 13 以上，Windows 要 10 的 1809 版以上。
7. 二，能上网：装和用的时候，都要联网。
8. 三，一个账号。
9. Claude 的 Pro、Max、Team 或企业订阅，或者 Console 账号，都行。
10. 免费的 Claude 账号，不含 Claude Code。
11. 另外，要在 Anthropic 支持的国家和地区才能用，看官方列表。
12. 这些不用装：Node.js 不用，管理员权限也不用。

> 画面建议：三个图标依次出现（电脑 / 网络 / 账号），右边逐条打字幕；可以录一小段 Windows 设置 → 关于，看一眼系统版本。

## 2　打开终端（5 句，126 字，约 23 秒）

13. 先打开终端，就是第 1 期说的，那个只能敲命令的窗口。
14. Mac：按 Command 加空格，输入 Terminal，回车。
15. Windows：按 Win 加 X，选 PowerShell。
16. Windows 有两个长得像的：PowerShell 和 CMD。
17. 每行开头带 PS 的，是 PowerShell；不带的，是 CMD。

> 画面建议：你自己的屏幕录屏——Mac 按 Cmd+Space、Windows 按 Win+X；再出一张对比图：左边每行以 PS 开头，右边不带 PS，橙框圈出 “PS”。

## 3　装：一条命令（9 句，166 字，约 31 秒）

18. 命令就一行：复制，粘贴，回车。
19. Mac 和 Linux，用 curl 那一行。
20. Windows PowerShell，用 irm 那一行。
21. 在 CMD 里，用 curl 那一行，别用 irm。
22. 命令我放在简介里，不用手敲。
23. 回车以后，屏幕会滚一阵字，等它停。
24. 看到 “successfully installed”，就装好了。
25. 这样装的，它会在后台自动更新。
26. 用 Homebrew 或 winget 装也行，不过它们默认不自动更新。

> 画面建议：大窗。三条命令依次出现（官方文档页面录屏，或自己的终端）；在你的真实终端里粘贴 + 回车 + 看到成功提示；命令文字同时打在字幕上。

## 4　验证，和装错了怎么办（8 句，166 字，约 31 秒）

27. 装完，开一个新的终端窗口，输入 claude，空格，两个横杠，version。
28. 能打出版本号，就成功了。
29. （可删）还想更仔细？输入 claude doctor，它给你做一次体检。
30. 提示找不到 claude？多半是路径还没生效。
31. 先关掉终端，重新开一个，再试。
32. 还不行，看官方的排错页，链接在简介。
33. 报 irm 不认识？你在 CMD 里，换 PowerShell。
34. 报 && 无效？你在 PowerShell 里敲了 CMD 那一行。

> 画面建议：录屏——新开终端 → 输入 claude --version → 出版本号。两条报错：官方文档 Troubleshooting 页对应条目圈出来（页面录屏 / 截图）。

## 5　第一次启动：进文件夹，输入 claude（9 句，173 字，约 32 秒）

35. 装好了，来用一用。
36. 先进到一个项目文件夹。
37. 第一次练手，建议用个不怕改坏的，或者新建一个空的。
38. 因为在哪个文件夹启动 claude，它就能动这个文件夹里的东西。
39. 在这个文件夹里，输入 claude，回车。
40. 第一次会让你登录：浏览器会弹出来，登进账号就行。
41. （可删）也可以用 API key 或云平台账号，那是给公司和开发者用的。
42. 陌生的文件夹，它会先问你：信任吗？看清楚再选。
43. 看到 Claude Code 的欢迎界面，就进来了。

> 画面建议：录屏——cd 进文件夹 → 输入 claude → 浏览器弹出登录页（别把账号邮箱录进去）→ 回到终端 → 欢迎界面。登录页和账号信息要打码。

## 6　不想用终端？还有别的入口（6 句，130 字，约 24 秒）

44. 不想碰终端，也行。
45. VS Code：装 Claude Code 扩展，它自带一份，不用另装。
46. JetBrains：要先装好前面这个，再装插件。
47. 桌面应用：登录，点上面的 Code 标签，需要付费订阅，不用碰终端。
48. 网页版：claude.ai/code，不用装，连上 GitHub 仓库就能跑。
49. 终端功能最全，其他入口，用着更顺手。

> 画面建议：四个入口依次切：VS Code 扩展页 / JetBrains 插件页 / 桌面应用 Code 标签 / claude.ai/code，各 2–3 秒，下面标一个字：编辑器 / IDE / 桌面 / 网页。官方课第 3 课有现成素材。

## 7　第一个提示：先别动手（8 句，139 字，约 26 秒）

50. 现在说第一个提示。别急着让它改东西，先让它做计划。
51. 先看底部状态栏：现在是哪一档。
52. 按 Shift 加 Tab，一档一档轮换，换到计划模式。
53. 状态栏会写 plan mode on。
54. 按几下，看你从哪档出发，以状态栏为准。
55. 也可以在提示前面，加一个 /plan。
56. 计划模式：只研究，出方案，不改你的源码。
57. 它可能反问你几个问题，答完，交给你一份计划。

> 画面建议：大窗，终端里按 Shift+Tab，状态栏文字一档档变，停在 plan mode on（橙框圈出状态栏）。

## 8　写一句具体的话（7 句，124 字，约 23 秒）

58. 提示怎么写？官方课的建议：越具体越好。
59. 官方的例子，是给应用加暗色模式。我用大白话念一遍：
60. “我的应用，整个都要有暗色模式。
61. 请在顶栏加一个开关，能在浅色和深色之间切换。
62. 再根据现在的浅色主题，找一个对比度合适的颜色。”
63. 要什么、加在哪、颜色怎么选，都说清楚了。
64. 只说一句“加个暗色模式”，它就得自己猜。

> 画面建议：大窗，终端里一行行打出这条提示；字幕同步中文。官方课第 4 课有现成的打字镜头。

## 9　看计划，批准，开工（9 句，141 字，约 26 秒）

65. 回车以后，它先读你的项目，再出一份计划。
66. 先读一遍。不满意，就告诉它具体改哪一块。
67. 也可以按 Ctrl 加 G，直接在编辑器里改。
68. 没问题了，它给你三个选项。
69. 第一个：批准，并用自动档开工。
70. 第二个：批准，但每一处修改，都由你手动确认。
71. 第三个：不批准，继续计划。
72. 第一次，我建议选第二个，一处一处看它改了什么。
73. 批准以后，它才动手。改完，会告诉你做了什么。

> 画面建议：大窗，官方课第 4 课 104–116 秒（计划 → 选项 → 改动汇总）；三个选项用橙框依次圈。

## 10　收尾（3 句，37 字，约 7 秒）

74. 装它，一条命令。
75. 用好它，从计划模式开始。
76. 下一期：探索，计划，编码，提交，官方推荐的标准工作流。

> 画面建议：回到脸出镜，最后一句打字幕。
