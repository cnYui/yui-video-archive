## 2. 节目规矩（细节在技能里，这里只写这个节目特有的和要紧的）

1. **形式**：竖屏 1080×2340、30 fps，60–90 秒（265–400 个汉字，温柔男生每个汉字约 0.215–0.22 s），**不加悠一片头片尾**，第一帧就是钩子、金句说完留 0.8 s 结束。版式 B + 边框 6 + 随机背景印花 + 系列 BGM（比人声低约 14–15 dB）。中文字幕 52 px + 英文字幕 30 px 双语（ASS 里写 76 / 44，见技能）。
2. **讲法（默认）**：官方视频 2–6 分钟，压成 60–90 秒，所以走“**压缩改写**”：温柔男生用第三人称**重新讲**，不留官方原声、不逐句同传；第 1 期做完让用户听，由用户定要不要改成“原声压低 + 同传”。（技能规矩：压缩成 20–30 秒的二次剪辑不做同传；逐句跟着讲才用同传。）
3. **称呼**：官方视频没有署名的讲解者，一律叫“官方教程”“Anthropic 官方课”；视频里出现人名的，按技能规矩直接叫名字。不以“我”开头，“你”改成无主语。
4. **画面 = 真实素材（≥ 90%）**：上框官方视频片段，下框官方页面录屏（课时页的示意图、命令、代码块、`code.claude.com` 文档页）；不做整屏文字卡片，标题和大数字卡是唯一的设计元素。版式（dual / single）第 1 期定，定了写回 §5。
5. **台本风格**：照 `docs\台本风格_AI大圆镜.md`：第一句就是最反常识的事实（带数字或具体对象）→ 背书（“Claude 官方入门课，今年 5 月发布”：写月份，不写几号）→ 拆机制（短分句、自问自答）→ 泼冷水（边界、官方没写的）→ 收尾金句（能单独转发）。每分钟 8 个以上数字，每个数有出处。
6. **事实核对在台本之前**：每个命令名、模式名、数字，对 `code.claude.com` 的文档页和课时页逐条核；官方没写的明说“官方没写”；视频发布时间从 2025-06 到 2026-09 都有，界面和功能名可能已变（站上横幅：Cowork 现已并入 Claude）。
7. **版权和挂名**：这些视频是 Anthropic / Claude 官方 YouTube 频道的，**标准 YouTube 许可（没有 CC）**。照项目惯例：只做介绍和讲解，不整段搬运原声，用中文重新讲；简介前两行写来源，声明选“含 AI 生成内容”。挂名模板：“画面来自 Anthropic 官方 YouTube 频道（Claude）与 Claude Academy（academy.claude.com），版权归 Anthropic 所有。本期为中文讲解 + 双语字幕。”
8. **发布**：B 站 / 抖音 / 小红书三个平台都发（2026-10-06 起视频号不发），默认项（合集、BGM、话题数、位置、声明）按技能；用户在交付包里说“同意 / 用封面 X 标题 Y”才算授权，视频由用户自己拖进各平台上传区（不压缩、不绕 10 MB）。
9. **共用资源要排队**：Chrome、Fish、渲染都可能被别的会话占着，开工先 `ListAgents`；同一时间只跑一个渲染（空闲内存 < 6 GB 用 3 路）。**这台电脑常年很忙**：2026-10-05 晚上 faster-whisper large-v3-turbo 转一条 3 分钟视频 7 分钟都没出，要转写先看别的会话在不在跑重活。

- **要点**：和聊天窗口最大的差别：它能直接动你的文件、终端、整个代码库。底层是“代理循环”：找线索 → 动手（改文件、跑命令）→ 验结果，没过就再来，你随时能插话、打断、纠偏。四个零件：循环、上下文窗口（满了自动压缩）、工具（什么时候该调用由它判断）、权限模式（手动 / 自动接受编辑 / 计划 / 自动）。能做：读懂代码库、跨文件改、跑构建和测试、搜网页；可以在终端、VS Code、JetBrains、桌面端里用。
- **钩子（草案）**：「Claude Code 干活就三步：找线索，动手，验结果。没验过，重来。」
- **收尾（草案）**：聊天框交答案，代理交结果。
- **画面**：上框官方视频（循环示意 + 终端演示）；下框课时页的循环图（`how-claude-code-works` 页）。
- **泼冷水 / 核对**：官方自己写了它会误解意图、引入 bug、过度设计，所以人要守在循环里。权限模式名和数量以文档为准（101 课写 4 种日常模式，实战课写 6 种，是同一套）。

### 第 6 期｜Hooks：把“通常照做”变成“不可能跳过”

- **素材**：`CCA-05_hooks__1m0huCacWPs.mp4`（3:24，2026-09）；课时页 `courses/claude-code-in-action/hooks`。**可选补充（未下）**：101 第 12 课 `IkaPHiMDazM`（3:21）。
- **要点**：CLAUDE.md 里写“每次编辑后跑格式化”，Claude 多数时候会做；hook 保证每一次都做。hook 是挂在事件上的代码：PreToolUse（工具调用前，能拦）、PostToolUse（调用后，常用来自动格式化 / lint）、Stop（它想收工时，没过就拦下）；官方说大约 30 个事件，常用就这几个。PreToolUse 退出码 2 才是拦截，错误信息会反馈给 Claude 让它换做法。

- **收尾（草案）**：请求会被忘，钩子不会。
- **画面**：上框官方视频；下框课时页的事件列表 / `settings.json` 配置示例。
- **泼冷水 / 核对**：退出码要对，2 才拦，其他只是报错不拦；事件数量以文档为准。

### 第 9 期｜MCP：把数据库、工单、最新文档接给 Claude Code

### 第 10 期｜权限模式与自动模式：怎么放心放手

- **素材**：`CCA-04_permission-modes__IS6larFJBK8.mp4`（2:41，2026-09）；课时页 `courses/claude-code-in-action/permission-modes`。
- **要点**：一共六种模式：手动 / 接受编辑 / 计划 / 自动 / 不问 / 绕过权限；Shift+Tab 在日常四种间切，状态栏显示当前模式。自动模式 = 另一个分类器模型在每个动作前审意图，专拦：生产部署、强推、下载来的代码直接进 shell、往外发敏感数据、不可逆地删会话前就有的文件；放行日常的本地编辑、按锁文件装依赖、只读请求、推自己的分支。**它只管危不危险，不管对不对**，所以要配一个跑测试的 Stop hook（回扣第 6 期）。“不问”给 CI、定时任务这类没人批准的场景；“绕过权限”只许在隔离容器或虚拟机里用。
- **钩子（草案）**：「自动模式里有个保安盯着每一步。但他只管安不安全，不管对不对。」
- **收尾（草案）**：保安管安不安全，测试管对不对。
- **画面**：上框官方视频；下框课时页的六种模式列表 / 状态栏。
- **核对**：官方自己说自动模式的护栏还在变，名单以文档为准；自动模式不是所有套餐都有（官方课时页写“取决于套餐和设置”）。
- **封面钩子草案**：「自动模式 / 有个保安」
