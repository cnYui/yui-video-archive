## 做对的（留着）

- **第 1 期的教训前置了**：开工先排画面配比（官方演示 53% + 页面录屏 47%，卡片 0%）、目录 ≤ 3 条、封面字和标题分开、配音用空白项目；这四条第 1 期各返工一次，这期都没有。
- **事实核对前置、并行**：台本是照“能写 / 不能写”清单写的，推文省掉的前提（默认关闭、第一方会话 + 遥测、组织可用、源码没公开）都补上了，官方没写的明说；用户反馈（GitHub issue）只放简介，标明“不是官方结论”。
- **下载走公开接口**：X 的嵌入接口直接给官方 CDN 直链，不用第三方站，也不用解 JWT；主机名校验写进了脚本。
- **引擎复用**：中英双语引擎（OpenAI 相关的模板）+ 第 1 期的页面录屏，只加了 `hold` / `@row` / `note` / `box` 几处；从开工到出第一版静帧约 26 分钟。
- **配音一次生成、一次导出**，`import_segments.py` 按 metadata.csv 逐句核对文字再放进工程，没出现对不上的句子；和 Tavus 会话轮流用 Chrome / Fish，没有互相覆盖。
- **机器验收到位**：`check_subs.py`（字幕不出版面）、`qa_mix.py`（每条字幕窗口里是对应那句话）、`check_cover.py`（官方宇航员逐像素对）；成片抽帧自己看过。
- **投稿时用户在页面里改标题，我只读不写**，没有互相覆盖。
