【要点】（来自官方文档和 @ClaudeDevs 推文，细节以官方为准）
· Projects 在升级：从“文件夹”变成“和 Claude 的一场对话”，先从 Claude Code 开始；聊天和 Cowork 里本来就有的项目也会跟着升级。
· 现状：公测，Pro 和 Max 用户逐步放量；Team 和 Enterprise 暂时没有。官方推文说，等候名单里的 Pro 和 Max 用户已经全部放进来了。
· 入口：claude.ai/code、桌面 App 的 Code 标签页、手机 App；文档写明终端 CLI、VS Code、JetBrains 里没有。
· 侧栏里看不到 Projects，说明还没轮到你，可以报名等候名单：https://claude.com/form/projects
