时间参考：第 3 期（《You should know 插件》）从“用户发来两条推文 + 一篇博文”到用户点“立即投稿”约 1 小时 45 分钟；其中事实核对子代理跑了 32 分钟（我同时在搭引擎、录页面），配音前等 Tavus 会话用完 Chrome / Fish 约 6 分钟（之后它又要了两次，我让出来，没卡住自己），抽帧 + 版面小样几分钟，**渲染 4 路约 2 分钟（3335 帧）**，`qa_mix.py` 约 4 分 45 秒，`finish.py` 约 1 分钟。顺的话主要时间在台本、叠加层位置和等用户。

## 1. 下载官方视频

```bash
python scripts/fetch_x_video.py "<推文链接>" "<另一条>" --out "<本期>\素材\X平台视频_ClaudeDevs"
```
- X 的公开嵌入接口 `cdn.syndication.twimg.com/tweet-result?id=<ID>&lang=en&token=a` 给出推文全文、UTC 时间、t.co 展开后的链接、各档 mp4 直链（`video.twimg.com`，官方 CDN）、回复关系。脚本取最高码率那档，断言主机名、下载、`ffprobe` 核对，写 `来源.md`。**不用 TwitterSaver**（没有点击劫持广告、不用解 JWT）；用户明说用 TwitterSaver 就照他说的（openai-episode 技能里有那套）。
- 官方视频的音轨多半是界面提示音（第 3 期：−16.5 LUFS，在“提示出现”“按键”那几秒有尖峰），不是人声：`faster-whisper small` 听一遍确认（只会幻觉出 “Thank you for watching”）。有提示音就留着（`HAS_AUDIO: True`，混音里会压到 −21 LUFS、旁白说话时再压 −9 dB）。
- 推文里的 `https://claude.dev/...` 博文、docs 链接就是要读的官方页面（`curl -sL -A "<Chrome UA>"` 抓 HTML 取正文）；**博文可能压根没提这条推文说的功能**（第 3 期的博文是 Token Weather 教程，全文没提 You should know）——推文是主来源，博文是背景。

## 2. 看素材

- `python scripts/tsheet.py <视频> <联系表.png> 1 5 480` 看整条（每帧左上角是秒数）；再用 `… 4 5 384 12 14.5` 细看某个瞬间什么时候出现（第 3 期靠它定出：提示 12.8 s 出现、按键 1 在 17.0–17.5 s、按键 2 在 23.5–23.8 s、第 24 s 引用块贴进输入框）。
- 关键帧抽成全分辨率（`ffmpeg -ss t -i … -frames:v 1`）读英文原文，译文和高亮框的坐标按这些帧量。终端演示常带“运镜”（开头 / 结尾窗口缩小放大），中间一段是定格的全屏终端——叠加层只在定格那段放。
- 要回顾上一期的素材（比如 mod 示例）：直接引用上一期 `素材\X平台视频_ClaudeDevs\` 里的文件（`common.py` 里写绝对路径），不重复下载；但**提到上一期讲过的东西用一句话带过**，别重复讲。

## 3. 台本和画面表

**先做事实核对（facts.md），再写台本。**
- `台本/录制稿.json`：`slug`、`title`、`sub`（左栏标题下的小字）、`chapters`（字符串，≤ 3 条 ≤ 7 字）、`lines`（`id` / `zh` / `say` / `en`；长句拆条的断点 `"cut": [[中文锚点, 英文锚点], …]`，`bilingual_std` 自动拆得不顺才写）。
- **2026-10-04 起照 AI大圆镜 的写法**：先读 `D:\大疆\docs\台本风格_AI大圆镜.md`（钩子带数字、15 秒内给来源、分句 8–12 字、每分钟 8 个以上数字、短问句换挡、泼冷水、金句收尾；里面有拿第 3 期开头改写的示例）。
- 风格：短句口语，一句一个意思；不用“不是……而是……”；中文每句 ≤ 约 28 字；官方事实带出处词（“官方推文说”“文档里的说明”“更新日志写着”）；**官方没写的明说“官方没写”**；开场用演示的前十几秒当钩子，别先讲概念；结尾一句话收，不喊口号。
- `say`（念的字）约定：数字写汉字（`二点一点二八七`）；`/plugin` 写 `斜杠 plugin`；`mod` 在中文里写“模组”（和第 1 期一致）、英文字幕写 mod；产品名原样（Claude Code、You should know）；“按 1”写“按一”。
- `en`：口语、简洁、≤ 约 90 字符（自动拆条以后每条 ≤ 90）；官方名称原样。**写完 `check_subs.py` 一遍**。
- 估时：`--est` 按 6.4 字/秒，曼波实测约 6.6 字/秒（第 3 期 23 句 647 字 → 97.5 s 有声，占成片 87%；官方信息类话比较密，想轻一点就拆成两条或删次要句）。
- `台本/plan.json`：`type: clip`（`ranges` 素材段，`{"src","in","out"[,"crop"]}`；`{"src","in","hold":秒}` = 定格那一刻）/ `type: card`（`dur` 秒，**页面录屏场景用 card + `overlay: "page"`，画面由 scenes.js 的 pageShot 铺满整个场景**）；`chapter`（−1 = 开场，章数 = 收尾全标已看）；`lines: [{id, a}]`，`a` = 这句话从场景开头起第几秒开口（前一句没念完自动顺延 0.18 s）；`credit`（右上角来源角标 `@ClaudeDevs · X（官方演示）`）。
- **让旁白和画面对上**：把演示拆成“一个节拍一个场景”（第 3 期 6 段：开场 / 提醒弹出 / 看详情 / 带回主会话 / 改好 / 收尾），每段 `ranges` = 真实播放的那几秒 + `hold`（静止画面撑到旁白说完）；话比画面长而最后一段不是定格时，素材会接着往下放，可能提前播到下一个节拍——这时加一段 `hold`。定格点离素材结尾要 ≥ 0.1 s（第 3 期定在 38.86 s、视频 38.867 s，ffmpeg 取不到帧，改 38.8）。
- 结尾可以回到演示最后一个画面（窗口缩回去的那 2–3 s + 定格 4 s），上面放开启命令 `.cmd` 条，当“带走一句话”。

## 4. 引擎和叠加层（`scenes.js`）

- 版式见 SKILL.md；左栏是文字目录（≤ 3 条），不是缩略图。
- 工具：`S(id)` / `E(id)` = 这句开始 / 结束的成片秒；`P(id, '词')` = 说到这个词的时刻；`V('d1', 10.1)` = 素材 d1 的第 10.1 秒在成片里的时刻（把标注钉在演示的某一刻）。
- `note(t0, t1, '中文译文', '小字', {x, y, w})` 译文条；`box(t0, t1, x, y, w, h)` 高亮框；`pageShot(from, to, 页面图名, [[句子, 时刻, 中文译文], …], {start, pad})` 页面录屏（见 pages.md）。
- 来源角标默认右上角，**别把译文条放在那儿**；终端的输入框那一带（演示区 y 640–740）最干净；引用块和输入行之间只有一行空档时用 y 636 的单行译文；演示里原来就有的按键提示、标签（比如 Glossed over）别再重复画。
- 最后一个场景的叠加层要盖到片尾（`TL.total`），不然片尾那 1.4 s 角标消失。

## 5. 时间轴、抽帧、版面自查

```bash
cd "<本期>\制作\00_整片"
python build_timeline.py [--est]    # --est：配音还没出，按字数估时间（出版式小样）；看“字幕 N 条（超长没拆开：…）”和【注意】（注释超出场景）
python check_subs.py                # 字幕版式自检（中英各一行、不超出画面、演示区不压字幕带）
python capture_pages.py             # 官方页面 / 推文截图 + 高亮位置（写 media/pages/ 和 pages.js / pages.json）
python prep_frames.py               # 抽帧（增量：media/scr/_manifest.json；定格段只抽 1 帧）
python render_all.py --stills-segs  # 每个场景 3 张静帧 + 联系表（stills/_sheet_segs_*.png）
python render_all.py --stills 16.5 18.0   # 指定时刻
```
- **静帧要逐张看**：第 3 期靠它抓到——来源角标盖住终端第一行字、重复画了官方已有的按键提示、译文条盖住输入行、页面镜头之间闪一下空白底（页面镜头要铺满整个场景，`pageShot` 已处理）、`T_uses` 截图顶上露出上一段的半行字（起点留白要小）。
- 配音还没出时先 `--est` 排版面；配音出来后重跑 `build_timeline.py` + `prep_frames.py`（只重抽变了的段）；改了 CSS / 叠加层不用重抽帧。

## 6. 混音、渲染、复核

- `mix_audio.py`：画外音 −16 LUFS（两遍 loudnorm，线性）；素材原声拼起来量一次拉到 −21 LUFS、有人说话压 −9 dB；定格段没有原声；系列 BGM（`AI科普/素材/音频/bgm.wav`）垫在下面；整片 −16 LUFS + 软限幅。
- **渲染**：`ListAgents` + 空闲内存（`Get-CimInstance Win32_OperatingSystem`）→ ≥ 6 GB 用 4 路，否则 `RENDER_WORKERS=3`；`python render_all.py`（约 2 分钟 / 3300 帧）；同一时间只一个渲染。
- **复核（出片前必做）**：`python qa_mix.py`（把混音按字幕逐句切出来识别，和字幕比；看每条窗口里是不是对应那句话、有没有叠音 / 放错位置；低分的是声线老毛病，列给用户听）；成片抽帧（`tsheet.py` 每 5 s 一帧、全分辨率几帧看字幕和叠加层）。

## 7. 收尾（finish.py）

`python finish.py`：共用片头片尾（`AI科普/skill/yuanlai-ruci-episode/scripts/add_to_video.py`，正片不重编码）→ `<slug>_成片.mp4`、`_手机预览.mp4`、三份 SRT（时间 = 字幕显示区间 + 片头秒数，读 `pack_info.intro_seconds()`）、响度报告。`python scripts/predeliver_check.py "<本期目录>"` 自查。看片头（4.8 s）和片尾（9.0 s，参考文献 + 致谢是否排得下）各抽几帧。

## 10. 坑清单

| 坑 | 做法 |
|---|---|
| 推文省掉前提（默认关、版本、组织 / 遥测限制） | 台本前先读文档 + 更新日志，讲清“默认是关的，要自己开” |
| 上一期说的话和这期的功能冲突（第 1 期“模组默认开着”≠ 这个内置插件默认关） | 写台本前对上一期台本 `录制稿_*.md` 的“已讲过”清单，冲突处明说 |
| 共用片头片尾当天被改（4.8 / 9.0 s） | 时长读 `pack_info`，复制模板前看最新记录；`common.INTRO_SEC` 和 `finish.py` 输出对一下 |
| 定格点贴着素材结尾 | ≥ 0.1 s |
| 页面镜头之间闪空白底 | 页面镜头铺满整个场景（pageShot 已做） |
| x.com 帖子页无头浏览器是空白 | 用 X 嵌入页 `platform.twitter.com/embed/Tweet.html?id=…`（capture_pages.py 的 `X_` 页面） |
| 表格里好几行有同一句话 | `@row:行里的字\|格子里的字`（这里竖线前的反斜杠只是 markdown 表格的转义，SPECS 里写时竖线前面不加反斜杠，见 pages.md） |
| 导出 zip 里个别句是 mp3 | `import_segments.py` 自动转 wav |
| 命令里带删除命令字样被钩子拦 | 写文件再运行，不绕 |
| 用户在投稿页里手改标题 | 只读不写，投完用接口读线上标题同步回文档 |
| 标签被静默丢掉（“新功能”） | 加完读回，被丢的换一个（AI Agent） |
