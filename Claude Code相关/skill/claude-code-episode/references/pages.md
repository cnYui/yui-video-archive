# 官方页面 / 推文录屏、演示上的译文条、定格

用户 2026-10-02：“视频里多出现你下载的视频演示片段，而不是你一味的在说讲解”。官方没有现成视频的段落，就**录官方页面**：用 Playwright 把要讲的小节截成高清长图，量出要高亮的那句话的位置，视频里按解说时刻把图往上滚、给对应的句子刷荧光笔，底部一条中文译文——就像在录屏。第 1 期做了 19 张页面图，第 3 期做了 4 张（推文 ×2、文档内置模组表、更新日志），占画面 47%（官方演示视频 53%，卡片 0%）。

## 1. 截图：`capture_pages.py`

```bash
cd "<本期>\制作\00_整片"
python capture_pages.py            # SPECS 里全部重录
python capture_pages.py Y_list …   # 只录指定的几张
```
输出 `media/pages/<名字>.png`（800 CSS 宽 × 2 倍像素 = 1600 宽；推文是它自己的宽度）+ `pages.json` / `pages.js`（`window.PG`：每张图的 `src / w / h / url / bg / marks`，marks = 高亮句子在图里的像素位置）。

`SPECS = {名字: (页面, 起点文字, 高度 CSS px, 起点上方留白, [要高亮的句子])}`：
- **起点文字**：页面里能找到的一句话（取包含它的最小元素的上边）；以 `#` 开头 = 只在 h1–h4 里找这个标题（`#Mods built into Claude Code`）。
- **高度 / 留白**：每张图只截要讲的那一小段（约 450–1100 CSS px 高）。留白要小（≤ 15–40）：留大了上一段的半行字会露在图顶上（第 3 期 `T_uses` 留 60 就露了）；更新日志要留 150 才看得见上面的版本号和日期。
- **高亮句子**（≤ 15 个词，大小写不敏感，弯引号 / 直引号都认）：普通文字 = 页面里的原文子串；`@@文字` = 高亮它所在的整个段落块；`#sel:选择器` = 整块（图表）画框，不填色；**`@row:行里的字|格子里的字` = 表里这一行的这个格子**（几行都有 “Disable it in /plugin” 时点名取最后一行那格）。
- 句子里夹着链接 / 代码就是几个文本节点，单节点匹配不到——用句子的前半段，或用 `@@`。找不到会打印“没找到要高亮的句子”。
- **推文**（页面名 `X_` 开头）：用 X 的公开嵌入页 `https://platform.twitter.com/embed/Tweet.html?id=<ID>&theme=light&hideThread=true&lang=en&dnt=true`（x.com 的帖子页在无头浏览器里是空白）；按 `article` 外框截，高度写 `"after:某句话"` = 只截到这句话下面（推文 1 截到命令那行，不带视频封面），写 `0` = 整条（推文 2 带博文链接卡片）；`SHOW_URL = {"X_t1": "https://x.com/<账号>/status/<ID>"}` 决定浏览器顶栏里显示的网址；嵌入页的时间按本机时区显示（东京），旁白说日期要和 UTC 对上。
- 官方文档是前端渲染的：`goto` 后等 2.5 s + 滚一遍触发懒加载，脚本已做。

## 2. 视频里：`pageShot`（scenes.js）

```js
pageShot('N16', 'N20', 'Y_list', [
  ['cc-plugin-you-should-know', S('N16') + 1.0, '官方文档的内置模组表：现在一共 6 个，最后一行就是它'],
  ['Disabled by default.', S('N18') + 0.2, '默认关闭'],
  ['@row:cc-plugin-you-should-know|Disable it in /plugin', S('N20') + 0.2, '关闭：在 /plugin 里 Disable'],
  ["You can't update or uninstall a built-in mod", P('N20', '不能卸载') - 0.4, '内置模组不能更新，也不能卸载']], { start: 0, pad: 0 });
```
- 参数：`from` / `to` = 这个镜头从哪句到哪句；页面图名；`[[句子, 刷上的时刻, 中文译文?], …]`（按时刻从早到晚；**不要求页面里从上到下**，可以往回滚）；`{start: 起始滚动位置（图片像素）, pad: 比最后一句再多留的秒数}`。
- 每条高亮出现前 0.95 s 开始往它那里滚，滚到画面偏上三分之一；比窗口还高的（图表）顶部对齐；已经讲过的高亮变淡（opacity 0.4）；译文条在底部（黑底白字 40 px，单行 ≤ 约 30 个汉字）。
- **页面镜头铺满整个场景**（`pageShot` 自己找到起止句所在的场景，t0 取场景开头、t1 取场景结尾）：卡片场景前后各有零点几秒空档，不铺满会闪一下空白底。镜头之间快切（淡入淡出 0.1 s），不然两页文字叠在一起。
- 浏览器顶栏（红黄绿点 + 网址）是画出来的，网址取页面图的 `url`。

## 3. 演示视频上的叠加层

演示区坐标 1474×829（源视频 1920×1080 的坐标 × 0.7677）。**先抽关键时刻的全分辨率帧再量坐标**，叠加层按 `V('d1', 秒)` 钉在演示的某一刻。

- `note(t0, t1, '中文译文', '小字', {x, y, w})`：白底橙边条，默认 `x 40, y 648, w 1394`；译文是把画面里的英文翻成中文（便条原文、按键选项、Claude 的回复），小字放解释。
- `box(t0, t1, x, y, w, h)`：橙色高亮框（5 px 边 + 淡橙光）。
- **位置经验**（终端演示）：右上角是来源角标，别放；输入框那一带（y 640–740）和引用块与输入行之间的空档最干净；输入行里正在显示被引用 / 追问的内容时，译文条改放 y 636 的单行；官方视频里原来就有的标签 / 按键提示（Glossed over、按键 1 的圆角键帽）别再画一遍（第 3 期画重了，删掉）。
- 演示 / 页面镜头里出现的官方品牌图（推文头像、博文卡片）就是截图原样，不加工。

## 4. `hold`（定格）和节拍

静止的画面（读提示、读解释）配的旁白常比画面长。`plan.json` 的 range 写 `{"src": "d1", "in": 21.0, "hold": 6.8}`：取素材 21.0 s 那一帧定格 6.8 s（只抽 1 帧，混音里没有原声）。一个节拍一个场景：`ranges: [{真实播放的几秒}, {hold}]`，旁白 `lines` 的 `a` 对着真实画面变化的时刻。注意：定格点离素材结尾 ≥ 0.1 s；`V()` 在定格段里返回定格开始的时刻。
