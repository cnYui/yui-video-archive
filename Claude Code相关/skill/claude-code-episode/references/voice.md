# 配音：Fish 网页版「故事工作室」空白项目（曼波声线）

> **2026-10-04 更新**：用户“之后语音合成使用温柔男生这个配音”——**新一期起 Fish 里选声音「温柔男生」**（下面写“赛马娘（曼波欧耶版）”的步骤，选声音的方法不变，把声音换成它；模型沿用 S2 Pro）；已做完的几期不动。

用户 2026-10-02：“你可以新建一个空白的fishapi页面来做tts”——TTS 页的编辑框草稿是服务端存的、所有标签页和会话共享（日报、Fable、DevDay 都往里贴稿），所以用**故事工作室的空白项目**：独立、不碰共享草稿。声音「赛马娘（曼波欧耶版）」，模型 **S2 Pro**（旧版；默认是 S2.1 Pro，要重选）。第 3 期（23 句 / 647 字，一次生成、一次导出）实测的步骤如下；记忆 `fish-tts-use-blank-page` 里也有。

## 步骤（Chrome 插件，账号内网页不用内置浏览器）

0. **先问别的会话在不在用 Chrome / Fish**（`ListAgents`）。第 3 期有另一个会话（Tavus）同时要用：它发消息约时段，我让给它、等它说“用完了”再开，用完我也发消息还它。共用一个 Chrome 窗口时，**隐藏的标签没法可靠输入文字**（Fish 点“生成”没反应），谁用谁的标签要在前台；用户全屏看视频时别把标签盖上去。
1. `https://fish.audio/zh-CN/app/story-studio/` → 右上“新建项目”（第一次点可能没反应，再点一次）→ 弹窗“空白项目”（里面有一句示例文字）。页面地址里的项目 ID 是账号内编号，别写进仓库文件。
2. **声音**：右侧“声音”卡片，悬停出现 ⇄（重新选择语音）→ 弹窗“最近使用”里悬停赛马娘（曼波欧耶版）→ “使用” → 弹窗问“当前章节还是所有章节”选“所有章节”。**模型**：右侧“模型”下拉 → S2 Pro。
3. **台词**：点示例文字 → `Ctrl+A` → `computer type` 整篇（一行一句、每个换行 = 一个区块；`say` 列的字）。只有一个区块时 Ctrl+A 才选得全；长文档里它只选中渲染出来的那部分，要换稿就“章节”→ 新篇章，在新章节的空白区块里键入（新章节的声音 / 模型要重选）。键入后用 `javascript_tool` 读 `document.querySelectorAll('div.content')` 逐句核对（应有 N 块、文字和台本 `say` 一致）。改某一句要用真实键入，别用 `execCommand('insertText')`（界面上看着改了、重新打开又变回旧稿）。
4. **生成**：右上黑色“生成”（整稿十几秒）；生成完按钮变“重新生成”，**别点**（会整稿重来）。
5. **导出**：“导出项目” → 面板里“章节”默认“整个项目”、**“文件结构”选“按段落拆分”**（每次打开面板都回到“单个文件”；选完后 MP3 / WAV 两个按钮会变灰）→ “导出” → 几秒后 Chrome 下载 `C:\Users\yui\Downloads\segments (N).zip`（`N` 是第几次下载，别拿错别的会话那份）。zip 里 `segments/<章节名>/000000.wav …`（逐句单声道 44.1 kHz；**偶尔有一句是 mp3**，第 3 期最后一句）+ `segments/metadata.csv`（ID、文字、文件名，顺序 = 台词顺序）。面板里的“预计费用”≈ 文本字节数（积分），估计值，实际扣多少没核对。
6. **放进工程**：`python import_segments.py "C:\Users\yui\Downloads\segments (N).zip"`（在 `制作\02_配音\`）：按 metadata.csv 顺序和台本 `say` 逐句核对文字（不一致就停）→ 放进 `tts\seg_raw\final\000000.wav …`（mp3 自动转 wav，旧 final/ 备份成 `final_旧_<时间>/`，不删）。要换其中几句：把新导出的那一句放进 `tts\seg_pick_v3\<句号>.wav`（盖过同序号的）。
7. `python build_voice.py [--qa]`：逐句转 48 kHz 立体声 → 去头尾静音（> −45 dB）→ 前留 0.12 s / 后留 0.25 s → 音量拉到各句中位数（±4 dB）→ 拼成 `edit/tts_narration.wav` 和 `edit/tts_edit.json`；`--qa` 逐句 large-v3-turbo 识别和 `say` 比（约 1–2 分钟）。
8. 项目会留在用户账号的“故事工作室”里（我建的叫“未命名项目”），做完告诉用户可以删。`制作/02_配音/web_usage.txt` 记一行：时间、声音 / 模型、句数 / 字数、生成了几次、为什么重生成。

## 写 `say`（念的字）

- 数字写汉字：版本号“二点一点二八七”、“按一”“按二”；`/plugin` 写“斜杠 plugin”；`mod` 写“模组”；`@` 写“艾特”。
- 英文专名原样写（Claude、Claude Code、You should know、Agent Loop）；每句短，一句一个区块。语速约 6.6 字/秒。
- 这个声线的老毛病：英文专名读得偏中文腔、sh/x、q/x、ch/q 被 whisper 听错；**机器识别分低不等于读错**（第 3 期 6 句低于 0.85：N01、N12、N15、N18、N20、N21，多是 Claude / /plugin / 遥测），要用户耳朵听；用户说哪句不好，只重生成那一句。
- 想让某个英文词读准，可以在 `say` 里换成中文音译（别的会话遇到“英文专名读歪了，换成中文音译整稿重生成”）——但字幕 `zh` 仍写原文。
