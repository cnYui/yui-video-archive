# 封面设计笔记（Claude Code相关，2026-10-02）

## 官方像素宇航员

- claude.dev 教程页底部的场景（`footer .scene`）= 一张 2 倍分辨率的星空 canvas（灰色点阵的月牙、土星、星点）+ `.astro-stage` 里另一张 canvas，宇航员在上面逐格画出来。
- 宇航员的数据在页面前端脚本里（`fetch_sprite.py` 取）：`n({w:40, h:33, fps:12, palette:[…6 色…], base:"…1320 字符…", deltas:[130 帧补丁]})`。调色板下标：0 `#141413` 眼睛 · 1 `#bf684c` 深橙 · 2 `#d97757` 品牌橙 · 3 `#d1cfc4` 头盔环 · 4 `#f5db9a` 小星光 · 5 `#faf9f4` 高光。
- base = 没戴头盔的 Claude Code 小怪物：头 16×4（cols 13–28、rows 17–20，眼睛是 2×2 深色格，在 cols 15–16 和 25–26、rows 19–20）、手臂带（rows 21–24、cols 9–32）、躯干（rows 25–28）、四条腿（rows 29–32 的 cols 13–14、17–18、23–24、27–28）。deltas 是对上一帧的补丁（“格子序号 36 进制 + 新值”），头盔飞来扣上（约第 3–6 帧）→ 站直戴头盔（第 12 帧：环 rows 10–23、领口 row 23）→ 漂浮摇摆、拖着腿、冒小星光（第 30–60 帧）→ 头盔飞走。
- `mascot.py` 的 `float` / `float2` / `float3` / `stand` 就是第 40 / 47 / 54 / 12 帧；自画动作都从第 12 帧改：手臂 `LEFT_ARM` / `RIGHT_ARM`（各 13 格）、腿 `LEGS`、眼睛 `EYES_L` / `EYES_R`。

## 版式（16:9 = 1920×1080）

- 字：Noto Sans SC 900，左上两行，`x = 128`、第一行顶 `y = 150`、行距 1.08；字号最大 230，自动适配。字下垫一圈 16 px 的“底色描边”（`-webkit-text-stroke` + `paint-order: stroke fill`），挤掉紧贴字边的星点。night 方案另有很淡的黑色字影；其他方案不加（会把浅底弄脏）。
- 宇航员：右下，每格 18 px（身体 24 格 = 432 px = 22.5% 宽），外框中心在 x = 0.75w，外框底边在 y = 0.81h（地平线）；超出 96–1824 / 40–950 自动挪进来。4:3（1440×1080）每格 14 px，中心 x = 0.70w，底边 0.88h，字 `x = 84`、`y1 = 100`、最大 210。
- 字和宇航员的间距：字框外扩左右 90 px（4:3 是 70）、上下 24 px 后不碰宇航员的任何一格（按格子，不按外框，道具才不会把字挤小）。
- 字号不够（16:9 < 190、4:3 < 170）时自动把宇航员每格缩小 1 px 再试，**保底 16:9 每格 16 / 4:3 每格 12（身体宽都是 20%）**；验收的下限是 17% / 18%（每格 14 / 11），保底留了余量。再不够就换动作、`--flip` 或缩短字，不再缩宇航员。第 3 期的三个候选：A 别漏看重点 / Claude 新插件（字号 170、每格 16），B You should know / 官方新插件（200 / 18；4:3 是 154 / 12），C 它替你盯着 / Claude 的输出（168 / 16）。
- 像素小星光（橙 / 淡黄的菱形）不落在 16:9 的 96 px 两侧边里：那里的橙色会被验收数成“字溢出到 16:10 裁切区”。

## 背景方案（配色表在 `mascot.py` 的 `SCHEMES`）

| 方案 | 底色 | 第 1 行字 | 第 2 行字 | 头盔环 / 高光 | 星点 | 备注 |
|---|---|---|---|---|---|---|
| night | #141413 | 米白 #FAF9F5 | 品牌橙 #D97757 | 浅灰 #D1CFC4 / 米白 | 官方星空截图（灰点，只提亮不改色） | 第 1 期用的；也可 `--bg pixel` |
| ivory | #FAF9F5 | 深色 #141413 | 深橙 #C15F3C | 深色 / 米白 | 像素方点（米色 / 灰）+ 橙色小星光 | 头盔环改深色，不然和底色混 |
| orange | #D97757 | 米白 | 深色 | 米白 / 米白 | 像素方点（浅橙 / 深橙 / 淡黄）+ 淡黄小星光 | 宇航员加 1 格深色描边（身体和底色同色）；星光不用米白（和字色撞，验收会数成字色） |
| yellow | #F5DB9A | 深色 | 深橙 | 深色 / 米白 | 像素方点（黄 / 米色）+ 橙色小星光 | 淡黄 = 宇航员小星光的颜色 |

道具颜色：`P`（主色：night 米白 / ivory 深色 / orange 米白 / yellow 深色）、`S`（副色：night 淡黄 / ivory 橙 / orange 淡黄 / yellow 橙），保证道具在该底色上看得清。

## 验收（`check_cover.py`）

尺寸；底色；品牌橙占比（night / ivory / yellow ≥ 1%，orange 不查）；饱和像素里色相不在 8°–62°（橙–黄）的 ≤ 0.05%；宇航员按 meta 重新渲染后和成图逐像素一致 ≥ 95%（没被字压住、没被裁）且身体宽 ≥ 17%（4:3 ≥ 18%）；16:9 左右各 96 px 里没有字色 / 品牌橙像素。

## 试过并放弃的

1. 整体提亮背景：宇航员的橙变桃色、头盔线发白 → 只提亮灰色星点（按饱和度加权）。
2. 叠一层暖色径向光晕：发脏（棕色雾）→ 去掉。
3. 用截图抠宇航员再放大：边缘糊、星点贴着字尾读成省略号 → 改成直接用像素表按格子渲染，字避让按格子算。
4. 拼图块道具画得不像（像竖起的拇指）→ 换成插头（plugin / 模组）。
5. orange 方案的星光用米白：和第 1 行字同色，16:10 安全区验收会把它数成字色像素 → 改淡黄。
6. 第 1 期最初的封面 A / B（三个演示界面拼贴）被用户说“太丑了”→ 换成官方太空场景 + 宇航员；第 1 期封面在 `01_Claude Code模组发布\制作\04_封面\`，旧稿在 `_旧稿\`。
7. 第 3 期第一版封面没走 `make_cover.py`，另写脚本画了一个原创的橙色机器人：用户“太丑了，而且这都不是 claude 的形象”→ 整个丢掉（放进 `_旧稿_原创角色\`），重来用官方宇航员帧。教训：形象只来自 `mascot.py`，验收第 5 条会把非官方形象挡在外面；赶时间也不要自己造角色。
8. 自动缩小宇航员原来的保底是每格 12 px（身体宽 15%）：长字 + 带道具的动作会缩到 15%，验收判不合格 → 保底改成每格 16 / 12，字号不够就报警让人换动作或缩字。
9. 小星光落在 16:10 两侧被安全区验收误报（第 3 期 C 候选要靠换 `--seed 2` 才过）→ 生成时就避开两侧，不用再换 seed。
