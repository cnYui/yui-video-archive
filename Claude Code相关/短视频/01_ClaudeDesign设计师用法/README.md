## 配音

- Fish Audio 网页版「故事工作室」空白项目，声音「赛马娘（曼波欧耶版）」、模型 S2 Pro，一句一个区块（9 句 / 205 个字符含英文字母），导出“按段落拆分”。
- 实测语速：9 句 = 121 个汉字 + 7 个英文词（Anthropic、Claude ×4、Design、Code、Artifacts）+ 22 个标点，有声共 27.15 s ≈ 每个汉字 0.22 s（含英文词和标点停顿，即 4.5 汉字/s；不算英文词和停顿约 6.5 汉字/s）；要 30 秒封顶，汉字别超过约 125 个。`build_voice.py` 把句内 ≥ 0.3 s 的停顿压成 0.2 s（省 0.7 s）→ 26.42 s。
- 机器识别（large-v3-turbo + medium；`qa_mix.py` 对成片音轨的分数）：N04、N08 满分，N02、N03、N05、N06、N07 在 0.86–0.94；**N01 “设计师” 被听成“谢继续 / 续剧续 / CGC”（0.83），N09 “掌舵” 被听成“讲读 / 讲诺”（0.43）**，是这个声线的老毛病（zh→j、sh→x），**要用耳朵听**；Anthropic / Claude Design / Artifacts 英文专名识别器都认得出来。要换：N09 可以改成“你来定方向”（只改那一句，但网页的“重新生成”会整稿重来，所有句子都要重新核对）。
- 画面和配音同步：`qa_mix.py` 实测每句开口和时间线差 +5…+10 ms；成片响度 -16.0 LUFS。
- Fish 里留了一个“未命名项目”（账号的故事工作室里），用户可以删。

## 踩到的坑

- **Fish 故事工作室里改已生成区块**：窗口大小会在操作中途变（1254→1568→1715 宽），按坐标点区块会点歪，**这次误删了两个区块**；改用 `find` 取元素 ref 再点，改完用 `document.querySelectorAll('div.content')` 逐句核对。点“重新生成”**是整稿重新生成**（不是只生成改过的）：所有句子都是新 take，要重新 QA；导出的 zip 里新旧句子的格式会混（5 句 mp3 + 4 句 wav），`import_segments.py` 会转成 wav；页面下方 “00:00:42:25” 是播放头、不是总时长。
- **x264 要偶数尺寸**：框里的画面 972×547 编码报 “height not divisible by 2”，取 972×546。
- **faster-whisper 喂 numpy 数组按 16 kHz 解释**：48 kHz 的数组识别出来全是乱码（“中文字幕提供给…”），要先重采样到 16 kHz。
- **切点要逐帧看**：全屏人脸 29.1–29.9 s 还在从小框放大（手柄、文件名标签露在画面里），39.7 s 起是模糊转场；第二杯咖啡 76.0–76.3 s 还是聊天界面；Dumb-idea 框顶上的文件名标签会被裁切框切半——都靠 `gridframes.py` 抽帧叠坐标网格量出来的。
- **素材不够就复用**：人脸镜头一共才 26 秒（Hi-Nate 框、开头框、Dumb-idea 框、全屏人脸 30.0–39.4 s、两杯咖啡、全屏人脸 66–68.4 s），要铺满 28 秒，只能让 Hi-Nate 框首尾各出现一次（有意做成首尾呼应）。
- **工具**：这台机器上 `Remove-Item` 对 `build\stills\*` 会被拦，抽帧换新目录名（`--dir v2`）而不是删旧的；PowerShell 里没有 `python - <<EOF`，脚本写成文件再运行。
