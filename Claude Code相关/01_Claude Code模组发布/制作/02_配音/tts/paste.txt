Claude Code 现在，能装模组了。
对，就是你玩游戏时装的那种模组。
Claude 官方开发者账号，这几天连发了好几条新东西。
我给你捋一遍，先说最大的这个。
以前你能改的东西不少：设置、权限规则、斜杠命令、技能、状态栏。
模组再往前一步：改它的行为，改它的界面，还能换上你自己写的功能。
怎么写？几行 TypeScript 就行。
懒得写，就直接告诉 Claude Code 你想要啥，它帮你写。
怎么装？模组就是插件，输入 斜杠 plugin 就能装。
命令行版，和桌面版的 Code 标签页，都能用。
版本要 二点一点二八七 以上，默认就是开着的。
Claude Code 自己的 斜杠 diff 窗格，还有 AGENTS.md 支持，就是模组做的。
官方给了三个示例。第一个，Token Weather，上下文天气预报。
上下文，就是 Claude 在这场对话里，一次能记住的内容。
它在输入框上面画一行：天气图标，用了百分之几，
最近十二轮的小折线，还有上一轮涨了多少。
不到百分之二十五是晴天，往上依次是多云、阵雨、暴风雨。
到了百分之九十，它提醒你：快要压缩了。
整个模组，才八十行代码。
看到暴风雨，建议别再往里塞大文件了。
第二个，Blast Radius，爆炸半径。
Claude 要跑删文件夹、强制回退代码、强制推送这类命令时，
Blast Radius 先把命令拦住，告诉你它会动哪些文件。
你选继续，命令照跑。选取消，什么都不会被删，Claude 还会收到拒绝的理由。
删库跑路之前，你多了一次反悔的机会。
不过官方说了，它只是一道安全网，不能当权限系统用。
它只看命令的文字，绕得过去。真要硬拦，还得用权限规则。
第三个，Replay Theater，回放剧场。
比如让 Claude 把一个函数改名，它一口气改了六处，分在四个文件里。
这一轮结束，输入 斜杠 replay，或者按 R 键，就能一处一处回看。
上一步，下一步，像看比赛回放。
好玩归好玩，装之前，有件事要知道。
模组不在沙盒里，权限和 Claude Code 一样大。
它能读写你的文件，能启动程序，能联网，还能看到你环境变量里的密钥。
所以和装软件一个标准：只装信得过的人写的。
装之前，先跑一遍 claude plugin validate，能列出它挂了哪些事件、要调用什么。
不想用了，在 斜杠 plugin 里关掉就行。
自己写的想分享，放进 GitHub 仓库，别人三条命令就能装，也能提交到 Claude 目录。
没灵感？官方正往 Claude Code Playground 仓库里，加现成的示例。
顺带，官方这几天还发了三件事。
第一件，claude.dev，给用 Claude 做东西的开发者，开的新主页。
里面有工程深度文章，Claude Code 和 API 的指南，各个团队的经验，还藏了些彩蛋。
官方配的视频里，是站里一个像素小游戏：收集五个火花，把太阳叫醒。
第二件，Sonnet 五点五，五点五 家族的第二个模型，前面是 Opus 五点五。
比 Sonnet 五 更聪明，快三成以上。
单价没变，但干同样的活用的 token 更少，大多数任务最多便宜三成。
边界清楚的日常活交给它，比如修 bug、快速改功能。最难的长任务，还是交给 Opus 五点五。
Claude Code 里输入 斜杠 model sonnet 就能切过去，默认模型还是 Opus 五点五。
第三件，评测。
官方在 claude api 技能里，加了两个命令。
build eval，帮你给自己的应用建一套评测。
hillclimb，对着这套评测，一次只改一处，把分数一点点往上爬。
它还会留一部分没见过的题，防止光背题。
官方拿客服工单做例子，成本降到原来的五分之一左右，准确率还高了。
最后，想玩模组：先更新，看一眼版本号，二点一点二八七 以上就行。
建议从 Token Weather 做起，官方连提示词都写好了，复制给 Claude Code 就行。
