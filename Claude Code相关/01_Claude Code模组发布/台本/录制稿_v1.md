# 现在你可以修改Claude Code成自己喜欢的样子

v1（2026-10-02） · 配音：Fish Audio 网页版「赛马娘（曼波欧耶版）」，整期一次生成；模型 S2 Pro（用户 2026-10-01 指定，账号级设置）


## 1. 模组是什么

- **N01** Claude Code 现在，能装模组了。
- **N02** 对，就是你玩游戏时装的那种模组。
- **N03** Claude 官方开发者账号，这几天连发了好几条新东西。
- **N04** 我给你捋一遍，先说最大的这个。
- **N05** 以前你能改的东西不少：设置、权限规则、斜杠命令、技能、状态栏。
- **N06** 模组再往前一步：改它的行为，改它的界面，还能换上你自己写的功能。
- **N07** 怎么写？几行 TypeScript 就行。
- **N08** 懒得写，就直接告诉 Claude Code 你想要啥，它帮你写。
- **N09** 怎么装？模组就是插件，输入 /plugin 就能装。　（念：怎么装？模组就是插件，输入 斜杠 plugin 就能装。）
- **N10** 命令行版，和桌面版的 Code 标签页，都能用。
- **N11** 版本要 2.1.287 以上，默认就是开着的。　（念：版本要 二点一点二八七 以上，默认就是开着的。）
- **N12** Claude Code 自己的 /diff 窗格，还有 AGENTS.md 支持，就是模组做的。　（念：Claude Code 自己的 斜杠 diff 窗格，还有 AGENTS.md 支持，就是模组做的。）

## 2. 示例和注意事项

- **N13** 官方给了三个示例。第一个，Token Weather，上下文天气预报。
- **N15** 上下文，就是 Claude 在这场对话里，一次能记住的内容。
- **N16** 它在输入框上面画一行：天气图标，用了百分之几，
- **N17** 最近十二轮的小折线，还有上一轮涨了多少。
- **N18** 不到百分之二十五是晴天，往上依次是多云、阵雨、暴风雨。
- **N19** 到了百分之九十，它提醒你：快要压缩了。
- **N20** 整个模组，才八十行代码。
- **N21** 看到暴风雨，建议别再往里塞大文件了。
- **N22** 第二个，Blast Radius，爆炸半径。
- **N23** Claude 要跑删文件夹、强制回退代码、强制推送这类命令时，
- **N24** Blast Radius 先把命令拦住，告诉你它会动哪些文件。
- **N25** 你选继续，命令照跑。选取消，什么都不会被删，Claude 还会收到拒绝的理由。
- **N26** 删库跑路之前，你多了一次反悔的机会。
- **N27** 不过官方说了，它只是一道安全网，不能当权限系统用。
- **N28** 它只看命令的文字，绕得过去。真要硬拦，还得用权限规则。
- **N29** 第三个，Replay Theater，回放剧场。
- **N30** 比如让 Claude 把一个函数改名，它一口气改了六处，分在四个文件里。
- **N31** 这一轮结束，输入 /replay，或者按 R 键，就能一处一处回看。　（念：这一轮结束，输入 斜杠 replay，或者按 R 键，就能一处一处回看。）
- **N32** 上一步，下一步，像看比赛回放。
- **N33** 好玩归好玩，装之前，有件事要知道。
- **N34** 模组不在沙盒里，权限和 Claude Code 一样大。
- **N35** 它能读写你的文件，能启动程序，能联网，还能看到你环境变量里的密钥。
- **N36** 所以和装软件一个标准：只装信得过的人写的。
- **N37** 装之前，先跑一遍 claude plugin validate，能列出它挂了哪些事件、要调用什么。
- **N38** 不想用了，在 /plugin 里关掉就行。　（念：不想用了，在 斜杠 plugin 里关掉就行。）
- **N39** 自己写的想分享，放进 GitHub 仓库，别人三条命令就能装，也能提交到 Claude 目录。
- **N41** 没灵感？官方正往 Claude Code Playground 仓库里，加现成的示例。
