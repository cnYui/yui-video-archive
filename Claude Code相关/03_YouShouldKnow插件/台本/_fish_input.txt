你让 Claude 改完代码，最后它会给你一份总结。
这份总结写得很顺，每一条看着都是好消息。
可有一条，被它一笔带过了。
Claude Code 新加了一个内置插件，叫 You should know，直译就是，你该知道。
官方推文说：它会扫描 Claude 的输出，把你可能漏掉的重要信息挑出来，让你跟得上。
回到演示。总结刚结束，输入框上方就弹出一条提醒。
它说：刚才加的自动重试，可能让顾客被扣两次钱。
按一看详情：超时不等于没扣款，有时只是回信丢了，重试就会再扣一次。
常见的解法，是给每笔付款一个唯一编号，叫幂等键。
按二，这条提醒会带回主会话，标明是旁路智能体给的备注。
你顺口追问一句：这个键会不会过期？
Claude 看完说，旁路智能体说得对，马上改。
改完：每笔付款只生成一次随机键，每次重试都带着它。
它是怎么做到的？官方在下一条推文里说了。
这是一个模组：派出一个旁路智能体，在旁边观察 Claude 的输出。
模组是什么，第一期讲过。官方文档的内置模组表里，现在多了它，一共六个。
文档里的说明：Claude 做较长的任务时，它在旁边替你盯着；有你可能漏掉的，就在输入框上方留一条便条。
注意，它默认是关着的，要自己开，还要看你的组织有没有开放。
想开，输入官方给的这条命令就行。
不想要了，在 斜杠 plugin 里关掉；内置的模组不能卸载。
更新日志写着：二点一点二八七 版加入，前提是第一方会话、遥测开着。
至于多久提醒一次，会不会误报，官方没写。
总结写得再漂亮，也有没说出口的。多一双眼睛盯着，挺省心。
