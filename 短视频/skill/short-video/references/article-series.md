# 一篇文章 → 多期短视频（系列）

用户 2026-10-05（Tim Denning 那篇）：“他这个也能做成好几期短视频，你查一下他是谁，然后用他的头衔来讲述文章中他的观点，可以分好几期来讲，用他的配图”。成品：`独立视频\短视频\2026-10_TimDenning忠告1…6_*`（6 期，45–78 s，single 版式），**整套工具在 `独立视频\短视频\_TimDenning系列\`（README.md 有表），下一个系列先拷这个目录改 `series_data.py`**。记录 `docs/ai/context/20261005-211000-tim-denning-series-shorts_CN.md`，记忆 `tim-denning-series-article-to-shorts`。

## 流程（比单条多的几步）

1. **先查人**：作者主页简介（X 用 `api.fxtwitter.com/<账号>/status/<ID>` 的 `author.description`；Substack 用 `<名>.substack.com/api/v1/posts/<slug>` 的 `publishedBylines`）、再找 1–2 个独立来源。**“头衔”几乎都是自称**（10 亿阅读 / 赚了多少钱 / 做过什么）：台本每期第 2 句挂“简介自称”，履历写“自述”；起一个事实核对子代理（15 分钟时间盒，`素材\…\事实核对.md`）。同名的别人很多，别混。
2. **找公开版本做真实页面录屏**：X 长文是登录墙，作者常同时发在 Substack / 官网（公开、无头浏览器能截）；两版正文先逐段比对。配图以文章为准，**可能只有一张封面图**（X 的 `entityMap` 为空、`media_entities` 为 `[]`）——如实告诉用户，别硬凑；AI 生成的配图要在画面和简介里标来源（Substack 页标 Image Credit-Midjourney）。
3. **分期**：按主题拆（每期 3–6 条，45–75 s），选条目看三点：有具体细节 / 数字、画面上能高亮原文、不踩过审雷。**跳过**：加密货币推荐、宗教、性 / 性病、死亡 / 自杀 / 毒品比喻、没内容的短条。每期结构：钩子（他的一句话，引号）→ 第 2 句“出自 X，简介自称……”→ 条目（每条 2–4 句，“第 N 条：…”开头）→ 泼冷水（他没给依据的数字、“全是个人经验”）→ 金句。
4. **台本一份数据源**（`series_data.py`：每句 zh / say / en + 每个场景的页面高亮点 / 照片 / 大数字卡）→ `gen_episode.py N` 生成各期的 录制稿 / plan / scenes.js / 页面图；自检脚本查“他 / 她 / 我”、“不是…而是…”、短语在不在、估时。第三人称、对方自称的话挂名、他说“last year”这类相对时间要换成绝对的或去掉（文章 2025 年写、X 2026 年重发）。
5. **页面截图**（`capture_series_pages.py`，无头 Chromium，视口 640、2.4 倍像素）：Substack 按标题位置切段；高亮匹配要“拼接全部文字节点再映射 Range”（`<em>` 会把句子切开，技能引擎自带的逐节点匹配会退回整块高亮）；单句 / 短列表片段用 420 宽视口折行放大 1.5 倍（`vw=420`，不然框里只有一行小字）。**敏感原文不能随页面截图进画面**：相邻的列表项 / 段落要紧贴着截（`li_range`、`para_lines`），再核对图片底部几行像素是不是背景色；封面候选里也要看。
6. **画面**：`pageShot` 深色页用橙色半透明高亮 + 黄色中文译文条（和贴纸同色）、浅色页（推文卡片）用黄荧光笔 + 深色译文条；`photoShot` 放作者照 / 横幅（缓慢推近，`base` 放大取脸）；`big()` 大数字卡一条最多 1–2 张，别跨场景；贴纸写“第 N 条 · 主题”，来源小字写“图：Substack · …”。
7. **配音一份整稿**：几期的 `say` 拼成一个 Fish 空白项目一次键入（`build_fish_doc.py` 分 ≤ 24 句一段，JS 核对块数和 SHA-256）、一次生成、一次导出；`split_voice_export.py` 按 metadata.csv 核对文字后拆回各期的 `tts\seg_raw\final\`。声线温柔男生每汉字约 0.135 s（95 句 / 2397 字符 → 6:00），估时模型 `0.140·汉字 + 0.333·英文词 + 0.284·句内标点 + 0.405` 偏长约 4%。别的会话也要 Fish / Chrome / 渲染时用 `ListAgents` + `SendMessage` 排队，没有可见标签就别键入。
8. **渲染**：`run_episode.py timeline|render|qa N…`（空闲内存 < 6 GB 自动降 3 / 2 路）；渲完 `finish.py` 出成片 / 手机预览 / 三份 SRT；逐句识别（`qa_mix.py`）单独跑，不占渲染槽位。
9. **封面 / 标题 / 交付包**：`series_covers.py`（作者照最稳、页面截图加橙色高亮次之、X 横幅当第三种；Midjourney 派对图不做封面）；`series_publish.py` 写标题 + 各平台简介 / 话题（2026-10-06 起视频号不发：标题 3×3，不再写视频号短标题）（简介前两行写转载来源，自称的数字挂名，写“36 条”别和年龄“38 岁”写混）；`make_delivery.py` 汇总 `交付包.md`；聊天里发摘要 + 总览图，回“第 N 期：封面 X 标题 Y 同意”才发布。
