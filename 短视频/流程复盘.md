### 本次补的工具（用 Tavus 的素材验证过）

- `scripts/make_cover.py` 加 `style: "full"`（满框 C 风格）：自动检脸（OpenCV）、按比例裁窗、字放在脸的另一边、箭头指脸；`avoid` / `keep_clear` 处理视频通话小窗；用 Tavus 的帧复现了 3:4 / 16:9 / 4:3 三个比例，字、箭头、小窗处理都对。**页面 / 数字这类没脸的画面不适合 `full`，第三个候选用 `split`。**
- `scripts/make_candidates.py`：读 `制作/04_封面/candidates.json`，一条命令出 3 候选 × 3 比例 = 9 张 + `候选总览.png`；`--select X` 把选中的复制成 `封面_选定_*`。Tavus 素材测试：A 安静帧、B 竖大拇指帧、C 官网实验页，25 秒出完。
- `scripts/check_titles.py`：读 `投稿信息.json` 的 `titles`（3×4）和各平台字段，按 B 站 ≤ 80 / 抖音 ≤ 30（话题 ≤ 5）/ 小红书 ≤ 20 / 视频号短标题 6–16 量字数，也查标题和封面大字别同一句、三个候选不重复；正常一组全过、故意超限逐条报。
- 模板：`assets/cover-template/candidates.json`、`assets/publish-template/投稿信息.json`；`new_short.py` 建条目时拷进本条，并打印交付包的下一步。
- `scripts/cover_frame0.py`（用户 2026-10-04：“视频号封面放到成片第 0 帧，做成选定的封面”）：把成片的第 0 帧换成选定的封面——3:4 封面放在 1080×2340 画面正中（y 450–1890），上下用封面自己模糊铺满；**只重编码第一个 GOP（约 8 s），其余帧直接拷贝、原声不动**，视频长度 / 帧数 / 每帧 pts 不变，原片留 `_成片_无封面帧.mp4`。Tavus 成片测试 19 秒：每一帧 pts 一致、拷贝段逐像素一致、原声 md5 一致、第 0 帧 48 dB（只做 4:2:0 的参考）、解码无报错；`--check` 查现在的成片是不是封面帧，`--full` 整条重编码备用（拼接校验不过时自动用）。流程里放在“用户说同意、`make_candidates.py --select X` 之后、开 Chrome 之前”。
