# REA 事实核对

| 说法 | 结论 | 依据 |
|---|---|---|
| 官方项目 | 已核实 | `morluto/rea` GitHub API：描述为 Reverse engineer anything with agents；README 标 MIT |
| 当前 Star | 已核实 | 2026-10-14 初查 218,376，保存证据时 218,591；台本约 21.8 万 |
| ADB 连接模拟器 / 真机、读取和拉取 APK | 已核实 | `docs/adb-device-analysis.md`：list / inspect / pull 操作 |
| HAR / mitmproxy 抓包 | 已核实 | `docs/web-network-captures.md`：HAR 1.2 与 mitmdump 12.2.3 |
| Binwalk / Unblob + Ghidra | 已核实但有前置条件 | `docs/firmware-analysis.md`：Binwalk 3.1.x、Unblob 26.6.x；Ghidra 需要已有安装 |
| “每个请求自动定位到 App 源码” | 收紧 | 仓库支持网络捕获和源位置映射，但不保证任意 App 自动完成因果定位 |
| X 链接中的教程 | 已核实 | `0xlangeai/status/2109544824135467312` 实际是蓝哥 AI 的 REA 恐龙小游戏教程文章，已下载其中 9 张图片 |
| 用户后补 X 教程 | 已核实 | `ResearchWang/status/2109812002076143824` 是 REA、Reverse-skill、PentAGI 组合教程，已下载 3 张图片；没有空调或 AR 眼镜实测 |
| 空调 / AR 眼镜案例 | 未核实 | 公开搜索没有找到可绑定到给定 X 链接的原帖；视频不把它作为 REA 官方案例 |

视频中的结论：REA 把“观察行为、读取程序、保留证据、交给 Agent 解释和实现”串成工作流；能否控制某台设备，取决于设备协议、权限、加密和现有工具。
