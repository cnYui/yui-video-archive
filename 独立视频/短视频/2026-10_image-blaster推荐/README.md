## 做法

- 素材：`D:\大疆\独立视频\素材\2026-10_image-blaster\`（合集层共用素材；README 里有来源和挂名）。**视频是作者本人 @neilsonks 2026-05-14 在 X 上发的原帖演示，我们下的是 @liambraus 10-03 转发的 720p 版本**（原帖还有 2560×1440 版本，没换）。
- 引擎：`短视频\skill\short-video` 的竖屏单框引擎（10:17 的快照），**本条副本已改成新版式**：`index.html`（版式 B、边框 6、背景印花 `pattern.png`）、`engine.js`（边框右上角贴纸 = 当前场景来源）、`scenes.js`（`linkPill()`、`big()` 默认 y）、`check_subs.py`（字幕 y 从页面里量）；改之前的版本在 `制作\00_整片\_index_旧版式.html` 等。
- 版式 B（用户 2026-10-04 选定）：标题 280–570 不动 → 视频框 770–1339（间距 200）→ 字幕 1498–1608（间距 160）→ 链接条 / 紧凑数字卡 1658 起；双横屏 = 两框叠在一起（860 宽、间隔 24）、字幕在下（1764）。边框 6 = 7 px 黑描边 + 橙色硬阴影 + 右上角黄贴纸；背景 = AI 工具图标低透明度印花，按技能规矩每期随机挑一张（`短视频\skill\short-video\assets\backgrounds\` 三张），这条随机到 `pattern_color.png`（原色约 11%），存在 `制作\00_整片\bg.png` + `bg.json`。引擎副本 2026-10-04 下午用 `制作\00_整片\_sync_template.py` 同步到技能模板最新版（改前的文件在 `_同步模板前备份\`）。BGM = 系列 BGM `AI科普\素材\音频\bgm.wav`：垫底 −7 dB、压人声时降到 0.05 倍、讲解者说话时进一步让位（`mix_audio.py` 开头的参数），混音各路响度：人声 −16.0 / 原声 −29.1 / BGM −29.7 LUFS（单路），成片 −16.1 LUFS。
- 同传：@neilsonks 的英文讲解按句切在静音处（逐词时间 `制作\03_原声转写\asr_en_words.json`），曼波中文同传每句比英文晚约 0.4 s 开口，原声 −21 LUFS、曼波说话时再压 −9 dB；自己的解说（N02、N07–N09、N11）画面是 GitHub 页面录屏 / 定格，没有原声。
- 第三人称：N01 “@neilsonks 五月发布了一套 Claude 技能……”（语音念“尼尔森五月发布了……”），N03 去掉“你”；这两句在 Fish 里单独重配（`制作\02_配音\tts\seg_pick_v3\N01.wav` / `N03.wav`，`build_voice.py` 会盖过整稿里的原句），其余 9 句沿用第二版的配音。
- GitHub 链接条：展示 GitHub 仓库页（N02、N09 两处）时在字幕下面亮 `github.com/neilsonnn/image-blaster`；“要两个 key”那处仍是数字卡。
- 配音：Fish 故事工作室空白项目，赛马娘（曼波欧耶版）+ S2 Pro；整稿 11 句 / 356 字生成过 1 次（v2），N01 / N03 单独生成 1 次（`制作\02_配音\web_usage.txt`）。

```bash
python build_timeline.py && python check_subs.py && python prep_frames.py     # 改台本 / plan 后

```
