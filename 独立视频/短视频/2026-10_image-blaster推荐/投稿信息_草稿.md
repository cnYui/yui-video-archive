## 简介

GitHub 项目推荐：neilsonnn/image-blaster。一张图 → Claude 先列出物件，混元 3D 给每件物件出模型，World Labs 用擦掉物件的空场景生成可以走进去的 3D 场景，ElevenLabs 配环境音和碰撞音。
画面和英文讲解：作者 @neilsonks（Neilson Koerner-Safrata）2026-05-14 在 X 上发的演示视频（https://x.com/neilsonks/status/2055013782771134479 ；本片用的是 @liambraus 2026-10-03 转发的版本 https://x.com/liambraus/status/2106383261089849825 ），中文为 AI 同传（曼波声线），英文字幕为讲解内容（第三人称，略压缩）。
项目：https://github.com/neilsonnn/image-blaster （MIT 协议，作者 Neilson Koerner-Safrata，World Labs 设计团队；拍摄时 5.2k 星，最后一次提交 2026-05-15）。World Labs 展示页：https://www.worldlabs.ai/labs/showcase/image-blaster
“不到 5 分钟”是 README 里作者自己的说法，我们没有实测；需要自备 World Labs 和 FAL 两个 API key，费用没有核实；演示里作者说目前只管生成、不管搭场景。
画面版权归原作者，配音为 AI 生成。
