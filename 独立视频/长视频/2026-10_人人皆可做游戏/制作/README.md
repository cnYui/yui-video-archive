### 目录

| 路径 | 内容 |
|---|---|
| `voice.py` | 口播剪辑表（EDL）：`KEEP` 每条素材留哪几段、`CUTS` 说了一半重来 / 口头禅的小段、`GAPS` 段间停顿、`PRE` 开场前 4 秒实机快切；停顿 > 0.4 s 压到 0.3 s，切点落在静音里，所有时间落在 1/60 s 网格。`python voice.py show`（每句话在成片里的时间）/ `face`（face_tl.mp4）/ `audio`（人声.wav） |
| `02_出镜\` | 四条露脸的音频、代理（1080p60）、ASR 逐词时间（`asr\*.json`）；`ingest.py`、`asr.py` |
| `face_tl.mp4` | 出镜画面，和成片同一条时间轴（逐帧按 EDL 取；没人声的空档停在上一帧） |
| `人声.wav` | EDL 渲出的人声（−16 LUFS）；`音轨\`：人声 / 游戏BGM / 游戏音效 / 背景乐 / 混音（都从 0 秒对齐画面，可以拖进剪辑软件重混） |
| `v2\plan.py` | **整条页面时间线**：每个画板、卡片、便利贴、说明带的起止都用 `ph(素材, "词")` 对口播里的词；`SHOTS` 是实机镜头表（录像段、起点秒、章号） |
| `v2\comp.py`、`ui.py`、`gens.py` | 合成引擎（numpy 逐帧 + ffmpeg 管道）、小部件（框、贴纸、卡片、键帽……）、活素材（动作墙、视差街景、终端卡、代码窗口、文件夹窗口） |
| `v2\render.py` | `still 12 40 …`（抽帧检查，联系表 `_check\sheet.png`）/ `chunk a b out.mp4` / `video --workers 5`（整条，→ `v2\画面.mp4`） |
| `v2\subs_src.py`、`make_subs.py` | 字幕源（他说的话 + 英文）→ ASS（烧）+ 三份 SRT + `字幕核对表.md` |
| `v2\audio.py` | 分轨 + 混音；实机镜头的声音按 `plan.AUDIO` 取（bgm / sfx 往回挪 `full.webm` 的音频起点，和 `make_clips.py` 同一套） |
| `v2\finish.py` | `main` = 烧字幕 + 混音 → `整片_v2.mp4`；`full` = 加悠一片头片尾（`outro.json`）→ `欢迎来到人人皆可做游戏的时代_成片.mp4` + 手机预览 + 三份 SRT（时间含片头） |
| `outro.json` | 片尾清单**草稿**（按规矩每期要用户确认） |
| `v2\scan.py` | 从实况录像（A–E）按间隔抽联系表找镜头：`python scan.py B 253 330 2 out.png 6` |

### 重做

```text
cd 制作
python voice.py face && python voice.py audio     # 口播剪辑表改了（KEEP / CUTS / GAPS）之后
cd v2
python make_subs.py                               # 字幕源改了 / 口播改了
python render.py still 60 110 180                 # 抽几帧看版式
python render.py video --workers 5                # 画面（约 5 分钟，先 ListAgents 看别的会话在不在渲）
python audio.py                                   # 分轨 + 混音
python finish.py main && python finish.py full    # 正片，再加片头片尾
```
