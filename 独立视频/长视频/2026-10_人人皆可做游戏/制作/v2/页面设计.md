# 页面设计（长视频《欢迎来到 人人皆可做游戏的 时代》v2）

2026-10-06 用户：“当前你要做的是长视频，屏幕比较大，是可以放多个素材的，你合理规划一下页面的设计。”

样板图：`_design/总览.png`（7 张，用真实素材拼的）；单张在 `_design/page_*.png`；样板脚本 `design_sheet.py`，小部件 `ui.py`，活素材 `gens.py`。

## 画布

- **2340×1080、60 帧**（项目里横版长视频统一的画布，v1 无声版的 1920×1080 作废）；背景印花随机挑到 `landscape_orange.png`（`bg.png` / `bg.json`），重渲不换。
- 字幕在 y 922 以下（中英双语标准：中文 52 px + 英文 30 px），**所有内容都在 y ≤ 899**。

- **要摊开的素材**（图集、镜头表、对照）：中栏 + 右栏并成一块 **宽板 1700×859**，里面 2×2 或 1+3。
- **出镜当主角**（开场、收尾、“人要做挑选”）：出镜框从左栏放大到中栏（1152×648），左栏只留目录；右栏放证据卡。出镜框在两个位置之间用 0.35 秒补间过去。
- **只有游戏原声的段**（S08 里那 10 秒）：没有人说话，出镜框收掉，实机放大到 1536×864 居中。
- 实机永远用 **整数倍放大**（缩略图除外），像素不糊。

## 样式（照封面框版）

- 画板：INK 粗黑边 6 px、圆角 22、**橙色硬阴影**（出镜框用**黄色**硬阴影，卡片用黑色硬阴影）。
- **黄色贴纸**压在画板左上角，写“这块是什么”（原片 / 第十章 · 给将军剪头发 / ① 原片里的一个场景……）。
- 数字卡：大数字 + 橙色单位 + 灰色一句话，数字入场时从 0 数上去。
- 当前正在讲的那块：橙色光环；别的块不动。
- 目录卡：3 条（≤ 7 字）：先玩一下 / 怎么做的 / 门槛还剩什么；下面 15 个小点 = 15 章，实机切到哪一章，点就走到哪一章。

## 做法

- 合成引擎 `comp.py`：numpy 逐帧合成（背景 + 画板 + 贴纸 + 卡片），实机 / 原片 / 出镜用 ffmpeg 管道解码，字幕最后一遍用 ASS 烧；按场景切段多进程渲。
- 所有画面点位用口播时间对：`voice.out_time(clip, 源秒)` → 成片秒，剪口播改了，画面跟着走。
- 实机素材来自 2026-10-06 整部实况录屏的 A / B / C / D 四段（384×216 webm，最近邻放大）；音频（BGM / 音效）按同一时间点另取，混在人声下面。

## 实际做出来的（和上面的设计稿不一样的地方）

- **开场**：先 4 秒实机快切（“全江户，集结！”→ 背靠背），片名（白字 + 橙字描边）压在快切上；出镜框再从下面滑进中栏。说明带不放片名，放一条“旅程条”：像素视频 → 游戏素材 → 银魂游戏，讲到哪一步亮哪一步。
- **E 双击就能玩**：中栏是一个文件夹窗口（真实的游戏目录），鼠标移到 index.html 上双击，接着切到标题画面；右栏是三张便利贴“准备上架：小红书的小程序 / 抖音的小程序 / 小工具 / 让大家都能玩”。
- **血条**：右栏放一块把血条放大的实机裁切；“如果血条不够了”那一刻，主画面是补录的“银时倒下了…… 再来一次”。
- **S05 开头**：先放原片（那条 5 分半的像素视频）整块，再翻出 15 张分镜图（每张标 序章 / 第 N 章 / 终章），再进“原片 → 分镜 → 镜头表 → 游戏”的四宫格；名场面（眼睛特写、打穿墙、全江户集结）各换一组，镜头表里的对应行高亮；之后是四个小游戏同时放，最后是“台词页”：实机（天然卷 / 洞爷湖 / 不是假发是桂的那一刻）+ 说明带换成真实的 `story/chapter1.js`、`chapter5.js` 代码行 + 右栏口头禅便利贴。
- **S08**：主画面按口播换镜头（全江户集结 → 屋顶混战 → 各路人马 → 背靠背 → 天亮 → 终章踢飞“完”字），右栏三个缩略图轮流亮；“将近 5 分钟的打斗”“银魂永不完结”贴在主画面右上角（别压住游戏自己的对话框）。
- **S10**：别的动漫的图集四张同时亮（银魂 / 进击的巨人 / 火影 / 无职转生）→ “做游戏的门槛，还剩什么？”便利贴 → 以前 4 张卡逐张盖红叉 / 现在“想清楚、说清楚”+ 一段实机 + “审美：你来挑” → 媒介转换（五种输入 → 四个真实成品：UI 设计师长视频封面、强化学习短视频、官方课十集、这个游戏），“不用再啃大部头”“更快地了解内容和内涵”两张贴纸。
- **收尾**：出镜框回中栏；“以前 / 现在”两张说明带；最后一句说出口时片名和游戏 Logo 一起弹出。
- **S03（实机①）右栏**：他说“没加很多技能 → 一个普通的攻击 → 跳跃 → 剧情上的对话 → 环境的对话 → NPC 的对话”，右栏一条一条冒出来（橙点 = 操作 / 绿点 = 内容）；说明带同步换成 J / K / L 键帽（讲到哪个键亮哪个）。
- **“输了重来”**：“如果血条不够了”那一刻，主画面放补录的“银时倒下了…… 再来一次 → 重新开打”（`E_序章输一次重来`），一直放到 S04 的素材板进来，中间不空。
- **字幕**：照他说的字写（去口头禅、改 ASR 听错的字，不改词序、不加他没说的字，比如他说“现在只需要自己想要什么”就写这个）；列在 `字幕核对表.md` 里的 14 处是我拿不准的词。
- **声音**：实机段垫在人声下面的游戏 BGM / 音效；开场快切和“眼睛特写 → 打穿墙”那 10 秒只有游戏声；其余口播段垫一层很轻的游戏自己的 comedy 配乐。四条分轨在 `音轨\`，可以拖进剪辑软件重混。
